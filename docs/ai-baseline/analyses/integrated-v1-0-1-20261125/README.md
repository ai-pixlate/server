### OP06·OP07의 범위

OP06은 완료 2작업의 최초 N5 전체 번역 맵을 비교한 내부 관찰이다. N3/N5 수정 기록은 각각 16개 원본에서 change_count=0이며 실패 상품은 확인 단계에 도달하지 않았다. 규제 제안 해제·검증 후 직접 수정·빈 번역 직접 입력 등 별도 세부 신호는 독립 사건 기록이 없어 별도 실측값으로 확정하지 않는다. H05는 계속 미측정이다.

OP07 규제 판정 0건 비율은 GS-01 13/24=54.17%, GS-02 47/49=95.92%다. 허용 판정은 제외한 N2 기록이며 번역문 재대조는 포함하지 않는다. 자동 제외 6섹션(GS-01 1·GS-02 5), 현지 기준 미검사 0·판정 실패 0은 **기록된 73섹션 안에서의 값**이다. GS-03의 섹션 분모는 생성되지 않아 0건 성공이 아니라 미도달이다. 규격 검증은 GS-01 1/1·GS-02 12/12이며, 미생성 18장을 검증 통과로 세지 않는다. 규격 통과는 H03 사용 가능 A등급이나 규제 위험 표현 검출 재현율을 의미하지 않는다.

## 공통 결함과 개선 검토 방향

| 최초 원인 단계 | critical | major | minor | 영향 원본 수 |
|---|---:|---:|---:|---:|
| OCR | 1 | 0 | 0 | 1 |
| 번역·현지화 | 3 | 2 | 1 | 4 |
| 렌더·배치 | 1 | 0 | 0 | 1 |
| 원인 불명 | 3 | 18 | 2 | 12 |
| 고유 결함 합계 | **8** | **20** | **3** | **고유 12장** |

같은 root의 양 체크포인트 관찰 62행을 **31개 고유 결함**으로 연결한다. 영향 원본은 source_key로 중복 제거하며 단계별 합을 전체 원본 수로 사용하지 않는다. 원인 불명 23/31개는 그대로 남겼고 배치 형태라는 이유만으로 렌더 단계로 확정하지 않았다. 근거는 [PM 결함 목록](../../evaluations/h01-h04-official-20261124/pm-review-20261124/defect-inventory.md)과 [이번 원인별 집계](results/common-defects.json)다.

후속 개선 검토는 PM 확정 critical(용량·수치 배지·제품명 판독, 원문 밖 주장, 후기 대체 누락, 사용 빈도·콩알 표현)을 먼저 대상으로 삼고, 반복 겹침·보호 요소 손상과 major 의미 변화를 이어서 확인할 수 있다. TQ03의 모델 피드백은 별도 사람 검토 후보로만 사용한다. 콩·쌀 용어집의 단어 내부 매칭 원인은 별도 조사 요청이며 이 보고서에서 원인 확정·수정·추가 실험하지 않았다. EI-01 평가 이슈·EI-02 비결함 상태도 유지한다.

## 추적·재현·검증

- [입력 경로·SHA-256](results/inputs.json): 공식 실행·사용량·가격 근거, H 확정 결과·승인, OCR 저장 결과, TQ03 원시 결과·입력·설정·코드, 집계 명세와 실행 스크립트.
- [operation-evidence.json](results/operation-evidence.json)의 상품별 event→record_id와 [logical-executions.json](results/logical-executions.json)의 시도 행 ID로 원본 execution.jsonl까지 추적한다. OP01은 생성/저장 이벤트, OP04는 완료/중단/대기 이벤트, OP06은 최초 N5, OP07은 규제/규격 이벤트를 사용한다.
- [op-results.json](results/op-results.json)은 기존 운영 집계기 출력과 분자·분모·단위를 보존한다. `value=null`은 미측정이다. 비용 행의 numerator 부분합이나 미측정 행의 0을 완전한 비용·성공으로 해석하지 않는다. 상태별 OP02 및 OP03 자동 재시도 비율은 원시 논리 단위로 검산했다.
- [검증 결과](results/validation.json): H 확정 인용, OCR 저장 S/D/I/N 독립 합계, TQ03 확정 audit의 원시 표지 재대조(재추론 아님), 요청별 가격 계산, GS-03 실패 중복 방지, 입력 전후 불변.

Python 표준 라이브러리와 저장소의 기존 운영 집계 코드만 사용한다. TQ03 원본 묶음은 저장소 밖에 있으며 공용 접근은 미확인이다. 묶음을 확보한 뒤 확정 해시가 맞아야 재현한다. 모델 가중치는 필요 없고 다운로드·재배포하지 않는다.

```powershell
python -X utf8 -B docs/ai-baseline/analyses/integrated-v1-0-1-20261125/aggregate.py --tq03-root "<보존된 full-eval-20261120 디렉터리>" --output .cache/baseline-integrated-replay
```

출력 경로가 이미 있으면 중단한다. 원시 결과·동결 정답·실행 증거·PM 채점은 변경하지 않는다. 날짜별 과거 회차 문서는 당시 상태로 보존하고 현재 안내 문서에서 본 보고서와 확정 결과를 연결한다. 병합·새 모델 호출·제품 재생성·GS-03 재실험·노션 수정은 수행하지 않았다.

회귀 검증은 프로토콜·공식 평가 준비·범위·상호작용·감사·일관성 테스트 **89개 통과**다. 최초 실행에서 두 테스트 모듈의 import 경로 오류가 발생했으나 discovery 방식으로 재실행해 각각 12개 통과했다. 최종 집계 결과 11개 파일은 새 출력 경로 재현본과 바이트가 일치한다. [추가 검증 기록](verification.json)을 참조한다.
