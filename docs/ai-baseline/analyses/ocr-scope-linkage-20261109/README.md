# OCR 정책 반영 및 영역·GT 연결 검증

2026-11-09 · 범위 주석 revision 2 · 사용자 정책 반영 / 개별 연결 검증 진행 중. GT 수정·재전사·동결, OCR 실행, CER 채점은 하지 않았다.

## 정책 변경과 분류

이전 조사에서 미결이었던 논문 제목·저자·표·캡션은 본문·참고문헌과 함께 제외한다. 기프트카드 인쇄, 인증 마크 내부 문구, 협업·타브랜드 로고·패키지 인쇄도 제외한다. 각 이미지 밖에 별도로 작성된 설명·효능·구매 혜택은 포함한다. 근거는 이번 사용자 확정 요청이다. N3는 독립 평가 범위에 반영하지 않는다. 특허증·시험성적서는 기존 포함 원칙을 유지하며 추가 제외는 미확정이다.

| GS | 포함 | 혼합 | 제외 | 합계 |
|---|---:|---:|---:|---:|
| GS-01 | 11 | 13 | 1 | 25 |
| GS-02 | 37 | 11 | 0 | 48 |
| GS-03 | 27 | 9 | 3 | 39 |
| 전체 | 75 | 33 | 4 | 112 |

종전 76/31/4/정책 미결 1에서 변경됐다. GS-01_002/sec_1_07은 인증 마크와 별도 설명이 있어 포함→혼합, GS-02_001/sec_1_02는 기프트카드 인쇄와 혜택 안내로 미결→혼합이다. 위 수치는 정책 적용 분류이며 모든 세부 영역이 승인됐다는 뜻은 아니다. GS-01_002/sec_1_12의 원형 시험 결과 안내는 인증 마크인지 일반 설명인지 추가 확인이 필요하며 현재 포함 분류를 임의로 바꾸지 않았다.

## 연결 결과와 한계

- [영역 주석](scope-annotations.json): 112개. 대략적인 사각형은 자동 제외 마스크가 아니다.
- [GT 줄 연결표](gt-line-links.md) / [기계 판독본](gt-line-links.json): 혼합 33개, 기존 969줄을 빠짐없이 연결 후보로 기록. 포함 416, 제외 518, 미확정 35줄. 기존 텍스트·ID·순서는 변경하지 않았다. 의미 판정과 정확한 위치 연결은 별개이며 여러 영역 후보가 있는 줄은 위치 확정이 아니다.
- [OCR 연결 후보](ocr-region-links.json): 혼합 33개, 1,193영역. 우선 82개 외 1,111개는 기하 후보만 생성했으며 의미 범위가 검증되지 않았다.
- [우선 82개 검토](priority-82-review.md): 16개 섹션의 원본 위치를 시각 확인. 포함 30, 제외 47, 빈 출력 2, 미확정 3. 빈 출력은 GT 제외 근거가 아니다.
- [읽기 전용 확인 화면](review.html): 원본과 주석 및 기존 GT 비교. 로컬 이미지 경로를 참조하므로 공유 완료 자료가 아니다. 이번 화면은 파일 구조·참조 검증 대상이며 브라우저 시각 검증 완료로 표시하지 않는다.

큰 제외 사각형이 휴대용 스틱형 안내, 구매 혜택, Q&A, 별도 BODY WASH/LOTION 안내까지 덮는 사례가 있다. 사각형 내부 또는 교차 비율만으로 자동 제외하면 문자 누락/삽입을 숨길 수 있다.

## 기존 GT 재검수 후보 8개 재산정

| 섹션 | 후속 작업 | 예상 최소 검토량 |
|---|---|---|
| GS-02_008/sec_1_05 | 포함 정책인 특허증의 미전사 보완 필요 | 문서 1영역, 실제 줄 수 미정 |
| GS-03_014/sec_1_01 | 포함 정책인 시험성적서의 미전사 보완 필요 | 문서 2영역, 실제 줄 수 미정 |

따라서 **보완 필요 2개 + 보완 필요 여부 확인 5개 = 재검수 7개**, 논문 섹션 1개는 범위 연결 확인으로 분리한다. 5개를 오류 확정으로 해석하지 않는다. 보완 줄 수나 소요시간은 원본 독립 검수 전 확정할 수 없다. 기존 18개 재전사 초안은 보존하며 논문 추가 전사는 채택하지 않는다. 위 35줄 범위 검토는 전사 작업량과 중복 합산하지 않는다.

## 채점 차단 및 다음 작업

자동 처리 가능한 것은 ID·해시 대조, 전체 연결 개수 검증, 기하 교차 후보 추출이다. 의미상 단일 범위인 77개 출력은 후속 필터 검증 사례로 사용할 수 있지만 현재 자동 필터 승인이 아니다. GT/OCR 범위가 대칭적으로 승인되고 모든 연결·GT 완전성이 검증돼야 채점한다. **현재 혼합 33개 중 채점 준비 완료는 0개**이며 비혼합 79개도 이번 결과만으로 새 공식 채점을 승인하지 않는다.

다음 순서는 미확정 의미/혼합 문자열 처리 결정 → 나머지 OCR 1,111영역 및 거친 주석의 범위 연결 검증 → 7개 GT 검수·필요한 부분만 새 버전 보완 → 사용자 승인·범위/GT 동결 → 대칭 필터와 채점기 검증 → 별도 승인 후 재측정이다. v1.0.1·2차·3차에서 동일 입력/범위를 고정한다.
