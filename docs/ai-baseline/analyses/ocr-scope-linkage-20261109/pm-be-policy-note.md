# PM·BE 공유용 정책 변경 요약 — 미전송 초안

> 후속 결정: 특허증·시험성적서 내부도 제외하고 별도 효능 설명·요약·인용은 포함한다. 아래 기존 포함 원칙/추가 제외 질문은 이전 이력이며 [최신 공유 요지](../ocr-v6-policy-followup-20261109/README.md)를 우선한다. 아직 전송하지 않았다.

OCR 독립 평가를 실제 번역 대상 문자 인식 품질에 맞추기 위해 사용자 결정으로 범위를 정리했습니다.

- 논문 제목·저자·본문·표·캡션·참고문헌 전체를 제외하고, 별도로 작성된 효능·시험 결과 설명은 포함합니다.
- 기프트카드 인쇄, 인증 로고/심볼 내부 문구, 협업·타브랜드 로고와 패키지 인쇄는 제외합니다. 별도 구매 혜택·인증 설명·일반 문구는 포함합니다.
- 특허증·시험성적서는 기존 포함 원칙을 유지합니다. N3 최종 제외와 독립적으로 고정 원본을 평가합니다.

이는 평가 정책 및 서비스 적용 의도에 관한 결정입니다. **v1.0.1이 이미 논문을 제외한다고 확인한 것은 아니며 서비스 구현·계약은 수정하지 않았습니다.** 문서 캡처를 일반 텍스트로 처리하던 기존 기준과 논문 전체 제외의 차이를 확인해 주세요.

확인 요청:

1. 논문 전체 제외를 서비스의 어느 판정/번역 단계에 적용할지, 기존 동작·계약 변경이 필요한지와 담당자·적용 버전.
2. 논문 위 별도 효능 문구, 일반 설문/판매 순위 배지와 인증 마크를 구분하는 기준.
3. 일반 문구와 로고가 하나의 OCR 문자열에 섞인 경우 처리 정책. 평가 측에서 임의 분할하지 않겠습니다.
4. 특허증·시험성적서에 추가 제외 정책이 필요한지. 합의 전에는 현재 포함을 유지합니다.

현재 혼합 33개 섹션의 범위 연결은 검증 중이며 새 공식 CER은 산출하지 않았습니다. [상세 보고서](README.md)의 미확정 항목을 확인한 후 별도 범위/GT 승인 절차가 필요합니다.
