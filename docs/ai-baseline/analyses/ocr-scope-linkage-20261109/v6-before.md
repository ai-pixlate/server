# OCR01 번역 대상 텍스트 CER — v6 범위 명세 초안

2026-11-09 사용자 정책 결정 반영. **평가 목적·제외 정책은 확정, 영역 연결·채점 구현·GT 동결·공식 전환은 미완료**. 기존 [v4](ocr-v4.md)·[v5 후보](ocr-v5.md), OCR Text v1/v2와 결과는 그대로 보존한다. v6은 새 범위 명세를 구별하기 위한 초안 이름이며 공식 채점기 버전 승인이 아니다.

## 평가 목적과 적용 범위

OCR01은 **원본 기준으로 고정된 번역 대상 텍스트의 문자 오류율(CER)**이다. 서비스 보정 후 OCR 최종 반환값을 평가한다. GS-01~03의 112개 고정 섹션 이미지를 유지하며, N3 최종 제외·실제 번역 성공/실패·제품의 라벨 판정·OCR confidence로 평가 분모를 바꾸지 않는다. GS-01_001도 N3 제외와 무관하게 대상 문구를 평가한다.

사용자 확정 정책:

- 제품 용기·패키지 인쇄, 명시적으로 적용되는 상품 브랜드 로고는 제외한다.
- 논문 자체의 본문·참고문헌은 제외한다. 상세페이지가 별도로 작성한 시험 결과·효능 설명·원료 주석은 포함한다. 논문 위에 겹친 별도 설명도 포함하며, 논문 이미지라는 이유로 통째로 지우지 않는다.
- 설명·효능·사용법·주의사항·수치·단위·각주는 번역 대상이면 작은 글씨라도 포함한다.
- 특허·시험성적서·인증서는 논문과 같다고 임의 해석하지 않는다. 기존 일반 문서 포함 원칙을 유지한다.
- 논문 제목·저자·표·그림 캡션의 정책, 기프트카드·인증 마크·협업/타브랜드의 불명확한 처리는 미결로 둔다. 판독 불가를 빈 GT로 바꾸거나, CER가 높다는 이유로 제외하지 않는다.

이 정책의 서비스 적용 의도는 사용자 결정이지만, v1.0.1에 논문 본문/참고문헌 제외 구현이 있었다는 뜻은 아니다. 기존 문서 캡처 처리 규칙과의 차이 및 PM·BE 후속 합의는 [정책 보고서](../../analyses/ocr-translation-scope-policy-20261109/README.md)에 기록한다. 이 명세로 제품 동작·API·DB 계약을 변경하지 않는다.

## 영역과 GT·출력의 대칭 범위

원본 이미지의 큰 의미 영역을 포함/제외/검토 대상으로 주석한다. bbox 정확성 점수는 산출하지 않는다. 현재 주석은 대략적인 위치 안내이며 사각형 안의 모든 문자를 같은 대상으로 확정한 마스크가 아니다. 포함 문구를 포장 사진과 함께 덮거나, 논문 위 효능 설명을 제외하지 않도록 범위 연결 검토가 필요하다.

GT line ID → 승인된 범위와 OCR region → 같은 범위의 연결을 별도로 보존한다. GT에서만 텍스트를 제거하거나, 출력과 문자열이 비슷한 GT만 선택하지 않는다. 기존 텍스트 전용 동결본에는 검증된 줄별 범위 연결이 없으므로 자동 필터 입력으로 바로 사용할 수 없다.

후속 필터 구현 전 확정할 조건:

1. 원본/범위/GT 버전과 해시가 일치하고 정책 미결이 없어야 한다.
2. 하나의 OCR 결과가 포함·제외 영역을 함께 덮으면 문자열을 임의 분할하지 않는다. 원본과 연결을 확인하기 전 `undetermined`로 관리한다. 완결되지 않은 섹션을 일부 좋은 문자만 골라 완결 결과로 표시하지 않는다.
3. 누락된 대상 GT는 D, 대상 범위의 추가·중복 출력은 I로 유지한다. 비대상 판정에는 원본 의미 근거가 필요하다. 오검출 좌표가 제외 영역으로 이동해 삽입 오류가 숨겨지는 편향도 검증한다.
4. 큰 사각형의 부분 교차는 검토 후보 생성에만 쓴다. 겹침 비율/중심점 임계값이나 포함·제외 우선순위를 이번 초안에서 임의 확정하지 않는다.
5. GT 범위 연결, 출력 경계 통과, 영역 중첩, 좌표 부재/범위 이탈, 정책 미결을 구별해 기록한다. 출력 원문·해시·region ID는 그대로 보존한다.

## 계산·예외·집계

범위가 승인되고 완전한 GT/출력 연결이 확보된 섹션에만 계산한다. `CER = (ΣS + ΣD + ΣI) / ΣN × 100`; N은 **포함된 GT의 정규화 문자 수**다. 문자 수로 가중 집계하며 섹션별 비율을 단순 평균하지 않는다. 100% 초과를 자르지 않는다.

NFC·공백 제거·코드포인트·대소문자/문장부호 보존 및 반복 횟수는 기존 명세를 유지한다. 줄 내부 순서를 보존하고, v5 A2 순서 대응은 후속 검증 후보로 재사용한다. v5의 휴리스틱/분리·병합 한계를 해결됐다고 간주하지 않는다.

- 범위상 대상 없음: `not_applicable`, N=0, CER `— / 해당 대상 없음`. 라벨/논문 전용과 무문자 이미지를 사유로 구분하고 출력 증거는 보존한다.
- 포함 대상은 있으나 GT 불완전·정책/경계 미정: `undetermined`. 0오류나 비대상으로 대체하지 않는다.
- 정상 OCR 빈 반환: 대상 N자 삭제. 실행 실패·사용 가능한 출력 없음은 `no_output`; 파일·해시·형식 검증 오류는 `evaluation_failed`로 산출을 차단한다.
- 대상은 있지만 정상 측정 섹션이 0개: `— / 정상 측정 0건`, 원인별 수를 함께 표시한다.
- 전체 112개·대상·비대상·미결·실패·실제 측정 섹션 수, GT 문자 분모를 공개한다. 미측정 GT가 불완전하면 전체 문자 분모를 추측하지 않는다. 일부만 계산한 값을 112개 전체 결과로 부르지 않는다.

## 재현과 버전 비교

112개 원본 바이트, 정책 버전, 승인된 영역, GT line 범위 연결, 사용자 승인, GT·명세·필터·채점기 해시를 함께 고정한다. 제품별 보정 후 출력·제품 SHA·환경·설정·출처도 기록한다. v1.0.1·2차·3차에 동일 입력/정답/범위를 적용하며 제품의 N3/라벨/로고 출력으로 범위를 다시 만들지 않는다.

기존 v4/v5와 분모가 달라질 수 있으므로 새 결과를 과거 값 대비 OCR 개선률로 해석하지 않는다. 동일 새 기준으로 각 버전을 평가한 뒤에만 비교한다. 이번에는 새로운 GT·점수·필터를 만들지 않았으며, OCR02·H01~H05·OP01~OP07 정의는 변경하지 않는다.
