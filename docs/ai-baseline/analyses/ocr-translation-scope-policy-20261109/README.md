# OCR 평가 범위 정책 확정 및 GT 재검수 재산정

2026-11-09 · 사용자 이번 요청으로 **정책 확정**. 영역 주석/GT 연결은 검증 전, 실제 채점 가능 범위는 아직 동결하지 않았다. 기존 18개 재전사 초안을 보존하고 추가 전사는 하지 않았다. [이전 조사](../ocr-translation-scope-20261109/README.md)는 당시 결정 대기 이력으로 보존한다.

## 1. 정책과 분류

- N3 포함/제외를 OCR 범위에 적용하지 않는다. 원본의 고정된 번역 대상 문구를 독립 평가한다.
- 논문 본문·참고문헌 제외. 논문과 별개로 작성한 효능 설명·시험 결과·각주는 포함.
- 포장 인쇄·상품 브랜드 로고 제외 유지. 작은 설명·주의·수치·단위는 포함.
- 기프트카드/인증 마크/타브랜드 미결을 새 제외 규칙으로 채우지 않는다.

| 상품 | 포함 | 혼합 | 제외 | 정책 보류 | 합계 |
|---|---:|---:|---:|---:|---:|
| GS-01 | 12 | 12 | 1 | 0 | 25 |
| GS-02 | 37 | 10 | 0 | 1 | 48 |
| GS-03 | 27 | 9 | 3 | 0 | 39 |
| 전체 | 76 | 31 | 4 | 1 | 112 |

이전 조사와 개수는 같지만 GS-02_008/sec_1_04 내부의 논문 범위는 바뀌었다. 섹션에는 여전히 별도 설명과 포장 인쇄가 함께 있어 혼합이다. 위 표는 **이번 정책에 따른 섹션 구성 분류 기록**이며 112개 모두의 측정 가능 최종 확정이 아니다. 포함/혼합 안에도 일부 정책 미결이 있다(총 9개 섹션). [전체 목록](sections.md), [영역·이미지 해시 색인](scope-annotations.json).

제외 4개: GS-01_002/sec_1_24(패키지/브랜드), GS-03_018/sec_1_09(브랜드), GS-03_003/sec_1_01·GS-03_007/sec_1_01(무문자 사진/그림). 정책 보류 1개: GS-02_001/sec_1_02 기프트카드. GS-01_001은 N3와 무관하게 혼합으로 유지한다.

## 2. 영역 주석과 처리 가능성

[읽기 전용 주석 화면](regions.html)은 112개 원본을 펼쳐 볼 수 있고 **혼합 31개 전부에 제외 위치 주석**을 제공한다. 기본 포함 영역(I0)·제외 위치(E)·포함/정책 검토 보조영역(X)을 0~100 상대 좌표로 기록했다. 원본 이미지는 복사/변경하지 않았고 로컬 이미지 경로를 참조한다. GitHub에서 이미지 공유 완료를 의미하지 않는다.

주석은 **위치 설명용 큰 사각형**이다. 사각형 안에 일반 문구가 겹칠 수 있어 실행 가능한 마스크가 아니다. 모든 `approved_geometry`와 `automatic_scope_ready`는 false다. 특히 포장 위 콜아웃·기울어진 용기·개발 메모·반사 글자는 대략 박스만으로 안전하게 분리할 수 없다.

논문 섹션에는 참고문헌 제외와 논문 묶음 검토 영역, 별도 효능 설명 3개 패널 및 원료 각주 포함 위치를 구분했다. 논문 본문 제외는 확정이지만 제목·저자·표·그림 캡션은 사용자 결정이 없어 논문 전체를 빨간 제외 영역으로 처리하지 않았다.

기존 보정 후 출력 112개의 입력·출력 해시와 bbox 존재를 읽기 전용으로 점검했다. 좌표 누락 섹션 0개. 출력의 **거친 사각형 경계 교차 후보는 16개 섹션·82개 고유 OCR 영역(영역쌍 85개)**다. [출력 ID·bbox·주석 ID 근거](boundary-feasibility.json). 단순 AABB 부분 교차 조사이며 실제 의미 경계 통과 건수/오류 건수/bbox 정확도 점수가 아니다. 겹침 임계값을 정하거나 실제 출력을 필터링하지 않았다.

예: GS-01_002/sec_1_01(인쇄/배지), sec_1_06(기울어진 용기), sec_1_21(제품과 설명), GS-02_002/sec_1_01(제품/협업 표기), GS-02_008/sec_1_04(논문/설명 중첩). 후보의 region_key와 출력 인덱스를 보존했다. 사각형 안에 완전히 들어오는 결과도 의미상 자동 제외가 검증된 것은 아니다.

**GT와 출력의 동일 범위 적용은 구조적으로 가능하지만 아직 검증 완료가 아니다.** GT v2는 텍스트 전용으로 동결되어 line ID→의미 영역 연결이 없다. 과거 좌표를 검증된 범위 정답으로 쓰지 않는다. 범위를 가로지르는 문자열을 임의로 나누거나, GT에서만 글자를 지우지 않는다. 출력의 오검출 좌표로 제외 영역에 들어가 삽입 오류가 숨는 위험도 후속 검증 대상이다.

## 3. 기존 18개 재검수 재산정

[18개별 처리·근거·예상 작업량](gt-recheck.md), [기계 판독 목록](gt-recheck-18.json).

| 분류 | 개수 | 의미 |
|---|---:|---|
| 알려진 문제는 제외 대상 | 10 | 패키지·로고 인쇄의 미전사는 추가 전사하지 않음. 해당 섹션 전체 GT 완전성 승인 아님 |
| 번역 대상 문구 재확인 | 5 | 각주·수치·개발 메모 등 누락/오전사 여부 확인 필요. 오류 확정 아님 |
| 논문/별도 설명 범위 재확인 | 1 | 논문 본문·참고문헌 전사 중단, 별도 설명/각주 유지, 제목·표 정책 대기 |
| 포함 문서의 보완 필요 | 2 | 특허증·시험성적서의 기존 미완성 내용 |

**실제 재검수 후보는 8개**다. 이 중 즉시 전사 오류가 확정된 8개라는 뜻은 아니다.

| 섹션 | 남는 확인/보완 |
|---|---|
| GS-01_002/sec_1_06 | 하단 L024~L028 각주, 성분·숫자·기호 |
| GS-02_008/sec_1_01 | 15μm 등 치수·단위·각주 |
| GS-02_008/sec_1_04 | 별도 효능 설명 3개 패널·원료 각주, 논문 제목/표 범위 |
| GS-02_008/sec_1_05 | 특허증 본문·날짜·이름·주소; 판독 가능성 먼저 확인 |
| GS-02_014/sec_1_11 | 개발 사진 속 비라벨 손글씨·메모 |
| GS-03_013/sec_1_01 | L014 시험 각주 숫자 |
| GS-03_014/sec_1_01 | 두 시험 문서 본문·표·ORAC 수치 |
| GS-03_018/sec_1_08 | 하단 주석·LV별 설명, 제품 외 텍스트 |

GS-02_002/sec_1_01 좌표형 GT 두 줄과 GS-02_014/sec_1_09 빈 L008의 알려진 위치는 제외할 포장 인쇄다. 이번에 GT를 삭제/수정하지 않았으며, 향후 별도 범위 연결로 제외하는 것이지 잘못된 전사를 승인하는 것은 아니다. GS-01_002/sec_1_22의 가려진 성분 문구도 포장 인쇄이므로 추가 전사하지 않는다. 하단 인증 마크는 별도 정책 미결이다.

작업량은 기존 18개에 대한 **8개 섹션의 대상 영역 확인**, 알려진 보완 문서 **특허 1개 영역 + 성적서 2개 영역**으로 재산정했다. 신규 줄 수/소요시간은 판독 가능성과 범위 승인 전에는 산출 불가다. 또한 18개 밖 GS-02_013/sec_1_02 인증서의 완전성 확인, 전체 혼합 31개 GT 줄의 범위 연결은 별도 작업이다. 기존 53개 AI 단독 검수 이력은 그대로 유지한다.

## 4. 명세·서비스 정책 차이

새 [OCR01 v6 범위 명세 초안](../../protocols/v1/ocr-v6-scope-draft.md)을 추가했다. v4·v5 정의/파일/결과는 변경하지 않았다. N3 독립 범위, 논문 제외, 대칭 범위 연결, 예외 상태와 고정 버전 비교 요건을 정의했다. CER 공식·정규화는 유지하되 새로운 대상 분모는 아직 산출하지 않는다.

**서비스 적용 의도는 사용자 확정, PM·BE 합의/실제 구현은 별도 확인 필요**다. 기존 `docs/ai/pipeline.md` 7.4절은 문서·화면 캡처를 문서라는 이유로 라벨 처리하지 않는다. v1.0.1에도 논문 본문·참고문헌을 일괄 번역 제외하는 근거가 확인되지 않았다. 따라서:

- 논문/참고문헌의 식별·제외 단위, 별도 효능 설명 보호 방식에 대한 PM·BE/AI 합의가 필요하다.
- 기존 `is_product_label`/브랜드 로고 플래그를 논문에 임의 재사용하거나 새 API/DB 필드를 정하지 않았다.
- 실제 v1.0.1의 번역 처리 범위와 새 평가 정책이 같다고 표현하지 않는다. 사용자 의도에 맞춘 고정 평가 범위로 비교한다.
- 서비스 정본·제품 코드·H01~H05·OP01~OP07은 변경하지 않았다.

## 5. 남은 결정과 다음 순서

사용자 결정: 논문 제목·저자·표·그림 캡션까지 제외할지, 기프트카드/인증 마크/협업·타브랜드 처리. 확정된 본문·참고문헌 제외와 작은 번역 대상 포함은 다시 승인받을 사항이 아니다.

1. 위 미결 정책만 결정하고 범위 주석을 사람이 의미 단위로 확인한다. 픽셀 단위 bbox 정밀 검수는 필요하지 않지만 포함 문구를 제외 사각형이 덮지 않는지는 확인해야 한다.
2. 8개 후보의 대상 부분만 검수·필요 보완하고, 기존 GT 줄과 범위 연결을 별도 데이터로 작성한다. 10개의 제외 문제는 추가 전사하지 않는다. 승인 후에만 새 GT 동결.
3. 고정 범위의 GT/출력 대칭 연결·경계 미정 차단을 구현하고 누락/추가/중복/경계/좌표 오류를 합성 검증한다. v5 대응 알고리즘 한계도 별도 검증한다.
4. 같은 원본 112개·승인 GT·범위·명세·필터 해시를 v1.0.1·2차·3차에 고정한다. 기존 출력 재사용 가능성을 확인한 뒤 별도 승인으로 재측정한다.

이번에는 GT 전사·수정·동결, OCR 실행·CER 채점·API 호출, 커밋·push·PR을 하지 않았다. [검증 기록](validation.json)과 [기존 자료 해시](preserved-hashes.json)로 보존 상태를 확인한다.
