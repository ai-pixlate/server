# OCR v6 기준선 결정안·GT 완전성 점검

2026-11-10 · 사용자 결정 전 · GT/영역/코드 미수정 · 실제 CER 미계산

## 검증 범위와 결과

[채점기 준비 보고서](../../preparations/ocr-v6-scorer-20261109/README.md)와 기존 범위/검수 이력을 재사용했다. 실제 112개 입력에 채점 없는 preflight를 다시 실행하여 이미지·GT·출력·연결·보호 파일 해시를 검사했다. **필터 완료 107개(적용 103·전체 제외 4), 차단 5개, 범위/새 포함 GT 완전성 승인 미등록** 상태가 유지됐다.

[validation.json](validation.json)은 112개 각각의 이미지 경로·해시, 포함/제외/보류 GT ID와 빈 줄을 기록한다. 기존 1,861줄은 포함 1,208 / 제외 518 / 연결 보류 135로 분류된다. 포함 수에는 차단 섹션에서 연결된 줄도 들어 있으므로 실제 측정 분모나 승인된 GT량이 아니다. 문자 오류·CER은 계산하지 않았다.

이번에 원본을 다시 직접 연 대상은 설문 배지, 좌표형 GT, 영수증, Q&A, GT 0줄 사진 두 장으로 총 6개다. 나머지는 기존 원본 검토·검수 근거와 해시를 재사용했다. 112개 전체를 새로 육안 전수검수했다거나 무누락을 인증했다고 표시하지 않는다. 기존 사용자 미검수 53개의 상태도 바꾸지 않았다.

## 5개 차단: 추가 반복 조사 대신 선택할 방법

| 대상 | 최종 분류 | 추천과 필요한 조치 |
|---|---|---|
| GS-01_002/sec_1_04 설문 배지 | 현행 증거로 해결 가능(연결 확정 전) | 원본에서 98/96/95%와 사용감·추천·마무리 설명은 로고와 공간적으로 구분된다. 원형 배치만으로 제외하지 않는 기존 정책에 따라 설문 문구·수치를 포함하고 POWDER ROOM 로고를 제외하는 세부 연결안을 후속 작성. 곡선 제품명과 로고 접점은 함께 확인. 기존 OCR이 그 경계를 넘으면 해당 부분만 다시 보류하며 현재 완료로 승격하지 않음 |
| GS-02_002/sec_1_01 좌표형 GT | 현행 증거로 해결 가능(새 GT 교정 승인 필요) | L005·006은 원본에 없는 좌표형 데이터. 새 GT 버전에서 두 줄을 폐기 표시하고 평가 문자열에서 제거, 나머지 ID·텍스트·순서 유지. 아래 교정안 참조 |
| GS-01_002/sec_1_23 Good all goodal | 새 입력 필요(안전한 자동 공간 분리 경로 선택 시) | 일반 문구만 담는 고정 crop 후보를 원본 기준으로 정의·검수한 뒤 별도 로컬 OCR. 단일 기존 문자열의 추측 분할은 금지. crop을 선택하지 않으면 현 입력에서 undetermined 유지 |
| GS-03_005/sec_1_01 숫자 3 | 새 입력 필요(안전한 자동 공간 분리 경로 선택 시) | 제형 숫자를 제외한 설명/각주 crop 세트가 대안. 각주가 모두 들어가는지 먼저 확인. 기존 과대한 bbox를 숫자 문자열만 보고 제외하지 않음 |
| GS-03_014/sec_1_03 b3+ | 평가 규칙 결정 필요 | 배경과 전경이 같은 공간에 있어 사각 crop으로 해결되지 않음. **분리 증거 없는 혼합/겹침은 모든 버전에서 undetermined로 유지**하는 원칙 권장. 배경을 GT에서만 삭제하거나 섹션 전체를 not_applicable로 바꾸지 않음 |

Good all과 3의 기존 출력에는 안전한 문자 단위 위치 근거가 없다. 현재 증거의 반복 분석으로 이를 얻을 수 없다. 추가 입력도 원래 112개 full-section 출력과 동일 조건의 결과는 아니다.

### 교정안(적용하지 않음)

GS-02_002/sec_1_01:

- L005 기존값 `313, 638, 404, 807`
- L006 기존값 `304, 595, 396, 780`
- 원본에는 해당 숫자열이 보이지 않는다. 중앙 포장과 우측 배지·모공 탄력, 하단 구성 안내를 확인했으며 숫자열에 실제 텍스트 위치를 부여할 수 없다.
- 새 GT 버전 변경 이력에 두 ID를 `원본에 없는 초안 데이터 혼입`으로 기록하고 비활성화할 것을 제안한다. 빈 문자열로 교체해 숨기거나 나머지 L007 이후 ID를 당기지 않는다. 기존 37개 중 평가용 활성 후보는 35개가 되며 추가 전사 0줄이다. 실제 교정·동결은 승인 후 별도 작업이다.
- 나머지 포장/로고 제외와 상세 설명 포함 연결도 별도 검증해야 하므로 이 교정만으로 필터 완료를 보장하지 않는다.

### 대안의 영향

| 대안 | 장점 | 비용·한계 |
|---|---|---|
| 현 입력 유지 + 혼합/겹침 보류 | 원본·기존 출력 유지, 임의 오류 삭제 없음, 추가 실행 0 | 완결되지 않은 섹션이 남아 112개 전체 CER 확정 불가. 측정 부분값과 미측정 상태를 함께 공개해야 함 |
| 별도 고정 crop 입력 버전 | 분리 가능한 두 섹션의 자동 평가 가능성을 높임 | crop 수 K를 먼저 설계해야 함. v1.0.1과 이후 각 버전마다 K회 기본 로컬 OCR 필요. 정확한 K·시간은 아직 미정. 입력 문맥이 달라 기존 full-section 결과와 직접 비교 불가 |
| 배경/전경 마스크 또는 문자별 수동 대응 | 겹침 문제의 별도 해결 가능성 | 새로운 입력/대응 규칙과 독립 검증 필요. 마스크는 실제 서비스 입력을 변형하고 수동 대응은 이후 버전마다 검수 부담. 현재 v6 공식 규칙으로 도입하지 않는 것을 추천 |

사용자 결정은 **① 두 GT 줄 교정안 적용 허용, ② 두 섹션의 별도 crop 평가를 추진할지 현 입력 보류로 둘지, ③ 분리 불가능한 겹침을 undetermined로 남기고 부분 측정만 공개할지 전체 수치 확정을 계속 기다릴지**다. ③을 선택해도 기존 범위/채점 정의는 몰래 축소하지 않으며 전체 공식 CER은 null로 둔다. 설문 수치/로고 정책은 재승인 대상이 아니라 기존 정책의 연결 작업이다.

## 포함 GT 완전성·추가 사용자 확인

| 대상 | 원본/검수 근거 | 필요한 확인 |
|---|---|---|
| GS-02_002/sec_1_01 L005·006 | 원본에 없는 숫자열 두 줄 | 위 교정안 승인 |
| GS-01_002/sec_1_04 배지 | 핑크색 원 3개 상단 설문 문구·중앙 수치·하단 로고/곡선 제품명 | 포함 문구가 세부 연결에서 빠지지 않는지 최종 묶음 확인. 배지 전체 재전사는 불필요 |
| GS-02_001/sec_1_03 L028–052 | 원본 중앙 두 영수증, 대략 y=1230–1445. 작은 표제·상품명·교환 안내가 포함 범위에 있음 | **25개 기존 줄 한 묶음** 원본 대조 권장. 특히 왼쪽 영수증 마지막 줄의 문장 끝과 GT L051의 끝이 완전한지 확인 필요. 현재 보기만으로 교정 문자열을 확정하지 않음 |
| GS-02_014/sec_1_09 L008 | 빈 정답 유지 결정 이력. 말풍선 사이 배경 제품 인쇄와 Q&A 본문을 원본으로 구분 | Q&A 문구는 기존 GT에 있어 이번 대조에서 추가 누락 근거 없음. L008을 임의 채우지 않음; 빈 줄과 OCR 독립 범위 적용 확인만 승계 |

기존 미전사 수용 16개의 원래 사유는 대부분 포장·라벨·반사·논문·특허증·시험성적서 내부였다. 최신 정책에서 이 내부 미전사를 채우도록 요청하지 않는다. GS-02_014/sec_1_11의 별도 손글씨, GS-02_008/sec_1_04의 인용문, GS-03_018/sec_1_08의 각주는 기존 대조 근거와 GT를 승계한다. 이는 16개 전체 무오류 인증이 아니며 포함 영역이 바뀌면 다시 점검한다.

최소 추가 검수 묶음은 **좌표형 두 줄, 설문 배지, 영수증**의 3섹션이다. 앞 두 개는 차단 해소 작업과 겹친다. 실제 신규 전사량은 영수증 검수 전에는 확정할 수 없으며 전체 1,861줄 재전사는 권장하지 않는다. 사용자 미검수 53개를 이번에 검수 완료로 바꾸지 않고, 기존 표본 검수 방식을 승계할지 범위 승인 시 명시해야 한다.

### 정답 0자 구분

- **실제 무문자:** GS-03_003/sec_1_01(목·손 사진), GS-03_007/sec_1_01(액체/방울 사진). 원본 직접 재확인, 기존 GT 0줄·전체 제외와 일치.
- **정책상 전체 제외:** GS-01_002/sec_1_24, GS-03_018/sec_1_09. 기존 근거상 제품 인쇄/사진 제외. GT가 존재하더라도 적용 GT는 0이며 위 무문자 두 개와 사유를 구분.
- **연결 보류로 포함 GT가 0:** GS-01_002/sec_1_04, GS-01_002/sec_1_23, GS-02_002/sec_1_01. 실제 텍스트가 있고 GT 연결이 보류됐으므로 무문자/비대상이 아님.
- 필터 완료·평가 대상 103개 중 포함 GT가 전부 빈 섹션은 없다. L008의 빈 줄 하나와 섹션 전체 무문자는 다르다. 빈 줄이 없다고 미전사 누락도 없다고 판단하지 않는다.

## 공식 전환 절차와 권장 순서

1. 위 3가지 방법/교정 결정에 답한다. 기존 v2·v4·v5는 그대로 보존한다.
2. 설문 배지 연결, 새 GT 버전의 두 줄 교정, 영수증 묶음 검수만 수행한다. 변경 전후 ID·해시·원본 근거와 사용자 확인을 기록한다. 이번에는 수행하지 않았다.
3. crop을 선택했다면 **생성 전에** 원본 기준 포함 범위·crop 수·GT 연결을 확정한다. 별도 입력 버전/부모 이미지 해시/좌표를 보존하고 모든 통합 버전에 동일 입력을 제공한다. 기존 출력과 조용히 혼합하지 않는다.
4. 범위 승인: 전체 112개의 포함/제외/보류 목록, 미해결 처리와 고정 영역 해시 승인. GT 완전성 승인: 포함 영역 검수·교정과 표본 검수 한계 승인. 명세 승인: v6 범위, v5 A2 대응의 휴리스틱 한계, 예외/집계와 코드 해시 승인. 세 승인을 구분한다.
5. 별도 v6 기준선 manifest에 입력/GT/범위/정책/명세/채점기·Unicode 버전, 제품 SHA와 출력 출처를 고정한다. 2·3차에는 제품 출력만 바꾸고 동일 평가 조건을 확인한다. 변경된 crop/GT/정책은 또 다른 기준선으로 관리한다.
6. 실제 측정 승인을 받은 뒤 실행한다. 미측정이 남으면 measured subset과 사유를 공개하고 전체 CER로 표현하지 않는다. 기존 v4와 v6의 차이는 범위/방법 차이이므로 OCR 제품 개선율로 해석하지 않는다.

현재는 검증/결정안 작성만 완료했다. 전체 112개 공식 수치를 확정할 준비가 됐다고 표시하지 않는다. GT·필터·채점기·동결본·평가 결과·원시 증거와 기존 미커밋 작업을 보존했으며 커밋·push·PR, crop 생성·OCR/API 호출·CER 계산을 수행하지 않았다.
