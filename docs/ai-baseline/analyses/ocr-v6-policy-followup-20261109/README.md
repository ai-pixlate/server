# OCR v6 사용자 후속 확정 정책 반영

2026-11-09. 검수 JSON과 뒤이은 사용자 명시 결정을 구분한다. D06의 JSON include는 후속 정책으로 대체됐다. 정책·범위 연결 의견만 반영하며 GT·OCR 원문·기존 결과·동결본을 변경하지 않는다.

## 반영한 결정

- D01·D03·D04는 사용자 검수의 라벨 제외, D02는 텍스트 없음 제외를 범위 연결 기록에 반영했다. 좌표형 문자열 자체는 수정/삭제하지 않았다.
- D05는 원본에서 번역 대상 밖인 얼굴·배경의 오검출 제외. 대상 영역 내부 오검출은 I로 유지한다. 같은 원본 얼굴의 reg_0002 `F`에도 이 정책을 적용하는 연결 의견을 기록했으며, 사용자 항목별 직접 판정과 분석 적용을 구분했다.
- D06은 일반 설명 포함·로고 제외를 유지한다. `Good all goodal` 원문을 분리하지 않고 undetermined를 유지한다.
- D07 용기 반사상 제외를 기록했다.
- 특허증·시험성적서 내부 문구는 제외, 별도 설명·요약·인용은 포함한다. 내부 내용을 다시 전사할 필요가 없으며 내부 L018 교정 후보도 현 범위 GT 보완 대상에서 빠진다.

## 영향받은 GT·OCR 연결 재검토

| 섹션 | 기존 GT 범위 연결 | OCR 상태 |
|---|---|---|
| GS-02_008/sec_1_05 | L013–014 증서 제목 제외. L001–012 및 L015 별도 설명·각주 포함 | 증서와 외부 설명 경계 재검증 필요 |
| GS-03_014/sec_1_01 | L011–025, L034–036 문서 내부 제외. L001–010 및 L026–033 별도 제목·설명·인용 포함 | 문서 위 인용 상자와 문서 본문 경계 재검증 필요 |

두 섹션은 문서 내부와 별도 설명이 공존하므로 기존 포함→혼합이다. 기존 112개 분류의 단순 정책 갱신은 포함 73 / 혼합 35 / 제외 4이며, 새 원본 기반 번역 영역 검증 완료 수가 아니다. 기존 혼합 33개 보고서는 당시 이력으로 보존한다.

[GT 연결 의견 55개](gt-scope-decisions.json), [OCR 개별 연결 의견 4개](ocr-scope-decisions.json)는 별도 기록이다. 문서 두 섹션의 [OCR 86영역](document-ocr-pending.json)은 모두 원시 파일 해시를 확인했으나 개별 대칭 영역 연결을 새 정책으로 완료하지 않았으므로 보류했다. 86개 모두가 정책적으로 모호하다는 뜻이 아니라 기하 검증이 남았다는 뜻이다. 텍스트 유사도로 성급히 포함/제외하지 않는다.

## 남은 미결·실행 차단

1. **Good all goodal:** 한 반환값 안의 설명/로고를 안전하게 분리할 근거가 없다. 전체 포함·전체 제외·GT 기준 잘라내기 모두 사용하지 않는다. 후속 해결 후보는 원본 고정 범위와 문자/단어 위치 근거가 연결된 출력으로 검증하는 방식이다. 현재 문자별 위치 근거의 확보·유효성이 검증되지 않아 해당 영역과 이를 포함한 섹션의 완결 점수 산출을 보류한다. 추가 실행은 이번에 하지 않는다.
2. **원본 번역 대상 영역의 양쪽 경계:** 기존 I0 전체 이미지 포함 방식은 새 비텍스트 오검출 제외 정책에 충분하지 않다. 실제 텍스트의 출력 bbox에 맞춰 영역을 매번 줄이지 않고, 원본 기준 고정 영역으로 GT·OCR에 동일 적용하는 경계가 필요하다. 일반 효능 그림에서 검출된 `√` 등도 대상 영역 안/밖 확인 전 추가 판정을 확정하지 않는다.
3. **특허증·시험성적서의 문서/별도 인용 경계:** 위 GT 의미 연결은 정리됐지만 OCR 86영역의 대칭 범위 검증이 남았다. 문서 전체 사각형으로 별도 인용을 지우지 않는다. 새 정책상 내부 미전사는 추가 GT 보완 차단 사유가 아니다.
4. **공통 필터 명세:** 포함 설명 창을 문서/사진 제외 영역에서 차감하는 규칙, 혼합 반환값 처리, 제품별 region ID가 바뀌어도 동일 범위를 적용하는 검증을 완료해야 한다. 영역·GT 새 버전 승인/동결 및 채점기 검증은 아직 수행하지 않았다.

## 서비스 공유에 대한 의미

PM·BE에 공유할 최신 요지는 논문뿐 아니라 특허증·시험성적서 내부도 번역 제외하고, 상세페이지의 별도 효능/결과 요약/인용을 유지한다는 것이다. 이는 사용자가 확정한 정책이며 v1.0.1 구현이 이미 같다는 검증은 아니다. 서비스 코드·계약 변경이나 실제 공유는 하지 않았다.

기존 사용자 검수 화면은 당시 자료 해시와 판정 이력을 보존한다. 화면의 D06 추천/검수 JSON이나 G01·G02 전사 후보를 최신 정책으로 오인하지 않도록 이 문서를 함께 참조한다. 최신 평가 정책은 [v6 초안](../../protocols/v1/ocr-v6-scope-draft.md)에 반영했다. [검증 기록](validation.json): 보호 파일 232개 불변, GT 수정·CER 실행 없음.
