# 측정 결정

> 상태: `v1-draft` · `pm_review_pending` · 1~5단계 사용자 확정 · PM 승인 전 · 공식 실측 승인 전

이 문서는 최신 입력본과 충돌하지 않는 기존 실행 결정을 보존한다. 명세 전체의 확정이나 PM·실측 승인을 뜻하지 않는다. 지표와 집계는 [최신 집계 명세](protocols/v1/aggregation.md)를 따른다.

## 목적

- 이후 고도화의 비교 기준이 되는 단계별 품질을 확보한다.
- 최종 발표에서 품질 개선 노력과 결과를 설명할 근거를 확보한다.

## 실행 환경

운영·학교 서버와 동일한 환경을 재현하는 것을 필수 조건으로 두지 않는다. 현재 Windows PC에서 CPU OCR·로컬 GPU LaMa·전용 Python 가상환경·로컬 PostgreSQL·격리 BE 실행기를 사용한다. 검증된 구성을 고정하고, 후속 비교에서는 고도화 대상 외의 실행·평가 조건을 유지한다. 세부 조건은 [실행 명세](protocols/v1/execution.md#로컬-실행-환경과-재현-조건)를 따른다.

## OCR 품질 표본의 실행 제한

1.0.0 이미지 변환 baseline에서는 GS-01~03 원본 34장 전체 평가를 우선한다. 이 평가에 포함된 기존 OCR 품질 표본 12개에 대해서는 [OCR 채점 명세 v3](../ai-experiments/2026-09-25_02-ocr_scoring-spec-v3.md)의 정답 동결 전 OCR 실행 금지 제한을 해제한다.

기존 정답 초안은 보존하되 검수된 정답으로 사용하지 않는다. 독립 OCR 정량 평가를 완료한 것으로 간주하지 않으며, 과거 실측 결과와 채점 명세 원문은 보존한다. 향후 OCR 정량 평가에서는 정답 작성·검수 이력과 평가할 OCR 출력의 노출 여부를 별도로 관리한다. 출력에 노출되지 않은 검수자가 원본을 기준으로 정답을 작성하는 방식은 사용할 수 있다.

이 결정은 1.0.0 baseline의 입력 제한에 대한 예외다. 다른 OCR 실험의 제한을 일괄 폐기하거나, 계획 승인만으로 실제 OCR 실행을 허용하는 결정은 아니다.

## 규제사전 경고의 처리

사용자가 제공한 `regulation_dict_20260930.xlsx`(SHA-256 `ce2f95e1b7f21eb90cbba551d6c976fb11efabf608392521ae0970a288ddacbc`)의 RG-021·RG-022 대체 표현 경고는 1.0.0 baseline 실행의 차단 조건으로 두지 않는다. 적재된 원본 값을 유지하며, 경고와 실제 처리 결과는 측정 기록에 남긴다. 릴리즈의 검증·실패·제외 처리를 우회하거나 해당 항목을 품질 합격으로 간주하지 않는다.
