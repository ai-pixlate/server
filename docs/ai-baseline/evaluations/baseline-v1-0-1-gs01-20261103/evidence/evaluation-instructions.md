# GS-01 AI 최초 부분 평가 지침

GS-01 두 원본과 PM 승인 58개 동결 단위만 평가한다. 원본 34장의 성능으로 일반화하지 않는다.
H01은 동결 정책 기대와 N6 실행 기록으로 산출한다. GS-01_001 전체 제외는 정상이며 H01/H04 미적용, H02/H03도 정상 제외로 not_applicable이다.
GS-01_002는 원본과 machine_snapshot 23개 섹션 및 service_final 전체를 직접 대조한다. 그림 전체를 1400px 높이 27개 보기로 빠짐없이 확인한다.
각 보기의 좌측은 원본, 우측은 최종이다. 별도 픽셀 검증에서 23개 machine_snapshot 모두 최종의 대응 영역과 동일함을 확인했다. 두 체크포인트에 별도 평가 기록과 산출물 연결을 남긴다.
H04는 동결 critical_fact 28개에 대해 이미지의 정확성과 가독성을 각각 판단한다. 4개 정상 제외 단위는 분모에서 제외한다. 번역 텍스트가 존재한다는 이유만으로 이미지 가독성을 통과시키지 않는다.
결함 유형/심각도/최초 원인 단계는 protocols/v1/evaluation.md를 따른다. A/B/C는 기록한 결함을 기존 도구로 집계한다. 원인을 입증할 수 없으면 undetermined.
동일 섹션의 연결된 글자 충돌은 하나의 배치 결함으로 기록하고 그 영향을 묶는다. 독립적인 사실 오류/보호 오판/경고 누락은 별도 결함이다. 같은 결함의 최종 전파는 같은 root_defect_id를 사용한다.
허용 표현은 결함으로 세지 않는다. 조건부 경고는 N5 전달 기록과 대조한다. 실제 미국 시험/인증 충족은 평가하지 않는다.
AI 최초 판단만 기록한다. PM의 K01~03/critical/major/불확실 판단 검수는 미실시이며 human_review.csv를 채우지 않는다. 평가용 API/재생성/GS02·03 채점은 금지한다.
현재 채팅 모델의 정확한 이름과 설정을 증빙으로 확인할 수 없으므로 미확인으로 기록하며 GPT-6 Astra(light)라고 단정하지 않는다.
