[PR #153 준비 묶음](../../preparations/h01-h04-official-20261124/README.md)과 `baseline-v1-0-1-gs-v1-20261030-01` 실행의 원본 34장·승인 기준 339개만 사용했다. 생성된 최초 섹션 미리보기 67장과 최종 이미지 13장을 **각각 실제 시각 확인**했다. 원본·미리보기·최종본의 확인 구간·해시는 [visual-coverage.json](visual-coverage.json), 섹션 순서·오프셋 대조는 [section-order-check.json](section-order-check.json)에 있다.

## 최초 집계

H02~H04 품질 비율의 분모는 정상 측정(`measured`)만이다. 아래 비율은 미생성·판정 불가를 성공으로 간주하지 않는다. 전체 적용 대상을 나타내는 평가 가능률을 반드시 함께 읽어야 한다.

| 지표 | 최초 결과 | 분모·예외 |
|---|---|---|
| H01 기대 산출물 생성률 | **13/31 = 41.94%** | 원본 34장 중 정상 전체 제외 3장만 분모 제외. GS-03 미생성 18장은 실패 분모 유지 |
| H02 최초 결과 등급 | **A 1/12 = 8.33%, B 8/12 = 66.67%, C 3/12 = 25.00%** | 측정 12, 판정 불가 1, 미생성 18, 미적용 3. 평가 가능률 **12/31 = 38.71%** |
| H03 최종 결과 등급 | **A 1/12 = 8.33%, B 8/12 = 66.67%, C 3/12 = 25.00%** | H02와 같은 건수. 최종본 별도 확인 결과이며 자동 전파한 점수가 아님 |
| H04 최초 핵심 정보 보존 | **107/110 = 97.27%** | 적용 178, 측정 110, 판정 불가 1, 미생성 67, 미적용 21. 평가 가능률 **110/178 = 61.80%** |
| H04 최종 핵심 정보 보존 | **107/110 = 97.27%** | 최초본과 같은 건수. 핵심 사실 정확성·판독을 별도 확인 |

평가 처리 실패(`evaluation_failed`)는 각 지표 0건이다. H03의 정상 측정 12장 중 미해결 critical 5건·major 18건, 중대 결함 보유 원본 11장(11/12 = 91.67%)이다. 판정 불가 GS-02_003에서도 확인한 major 1건은 관찰 목록에 남기지만 기존 공식 집계기의 measured 범위 합계에는 포함되지 않는다. count 지표의 `denominator=1`은 집계기의 건수 표현이며 1장이라는 뜻이 아니다.

**H04 97.27%는 전체 페이지 사용 가능률이 아니다.** 동결 critical_fact의 수치·조건 보존을 측정하며, 이미지 배치·문서 보호·다른 의미 블록·정책 위반은 H02/H03 결함에 반영된다. GS-03의 평가 불가능한 67개도 품질 분모에 들어가지 않는다.

## PM 검수와 미완료 항목

PM 검수는 **0건**이며 [human_review.csv](human_review.csv)는 헤더만 있다. N3/N5 무수정 확인 이력은 PM 검수로 사용하지 않았다. [PM 검수 계획](pm-review-plan.json)과 기존 도구의 [검수 대기 목록](review-required.json)을 제공한다.

- **K01~K03, K05~K06:** 두 체크포인트의 해당 영역, critical/major 결함, 핵심 정보 근거 확인. K 영역만 본 것을 전체 원본 검수로 확대하지 않는다.
- **K04:** GS-02_002 정상 전체 제외. **K07~K09:** GS-03 N2 실패·미생성 예외. 없는 결과의 가독성은 채점하지 않는다.
- **판정 불가:** GS-02_003 상품명이 `Performance`와 겹쳐 원본 도움 없이 읽을 수 있는지 확정하지 못했다. H02/H03 각각 1건, H04 REF-001 각각 1건을 `undetermined`로 남겼다.
- **추가 확인:** GS-01의 SPF conditional 경고 전달 경로(EI-01), GS-02_009 후기 완충 표현 적합성(EI-02), 저대비 수치 판독, 저자극/hypoallergenic 심각도. 확인하지 못한 사항은 추가 확정 결함으로 가산하지 않았다.
- **A 표본:** GS-02_012가 양 체크포인트의 유일한 A 후보다. [후보 목록과 목록 해시](a-candidates.json)를 보존했으나 기존 추천안의 수·선정 방식은 아직 채택되지 않았고 임의 표본 추출도 하지 않았다.
- **기록 한계:** 정확한 채팅 모델 식별자·생성 설정과 전체 채팅 내보내기는 미확인이다. 실제 관찰·판정 응답과 근거를 보존했지만 독립 재평가 완료를 뜻하지 않는다.

평가 대상 34장의 상태 기록은 모두 존재한다. PM 검수·미판정 해소·A 표본 방식 확인 전에는 최종 공식 확정으로 표시하지 않는다. H05는 `미측정(별도 서비스 평가 예정)`, TQ/OP 통합 집계는 후속 작업이다.

## 검증과 재현

기존 `protocol.validate`의 구조·참조·해시 검증을 통과했고, 기존 집계기로 전체·상품·원본 결과를 계산했다. 준비/프로토콜 20개와 범위 12개, **기존 회귀 테스트 32개 통과**. 세부 결과는 [validation.json](validation.json), [검증 기록](verification.json)에 있다. 기존 정답·실행 증거·평가 명세·PM 승인 자료는 수정하지 않았다. 추가 생성·모델 API·노션 수정·병합도 하지 않았다.

저장소 루트에서 다음 명령을 실행한다. `.cache/h-scoring-replay`와 `.cache/h-scoring-replay-result`는 **존재하지 않는 새 경로**여야 한다. 기존 보존 Git 객체가 로컬에 있어야 입력 복원이 가능하다. 필요한 것은 Python 3 표준 라이브러리와 기존 저장소 도구이며 모델 환경은 필요 없다.

```powershell
python -B -m tools.baseline.evaluation_prepare --materialize docs/ai-baseline/preparations/h01-h04-official-20261124 --output .cache/h-scoring-replay
python -B docs/ai-baseline/evaluations/h01-h04-official-20261124/reproduce.py --input .cache/h-scoring-replay --output .cache/h-scoring-replay-result
```

첫 명령은 보존 입력을 복원하고 두 번째 명령은 이번 최초 평가를 복사·검증·재집계한다. 재평가나 모델 호출이 아니다. `reproduce.py`는 명세·집계기를 변경하지 않는다. 기존 집계기가 내부적으로 계산하는 TQ/OP 등을 발표 자료에 넣지 않고 H01~H04 및 공통 결함만 출력한다. 반복 근거 ID는 [aggregation-basis.json](aggregation-basis.json)으로 분리했으며 각 집계 행의 참조가 연결된다.

이 폴더의 [manifest.json](manifest.json)에 있는 파일 경로는 **위 로컬 복원 디렉터리 기준**이다. 저장소 결과 폴더 자체에서 `protocol.aggregate`를 실행하지 않는다. 이미지와 동결 자료를 새 PR에 중복 저장하지 않았다. [provenance.json](provenance.json)에 입력·지침·최초 기록 해시를 보존했다.

PM이 이미지를 확인할 때 기존 읽기 전용 뷰어를 사용할 수 있다.

```powershell
python -B -m tools.baseline.viewer .cache/h-scoring-replay/generation .cache/h-scoring-viewer
```

뷰어는 이미지 확인용이며 이 폴더의 평가표·결함 ID와 함께 사용한다. PM 수정 판정은 최초 파일을 고치지 않고 `human_review`의 별도 이력으로 연결한다.
