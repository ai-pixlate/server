# 이번 Codex 최초 채점에 적용한 지침

사용자 요청: 최신 develop의 평가 명세, PM 승인 34장·339개 동결 기준, PR #153 준비 자료와 v1.0.1 보존 실행 결과만으로 H01~H04 공식 최초 채점 및 공통 결함 분석을 수행한다. 이미지는 실제 확인하며 추측하지 않는다. GS-03 N2 실패·18장 미생성은 그대로 반영한다. GS-01 Pilot 점수를 재사용하지 않는다. PM 검수와 Codex 평가를 구분한다. 기존 정답·증거·명세 수정, 추가 생성·모델 API·노션 수정, 병합은 금지한다.

적용 정본은 develop `f2b66dc0ca4968104c6499aeafef2774b8f6ab87`의 `docs/ai-baseline/protocols/v1/evaluation.md`, `aggregation.md`, `dataset.md` 및 준비 묶음의 `instructions/evaluation-prompt.md`다. 파일 해시는 `provenance.json`에 기록한다. 준비 묶음에 보존된 과거 상태 문장을 현재 승인 상태로 오독하지 않는다.

- H01은 승인된 적용 여부와 N6 최종 실행 기록으로 계산한다.
- H02/H03은 전체 원본 결과를 각각 확인하고, 확정된 결함의 critical/major 수로 A/B/C를 계산한다. 없는 결과는 no_output이며 C로 만들지 않는다.
- H04는 critical_fact별 정확성·판독 가능성을 각각 판단한다. 불확실하면 undetermined로 기록하고 분모와 평가 가능률을 구분한다.
- 같은 원본의 같은 결함이 두 체크포인트로 전파되면 같은 root_defect_id로 연결한다. 다른 원본의 비슷한 현상이 동일 원인이라는 추정은 하지 않는다. 한 원본에서 관찰한 반복 배치 현상은 위치 목록을 포함한 관찰군으로 기록한다.
- 최초 원인 단계는 직접 확인되는 중간 증거로 정한다. 최종 이미지에서 보인다는 이유만으로 렌더 단계에 자동 배정하지 않는다.
- 원본/미리보기/최종본을 나란히 세로 1,600px 구간으로 확인하고 작은 글씨는 원래 해상도 crop으로 다시 확인한다. crop은 검수 보조물이며 원본 산출물을 수정하지 않는다.
- K01~K09, critical/major, 불확실 판단, 예외, H04 근거를 PM 검수에 연결한다. A 표본 추천안은 채택되지 않았으므로 임의 추출하지 않는다.
- 이번 출력은 공식 평가 회차의 Codex 최초 판단이다. PM 검수 완료 또는 최종 확정으로 표시하지 않는다. H05는 미측정이고 TQ/OP 통합 집계는 이번 산출물에서 제외한다.
