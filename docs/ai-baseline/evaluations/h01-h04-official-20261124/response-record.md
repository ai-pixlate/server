# Codex 관찰·판정 응답 기록

이 파일과 `visual-observations.json`, `evaluations.jsonl`, `defects.jsonl`은 이번 채팅에서 실제 이미지와 보존 자료를 읽고 작성한 평가 응답이다. 전체 대화 내보내기나 독립 재평가 기록이 아니다. 모델의 정확한 식별자·생성 설정은 확인되지 않았다. 기존 Pilot 결과를 읽어 공식 점수로 전사하지 않았다.

## 시각 확인

생성된 원본 13장에 대응하는 최초 섹션 미리보기 67장과 최종본 13장을 각각 확인했다. `visual-coverage.json`의 67개 세로 구간은 원본 전체 높이를 빠짐없이 덮는다. 같은 화면에 놓인 두 체크포인트를 별도로 확인했고, 최종본으로 최초본을 대체하지 않았다. GS-03 결과는 존재하지 않으므로 가상의 이미지 품질을 평가하지 않았다.

GS-01은 제목·본문·배지 겹침, 인증/브랜드 마크 재작성, 용량 50m, 원문에 없는 verified broad spectrum SPF가 확인됐다. SPF 50+/PA++++, 시험값과 인원·기간, Reef Safe·두 불검출 성분, 18 Free의 수치는 별도 대조했다. 15.92%와 6.78%는 저대비·배지 이탈이 있지만 확대 시 읽을 수 있어 H04 보존으로 최초 판정하고 PM 재확인 대상으로 남긴다.

GS-02는 큰 제목이 사진·본문에 침범하는 현상이 반복된다. 그래프 BEFORE 누락, 논문 사진 영문 재작성, 시험 배지의 한국어 잔존, 개발 스케치 재작성도 관찰됐다. 사용량 표의 초급·중급 빈도는 행과 문장이 겹쳐 판독이 어렵고, 콩알 크기는 Soybean Pulp로 번역됐다. 별도 사용법 도식과 Q&A의 기간·주의사항은 보존돼 있으나 표의 실패를 상쇄하지 않는다. 첫 후기의 fine lines ... disappeared는 동결 대체 조건과 불일치한다.

GS-02_003의 제품명은 Performance와 겹친다. 원본을 참고하지 않고 전체 제품명을 읽을 수 있는지 확정하지 못해 H04 해당 항목과 H02/H03 원본 등급을 undetermined로 기록했다. 큰 제목 Seller 잘림 등 확인된 major는 결함 파일에 남긴다. GS-02_012의 각주 전용 이미지에서는 추가 critical/major를 발견하지 않아 A 후보로 기록한다. 원본 끝 1px는 복원 대상이 아니며 22명은 다른 시험의 21명으로 고치지 않는다.

## 원인·불확실성

GS-01 용량 오류는 보존 text_block 41의 source_lines에 이미 50m가 있어 OCR을 최초 확인 단계로 기록했다. broad spectrum 추가, 후기 교체 누락, 콩알/Pulp 및 저자극/hypoallergenic 차이는 원문과 trans_1의 대비로 번역 단계에 연결했다. 사용 빈도 문자열은 번역까지 유지되고 결과 이미지에서 겹쳐 해당 배치 결함은 렌더 단계에 연결했다. 그 밖의 배치·보호 훼손은 최초 발생 단계를 입증하지 못해 undetermined로 기록했다.

GS-01 conditional 판정은 section_verdict에 존재하지만 보존 N5 화면의 필수 경고 목록에는 translation_failed 2개만 있다. 정본이 요구한 SPF 경고가 사용자에게 어떻게 전달됐는지는 이 목록만으로 전체 전달 경로를 단정하지 않고 평가 이슈로 남긴다. 이는 별도의 broad spectrum 추가 결함을 면제하지 않는다.

GS-02_009 후기의 felt like ... tightening my pores 및 일부 improve ... wrinkles 표현의 겉보기 완충 적합성, 일반 자극 시험을 hypoallergenic으로 옮긴 심각도, 저대비 정보의 판독성은 PM에게 구체 문구·좌표로 재확인을 요청한다. 미확인 항목을 확정 오류로 추가 가산하지 않는다.

## 검수 상태

PM 검수는 아직 0건이다. N3/N5 무수정 확인은 PM 평가 검수가 아니다. K04는 정상 전체 제외, K07~K09는 GS-03 미생성 예외를 검수한다. A 표본의 방식·수는 추천안 상태를 유지하며 선정 완료로 표시하지 않는다. 최초 판단에 대한 이견은 human_review의 별도 이력으로 남겨야 한다.
