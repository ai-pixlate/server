## 실행 조건 및 비용

- 제품: v1.0.1 `bfa3b700144467f4adf7d6802b7b2e93791fe6de`, 기존 격리 checkout clean 확인.
- Windows 격리 환경: 최초 회차 패키지 버전과 차이 없음, PaddleOCR 자산 30개 SHA-256 일치. 정답의 3개 입력 해시 일치 후 실행.
- 모델: PP-OCRv5_server_det + korean_PP-OCRv5_mobile_rec, CPU, Paddle 3.3.1 / PaddleOCR 3.7.0 / PaddleX 3.7.2. 제품 설정 변경 없음.
- 초기화 약 11초. GS-03_002 약 41초, GS-03_016 약 5초, GS-03_018 약 34초. 순수 추론 합계 약 1분 20초(프로세스 import·검증 시간 별도).
- OCR 엔진 호출 3회, 섹션별 1회 성공. 재시도·fallback 없음. 네트워크 연결 차단, 외부 API 0회·USD 0·과금 토큰 없음. 전력/장비 시간 비용은 미산정.
- 기존 모델 캐시를 사용했다. ccache 미설치 경고는 있었으나 실행 실패는 없었다. LaMa·Gemini·상품 전체 파이프라인은 실행하지 않았다.

## 해석 시 주의

- `lines[]`와 서비스 반환 `regions[]` 순서를 그대로 연결하므로 읽기 순서 차이도 편집 오류에 포함된다. 위치 기반 결함 원인이나 문자 자체의 인식 오류만으로 해석하지 않는다.
- L008은 사용자 결정으로 빈 정답을 유지했다. 그 위치의 출력은 제거하지 않고 전체 편집거리에 반영했다.
- 사용자 전사 검수·동결 승인 근거는 보존했으나 출력 노출 이력은 미확인이다. 별도의 PM 결과 검수·성능 목표 달성을 주장하지 않는다.
- GS-03의 예전 후보 3개는 입력 동일성이 미확인이라 사용하지 않았다. 이번 보완은 고정 입력으로 따로 실행한 결과이며 최초 회차의 실패 이력을 바꾸지 않는다.
