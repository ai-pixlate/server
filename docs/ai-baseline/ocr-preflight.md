# OCR 기술 품질 평가 자료 사전 점검

현재 상태: [텍스트 기반 v4](protocols/v1/ocr-v4.md)로 전환. 사용자 전사·누락 전수 검수 완료(369줄, 오류 0건), bbox·겹침 검수 생략, OCR02 보류·위치 진단 제외. 사용자 승인에 따라 [텍스트 동결본](references/ocr-text/ocr-text-v1-20261104/README.md) 12개·369줄 동결 완료. 채점기는 합성 테스트 28개를 통과했으며 실제 CER 측정은 미수행이다. 아래 입력·산출물 검사 수치는 최초 점검 근거이며 현재 후속 작업은 마지막 절을 따른다.

최초 점검일: 2026-11-04. 범위: 지표 정의와 자료 점검만. [OCR01·OCR02 정의](protocols/v1/ocr.md)를 추가했으며 정답 수정·사람 검수·동결·OCR 추론·CER 채점은 수행하지 않았다. 아래 수치는 파일·로그·구조 검사 현황이며 OCR 품질 점수가 아니다.

## 정답과 로컬 입력 상태

- [기존 정답 초안](../ai-experiments/ocr_truth/v1/): 12개 JSON, 총 369줄. 12개 모두 `review.status=draft`, 줄별 `verified=true`는 0개다. `reviewed_at`, `frozen_at`, `spec.commit`은 모두 null이며 `MANIFEST.json`은 없다.
- 각 JSON의 `image.path`는 저장소 루트 기준 `pipeline/out/ocr_input/v1/<원본>/sections/<섹션>.png`다. 기존 주 작업 공간 `C:/Users/Yeram/Documents/pixlate-server/`에서 **12/12 파일 존재·SHA-256 일치·이미지 크기 일치**를 확인했다.
- 이 입력 폴더는 Git 제외 대상이다. 현재 별도 worktree에는 12개 이미지 경로 모두 없으며, clone만으로 입력 자료가 준비됐다고 볼 수 없다. 입력·정답은 이번 점검에서 복사하거나 수정하지 않았다.
- 기존 `truth.py.check_doc`를 읽기 전용으로 재사용해 기존 주 작업 공간의 입력을 검사했다. 8개 섹션은 자동 구조 검사 0건, 4개 섹션은 합계 **bbox 겹침 38건**이다. 자동 검사 통과도 정답의 정확성·누락·여백 10%·셀 경계를 사람이 확인했다는 뜻은 아니다.
- 과거 기록의 GS-02_002 L005·L006 전사 오류 의심은 이력이다. 이후 사용자 전수 검수 결과는 오류 0건이며 이를 근거로 자동 전사 수정하지 않는다. 이번에는 문자를 대조해 정답 판정을 내리거나 `rotated` 등 태그를 자동 보정하지 않았다.

## 최초 측정에 추가 실행이 필요한가

- **확인된 9개:** 입력 동일성 확인. 보정 후 반환 경계가 확인되면 재추론 없이 재사용 가능하며, 텍스트 동결·채점기 합성 검증은 완료했으나 실제 출력 경계 확인 후 별도 측정 승인이 필요하다.
- **GS-03_002:** 현재 증거만으로는 재사용을 확정할 수 없다. 동일 입력 해시를 증명하는 추가 보존 자료와 재시도 선택 기준을 먼저 확인한다. 확보하지 못하면 고정 입력으로 별도 OCR 측정이 필요하다.
- **GS-03_016·018:** 최초 회차에 출력이 없어 12개 전체 OCR 정량 평가를 완성하려면 별도 OCR 실행이 필요하다. 제품 전체 파이프라인·이미지 생성이나 GS-03 상품 재실행이 필요하다는 뜻은 아니다.
- 따라서 **전체 12개를 추가 실행 없이 평가할 준비는 안 됐다.** 후속 실행은 별도 승인·정답 동결 후 진행하고 최초 회차를 수정하지 않는다. 최초 실측에서 재사용한 결과와 나중에 보완 실행한 결과는 실행 시점·제품/환경·시도 정보를 구분한다. 새 결과를 최초 회차에서 나온 것처럼 기록하지 않는다.

## 다음 단계와 미해결 사항

1. 기존 369줄 전사·누락 확인 완료와 오류 0건을 사용자 회신으로 보존한다. 좌표·겹침 38건 및 위치 기반 지표는 이번 범위에서 제외한다.
2. 사용자 결정으로 정답 `lines[]` 배열 순서를 채택했다. 동결 추출 시 순서 보존을 검증한다. GS-02_014/sec_1_09 L008은 사용자 결정으로 빈 정답을 유지하고 섹션 평가에 포함한다. 해당 OCR 출력은 제거하지 않으며 빈 정답 채택의 한계를 보고한다.
3. [텍스트 동결본](references/ocr-text/ocr-text-v1-20261104/README.md)에 원본 text·ID·이미지/파일 해시·사용자 검수 및 동결 승인 근거를 보존했다. 기존 v3 freeze는 사용하지 않았다.
4. 과거 출력이 실제 서비스의 보정 후 반환값인지 제품·기록 경계를 확인하고, 합성 검증을 마친 [채점기](../../tools/baseline/ocr.md)에 입력 색인을 준비한다. OCR02는 재검토 전 보류한다.
5. 부족한 출력의 보완 실행은 별도 승인 대상이다. 텍스트 동결 외에 실제 CER 채점·OCR 실행은 하지 않았다.

기존 [검수 화면](ocr-review.md)은 보존하며 현재 텍스트 평가 범위와 v3 화면의 완료 조건을 혼동하지 않는다.
