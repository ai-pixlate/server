# OCR 기술 품질 평가 자료 사전 점검

점검일: 2026-11-04. 범위: 지표 정의와 자료 점검만. [OCR01·OCR02 정의](protocols/v1/ocr.md)를 추가했으며 정답 수정·사람 검수·동결·OCR 추론·CER 채점은 수행하지 않았다. 아래 수치는 파일·로그·구조 검사 현황이며 OCR 품질 점수가 아니다.

## 정답과 로컬 입력 상태

- [기존 정답 초안](../ai-experiments/ocr_truth/v1/): 12개 JSON, 총 369줄. 12개 모두 `review.status=draft`, 줄별 `verified=true`는 0개다. `reviewed_at`, `frozen_at`, `spec.commit`은 모두 null이며 `MANIFEST.json`은 없다.
- 각 JSON의 `image.path`는 저장소 루트 기준 `pipeline/out/ocr_input/v1/<원본>/sections/<섹션>.png`다. 기존 주 작업 공간 `C:/Users/Yeram/Documents/pixlate-server/`에서 **12/12 파일 존재·SHA-256 일치·이미지 크기 일치**를 확인했다.
- 이 입력 폴더는 Git 제외 대상이다. 현재 별도 worktree에는 12개 이미지 경로 모두 없으며, clone만으로 입력 자료가 준비됐다고 볼 수 없다. 입력·정답은 이번 점검에서 복사하거나 수정하지 않았다.
- 기존 `truth.py.check_doc`를 읽기 전용으로 재사용해 기존 주 작업 공간의 입력을 검사했다. 8개 섹션은 자동 구조 검사 0건, 4개 섹션은 합계 **bbox 겹침 38건**이다. 자동 검사 통과도 정답의 정확성·누락·여백 10%·셀 경계를 사람이 확인했다는 뜻은 아니다.
- 과거 기록에 알려진 GS-02_002 L005·L006의 전사 오류 의심도 여전히 검수 대상이다. 이번에는 문자를 대조해 정답 판정을 내리거나 `rotated` 등 태그를 자동 보정하지 않았다.

현재 브랜치의 추적된 Python 코드에서 v3의 정답 대응·mixed_scope·CER 계산을 구현한 채점기는 찾지 못했다. 기존 합성 OCR 테스트는 제품 동작 검증이며 정답 기반 품질 채점으로 대체할 수 없다. 회차에서 이름으로 식별되는 `ocr_debug.json`은 확보하지 못했으므로 이음매 원인 진단을 0건으로 확정하지 않는다.

## 최초 측정에 추가 실행이 필요한가

- **확인된 9개:** OCR 재추론 없이 기존 출력을 재사용할 수 있다. 정답 검수·동결 및 채점기 구현·검증이 먼저 필요하다.
- **GS-03_002:** 현재 증거만으로는 재사용을 확정할 수 없다. 동일 입력 해시를 증명하는 추가 보존 자료와 재시도 선택 기준을 먼저 확인한다. 확보하지 못하면 고정 입력으로 별도 OCR 측정이 필요하다.
- **GS-03_016·018:** 최초 회차에 출력이 없어 12개 전체 OCR 정량 평가를 완성하려면 별도 OCR 실행이 필요하다. 제품 전체 파이프라인·이미지 생성이나 GS-03 상품 재실행이 필요하다는 뜻은 아니다.
- 따라서 **전체 12개를 추가 실행 없이 평가할 준비는 안 됐다.** 후속 실행은 별도 승인·정답 동결 후 진행하고 최초 회차를 수정하지 않는다. 최초 실측에서 재사용한 결과와 나중에 보완 실행한 결과는 실행 시점·제품/환경·시도 정보를 구분한다. 새 결과를 최초 회차에서 나온 것처럼 기록하지 않는다.

## 다음 단계와 미해결 사항

1. 고정 입력 12개를 후속 검수 공간에서 접근할 방법을 준비하고 동일 해시를 유지한다. 현재 로컬 전용 입력은 공유 완료 상태가 아니다.
2. 사람이 369줄 전체의 문자·누락·bbox·태그를 대조하고 38건 구조 검사 지적을 해결한다. 출력에 노출된 검수 여부를 기록한다. GS-01 서비스 평가용 58개 동결본과 OCR 줄 정답은 서로 다른 자료다.
3. [v3의 미명시 세부 사항](protocols/v1/ocr.md#채점기-구현-전-남은-세부-합의)과 재시도 출력 선택·결측 표본 보완 방식을 정한 뒤 채점기를 구현·검증한다. 임의 S/D/I 내역·보조 CER·rotated 귀속 규칙을 확정하지 않는다.
4. 정답·명세를 동결하고, 필요한 별도 OCR 실행 승인을 받은 다음 측정·채점을 진행한다. 2차·3차 통합도 같은 입력 해시와 동결 기준으로 비교한다.

이번 작업은 위 후속 단계를 수행하지 않고 여기서 종료한다. 커밋·push·PR도 생성하지 않는다.
