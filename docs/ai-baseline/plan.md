# 1.0.0 baseline 측정 계획

> 상태: `v1-draft` · `pm_review_pending` · 1~5단계 사용자 확정 · PM 승인 전 · 공식 실측 승인 전

## 측정 대상과 목적

실제 배포된 릴리즈 1.0.0의 정확한 커밋 SHA를 확인해 회차 기록에 고정한다. 브랜치의 최신 커밋을 배포 SHA로 간주하거나 실행 중 브랜치 갱신을 따라 코드를 바꾸지 않는다.

현재 품질과 결함·실패를 재확인 가능한 기록으로 남기고, 같은 평가셋·평가 방법으로 후속 버전의 개선과 퇴행을 비교한다. 최종 발표에서는 측정 결과와 실제 전후 이미지를 함께 제시한다.

측정 대상은 모델 추론과 전후처리·판정·번역·렌더를 포함한 이미지 변환 처리 품질이다. 기존 릴리즈의 BE 처리 흐름을 격리 환경에서 재사용한다. 운영 인프라 성능이나 모델 단독 효과를 검증한 것으로 해석하지 않는다.

고정 입력은 [평가셋](protocols/v1/dataset.md), 로컬 환경 결정은 [decisions.md](decisions.md#실행-환경), 공식 생성 횟수·재시도·예산 승인은 [execution.md](protocols/v1/execution.md)를 따른다.

## 확정 범위와 후속 작업

| 단계 | 내용 | 현재 상태 |
|---|---|---|
| 1 | 실제 처리 단계와 확보 가능한 산출물 | 사용자 확정 |
| 2 | 평가 대상과 평가 단위 | 사용자 확정 |
| 3 | 실패 유형과 심각도 체계 | 사용자 확정 |
| 4 | 핵심 품질·단계 진단·보조 운영지표 목록 | 사용자 확정 |
| 5 | 지표별 분모·계산식·판정 기준 | 사용자 확정 |
| 6 | GPT-6 Astra 평가 입력·출력 JSON, 프롬프트·독립 재검토 세부 구현 | 미확정·후속 검토 |
| 7 | 사람 검수 규칙·표본 범위, N3·N5 검수자와 수정 기준 | 미확정·후속 검토 |
| 8 | JSON·JSONL·CSV·Markdown 결과 파일 최종 구조 | 미확정·후속 검토 |
| 9 | 예상 호출량·토큰·비용 | 미확정·후속 검토 |
| 10 | 승인 후 실제 baseline 실측 | 미진행·별도 승인 필요 |

Codex 실행 절차와 측정 스크립트도 미확정이다. 6~7단계의 기존 상세안은 [평가·검수 제안](protocols/v1/evaluation.md#후속-검토-제안), 8~9단계와 실행 절차의 기존 상세안은 [실행 문서](protocols/v1/execution.md)에 보존한다. 이를 근거로 미확정 내용을 구현하거나 실행하지 않는다.

## 비목표

- 운영자 화면이나 별도 평가 기능 신규 개발
- 제품 파이프라인·DB/API 계약 변경
- 좋은 결과를 선택하기 위한 반복 생성
- 고정 평가셋 결과를 전체 상품·국가·언어 성능으로 일반화

보조 운영지표는 기존 기록에서 확인 가능한 값을 품질과 함께 표시하기 위한 것이다. 서비스 장기 운영지표와 격리 실행 결과를 동일하게 해석하지 않는다.
