# 1.0.0 baseline 측정 계획

## 측정 대상

릴리즈 1.0.0을 최초 기준선으로 삼고, 후속 고도화 버전을 같은 평가 기준과 측정 방식으로 다시 측정해 비교한다.

측정 준비 시 원격 `origin/release/1.0.0`의 최신 커밋을 확인하고 전체 SHA를 회차 기록에 고정한다. 공식 실행 직전에 원격 최신 커밋과 다시 대조하며, 달라졌으면 준비·검증을 갱신한 뒤 회차를 동결한다. 실행 중에는 브랜치 갱신을 따라 코드를 바꾸지 않는다.

측정 대상은 모델 추론과 이미지 결과에 영향을 주는 전후처리·판정·번역·렌더를 포함한 이미지 변환 처리 품질이다. 격리된 환경에서 해당 릴리즈의 BE 처리 흐름을 재사용한다. 운영 배포 인프라는 평가 대상에 포함하지 않으며, 실행에 필요한 DB 등은 보조 환경으로 준비한다.

## 측정 방향

최종 이미지가 사람이 보기에 사용할 만한지를 중심으로 단계별 품질을 평가한다. 이미지 품질을 완전히 정량화하기 어렵다는 점을 고려한다.

AI 에이전트를 최대한 활용하고 사람 검수 부담을 줄인다. 모델 품질과 함께 관리자 대시보드에 사용할 운영 KPI도 검토한다.

이 baseline의 완료율·처리 시간·사용량 및 비용은 격리 실행 환경의 기록이다. 운영 서비스의 성능을 검증한 것으로 해석하지 않으며, 이미지 처리 전체의 개선을 모델 단독의 개선 효과로 단정하지 않는다.

실행 환경은 현재 Windows PC의 전용 Python 가상환경, CPU OCR, 로컬 GPU LaMa, 로컬 PostgreSQL로 구성한다. 운영·학교 서버와 환경을 일치시키는 대신, 검증된 로컬 환경을 고정해 후속 측정에 재사용한다. 세부 고정 조건은 [실행 명세](protocols/v1/execution.md#로컬-실행-환경과-재현-조건)를 따른다.
