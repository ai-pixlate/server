# 1차 Baseline H01~H04 공식 평가 사전 준비

상태: **입력 준비 완료·미채점·PM 평가 검수 미시작**. 정답 승인과 평가 결과 승인은 다르다. 이 PR에서는 병합·공식 채점·모델 호출을 수행하지 않는다.

측정 제품은 v1.0.1 `bfa3b700144467f4adf7d6802b7b2e93791fe6de`, 최초 실행은 `baseline-v1-0-1-gs-v1-20261030-01`이다. [기존 회차](../../runs/baseline-v1-0-1-gs-v1-20261030-01/github-preservation.md)를 수정하지 않고 새 평가 ID `baseline-v1-0-1-official-h01-h04-20261124`로 연결한다.

## 입력 구성

| 파일 | 역할 |
|---|---|
| [manifest.json](manifest.json) | 기존 도구에 연결할 평가 manifest. 실제 평가 세션은 아직 빈 목록 |
| [reference_units.jsonl](reference_units.jsonl) | 기존 승인 58+281개를 연결한 339개 평가용 변환본. 새 정답 동결이 아님 |
| [reference-origins.json](reference-origins.json) | 원본 파일·버전·해시·줄 번호와 변환 전후 객체 해시 |
| [reference-approval.json](reference-approval.json) | 두 기존 승인 연결. GS-02·03 사용자 전달 구두 승인 출처 유지 |
| [file-plan.json](file-plan.json) | 이미지·실행·승인 증거의 원본 경로·고정 커밋·해시와 로컬 복원 경로 |
| [exception-plan.json](exception-plan.json) | 체크포인트와 H04 단위별 예외 처리 계획. 실제 평가 기록이 아님 |
| [review-checklist.json](review-checklist.json) | PM·K01~K09·중대 결함·불확실 판단·A 표본 추천안. 승인·선정 결과는 없음 |
| [preflight.json](preflight.json) | 입력 범위·분모 점검 결과. 점수 없음 |
| [validation.json](validation.json) | 로컬 복원 검증·테스트·불변성 확인 결과 |

`instructions/`는 평가 시 사용할 명세·지침 사본이다. 기존 회차 내부 명세는 당시 실행 증거로 보존한다. `protocol_commit`은 준비의 기준 develop 커밋이고 이번 PR에서 정비한 지침은 별도 파일 SHA-256으로 고정한다. 후속 평가 세션에는 실제 사용한 지침 경로·해시와 당시 도구 커밋을 함께 기록한다.

## 분모·예외 상태

| 항목 | 준비 범위 |
|---|---|
| H01 | 기대 산출물 대상 31장. 정당한 전체 제외 GS-01_001·GS-02_001·002만 미적용 |
| H02/H03 | 각 체크포인트: 이미지 평가 대기 13장, 산출물 없음 18장, 정상 전체 제외 3장 |
| H04 | 각 체크포인트: 적용 178개(이미지 확인 대기 111·산출물 없음 67), 미적용 21개 |
| H05 | 미측정(별도 서비스 평가 예정) |

H01 실패 분모에서 GS-03 18장을 빼지 않는다. H02/H03 A/B/C와 H04 보존율의 분모는 실제 `measured`이며 아직 확정하지 않았다. 적용 대상 수를 정상 측정 분모로 대체하지 않는다. 평가 가능률은 전체 적용 대상을 분모로 한다. 0분모 두 사유와 예외 건수는 기존 명세를 따른다.

GS-03 분석 실패는 `GS-03-job-3-N2` 한 묶음이고 원본 18장에 영향이 있다. 독립 품질 결함 18개를 생성하지 않는다. 최초 섹션 미리보기 67개와 N6 최종 이미지 13개를 별도로 확인하며 서로 대체하지 않는다. GS-01 Pilot 채점·결함·검수 기록은 가져오지 않았고 공식 평가로 승격하지 않는다.

## PM 검수 체크리스트

- 담당자 PM, 원본당 제한 시간 없음. 실제 확인·수정을 완료했을 때 종료한다.
- K01~K03·K05~K06은 해당 원본의 두 체크포인트를 확인한다. K04는 정답상 전체 제외의 적합성을 확인한다. K07~K09는 GS-03 미생성 및 예외 상태를 확인하며 가상의 이미지 품질을 채점하지 않는다.
- critical/major, 불확실 판단, 예외 원인, H04 정확성·가독성 근거를 연결한다. 사람의 판단은 human_review에 별도 기록하며 AI 최초 판단을 덮어쓰지 않는다.
- A 표본: 명세의 상품×체크포인트별 1장·최대 6쌍 SHA-256 정렬 방식을 **추천만** 한다. 채택 전 추출하지 않았고 수·방식 결정은 남아 있다.
- N3·N5 사용자 예람의 무수정 확인 이력은 PM 평가 검수와 다르다. OP06을 사용자 승인 성과로 발표하지 않는다.

## 복원과 다음 단계

[도구 실행 안내](../../../../tools/baseline/evaluation_prepare.md)에 따라 새 로컬 디렉터리에 복원한다. 이미지·원시 로그는 기존 Git 파일과 커밋에서 가져오며 새 PR에 중복 저장하지 않는다. `manifest.json`의 로컬 경로는 **복원된 디렉터리 기준**이고 이 준비 폴더 자체에서 aggregate/export를 실행하지 않는다.

복원 후 구조·해시 검증을 통과해도 실제 세션·모델 확인 근거·지침·응답 기록이 필요하다. 공식 채점 요청 후 이미지 확인과 평가 상태·결함 기록을 시작할 수 있다. PM 표본 방식 채택·평가 검수 완료 전 결과를 최종 확정하지 않는다. 이번 준비에 새 평가 정책 결정은 없으며 A 표본 방식만 기존 미정으로 남긴다.
