- `사람 확인 기록` 상태는 직접 확인 체크와 함께 사용자가 저장해야 생긴다. `human_reviews`에 당시 텍스트 SHA-256·이미지 해시·리비전을 남긴다. 이후 수정하면 이전 기록은 보존하지만 현재 확인으로 인정하지 않는다.
- 사용자 확인 기록도 최종 승인/동결이 아니다. 이 화면에는 모델 실행·표본 자동 승인·정답 동결 기능이 없다. AI용 POST 경로는 보완 모드에서 거부한다.

## 추적성과 재현

기존 줄 ID는 모두 유지했고 신규 ID만 증가시켜 부여했다. 배열에서 의미상 가까운 위치에 추가하므로 ID 숫자 정렬은 읽기 순서가 아니다. `lines[]` 배열 자체를 사용한다. 특히 논문 L025/L026 문장은 붙여 두고 새 Keywords/Abstract를 그 뒤에 배치했다. 초안 리비전 1→2의 위치 변경 이력도 보존했다.

`targets.json`은 v2의 18개 원본 단위 추출이다. `proposals.json`은 Codex가 이미지를 보고 직접 작성한 변경안이며 자동 OCR 전사물이 아니다. `build_draft.py`는 이 변경안을 별도 파일로 구성할 뿐 OCR/모델을 호출하지 않는다. 이미 만들어진 drafts 디렉터리를 덮어쓰지 않는다. 현재 리비전 2의 순서 정리는 해당 초안 history에 남아 있다.
