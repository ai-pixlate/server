## 출력 경계 확인

- 회차 runtime의 be.py SHA-256과 보존된 계측 코드가 일치한다. wrapper는 OCR run 반환값을 model_dump로 기록하고 같은 객체를 서비스에 반환한다. safe_record는 배열 순서를 보존하며 실제 OCR text에 인증 주소 마스킹 표식이 없음을 확인했다.
- v1.0.1 analyze._ocr_section→ocr.run 반환→merge.run 전달을 해당 Git 커밋 코드로 확인했다. 제품 코드 바이트 해시는 linkage.json의 boundary_review에 보존했다.
- **v1.0.1에는 현재 develop의 추가 호출 내 중복 제거·국소 재인식 기능이 없다.** 짧은 섹션은 엔진 결과의 to_result 변환 반환, 긴 섹션은 타일 처리 최종 반환이다. 이번 재사용 가능 9개는 모두 4,000px 이하이므로 타일 보정 대상이 아니다. 이는 v1.0.1 서비스의 최종 OCR 반환 경계를 충족하지만 최신 보정을 적용한 결과라는 뜻은 아니다.
- 9개는 원본 DB ID·분할 이벤트·DB 섹션 image_key·보존 객체 SHA-256을 연결하고 동결 입력과 일치함을 검증했다. 정답 bbox 검사는 수행하지 않았다.

## 준비 파일과 검증

- [inputs.json](inputs.json): 12개 전체 색인. available 9개, undetermined 1개, no_output 2개.
- [linkage.json](linkage.json): 원본/섹션 이미지·동결 정답·실측 로그·설정·환경·계측 코드 해시, 출력 행, 모든 후보 시도, 경계 검토 근거.
- [validation.json](validation.json): ready 9개, undetermined 1개, no_output 2개. S/D/I/N/CER은 모두 null이며 실제 계산을 호출하지 않았다.
- 합성 테스트 30개 통과: 편집거리 기존 테스트와 입력 검증 무채점 보장, 누락·해시 불일치·다른 섹션 연결·시도 문맥 분리 검사. 실제 출력은 형식·연결 검증에만 사용했다.

기존 회차·정답·이미지·로그는 복사하거나 변경하지 않았다. 상대 경로로 보존 자료를 참조한다. [재생성 및 검증 실행법](../../../../tools/baseline/ocr.md)을 따른다. 경계검토는 linkage.json의 boundary_review 객체를 별도 JSON으로 추출해 재사용할 수 있다. 다른 제품 SHA에서는 새 검토가 필요하다.

## 추가 실행과 비용

- GS-03_002/sec_1_04: 후보 3개는 동일 위치/크기지만 실행 입력 이미지 SHA-256 근거가 없다. 후보들은 각각 약 39초이며 좋은 출력을 고르지 않았다. 입력 바이트 증거와 시도 선택 기준을 확보하면 재사용 검토 가능하다. 확보하지 못하면 고정 입력으로 OCR만 1회 별도 실행해야 한다.
- GS-03_016/sec_1_01, GS-03_018/sec_1_11: OCR 출력 없음. 상품 분석은 merge 단계에서 VlmError(504)로 실패·재시도됐으며 이 두 원본의 OCR까지 도달하지 않았다. 두 섹션의 독립 OCR 품질 실패로 계산하지 않는다.
- **추가 실행 최소 2개, 현재 근거만으로 12개를 완성하려면 3개 권장.** 사용자 실행 승인 후 같은 제품 SHA·고정 입력 해시·모델 자산·설정·Windows 격리 환경에서 OCR 단계만 수행한다. 상품 전체 분석/번역/Gemini 호출은 필요하지 않다. 새 출력은 최초 회차에 섞지 않고 별도 보완 실행 ID·입력 해시·최종 반환 배열·사용량을 보존한다.
- 로컬 PaddleOCR만 사용하는 조건에서 **외부 모델 API 비용은 USD 0**이다. 전력·장비 시간 비용은 산정하지 않았다. 관측된 9개는 섹션당 약 13~41초, GS-03_002 후보는 약 39초이나 다른 두 섹션과 모델 초기화 시간을 보장하는 근거는 아니다. 전체 소요시간은 미확정이다.

## 다음 단계

9개 부분 CER은 별도 측정 승인 후 가능하다. 12개 전체 CER은 3개 미해결 입력을 해소해야 한다. 유효 섹션과 문자 분모를 공개하고 부분 결과를 12개 전체 성능으로 표현하지 않는다. 추가 실행 및 실제 채점은 이번 작업에서 수행하지 않았다.
