# OCR v6 고정 영역 후보·공통 필터 비채점 검증

영역 ID·원본 이미지 SHA-256·정책/범위 버전·픽셀 좌표를 [fixed-regions.json](fixed-regions.json)에 등록했다. **112개 전체의 고정 영역 정의가 완료된 것은 아니다.** 기존의 I0 이미지 전체 포함을 제거하고 미검증 영역은 unknown으로 유지했다. 기존 OCR 결과를 기준으로 GT나 영역을 줄이지 않는다. 영역 후보 파일은 GT 동결본이 아니며 공식 측정 승인도 아니다.

## 구현과 검증

- 공통 필터: [tools/baseline/ocr_scope.py](../../../../tools/baseline/ocr_scope.py). GT와 OCR 모두 동일 `classify` 함수로 원본 범위에 대응한다. GT에 검증된 위치/영역 앵커가 없으면 차단한다.
- 포함 영역의 문자열·순서·중복·빈 문자열은 그대로 반환한다. OCR에 없는 GT도 삭제하지 않는다. 따라서 후속 v5 문자 대응에서 누락·중복·오검출을 계산할 수 있다. 이번에는 문자 대응/오류 수/CER을 계산하지 않았다.
- 포함/제외를 가로지르는 bbox, 미검증 영역, 혼합 문자열은 hold. 문자열 수정·분리·유사도 기반 제외를 하지 않는다. 좌표·해시·버전 오류 및 GT 연결 누락도 차단한다.
- 문서 위 별도 인용 영역은 해당 문서 ID를 `overrides`로 명시한 경우에만 차감한다. 임의의 포함 영역 우선순위를 허용하지 않는다. 주석이 미검증이면 override도 통과시키지 않는다.
- 전체 영역을 검토한 경우에만 default=exclude를 허용한다. 그렇지 않은 원본은 default=unknown이며 배경으로 추측해 제외하지 않는다.
- `v5_inputs()`는 차단 없는 결과의 GT/OCR 원문 배열만 만든다. v5를 import하거나 호출하지 않는다. ready는 필터 일관성 결과이며 공식 채점 허가와 별개다.

테스트: `python -m pytest tests/test_ocr_scope.py -q` — 합성 18개 통과. 포함/제외, 경계, 혼합 문자열, 빈 출력, 누락 GT 유지, 중복/추가 문자 유지, 얼굴·배경·반사/문서 제외 규칙, 해시·버전 불일치, 포함 인용의 양쪽 대칭, 입력 불변성을 검증했다. 얼굴·반사 회귀 테스트는 원본 정책을 단순화한 합성 좌표 사례이며 실데이터 전체 검증으로 부르지 않는다.

전체 점검은 입력 112개 모두의 이미지·출력 해시를 확인했다. [섹션별 상태·차단 이유](section-status.json), [필터 전후 추적](filter-audit.json), [GT 영역 연결](gt-region-links.json), [검증 기록](validation.json)에 원문 포함/제외/보류를 남겼다. 기존 v1/v2·v4·v5 등 보호 파일 232개 불변을 확인했다.

기존 ‘혼합 27개 검증 완료’는 의미 정책 일관성 점검이었다. 이번 자동 필터의 원본 경계·GT 위치 검증과 기준이 달라 그대로 승계하지 않았다. GT 12개 섹션의 과거 bbox도 사용자에게 위치 검수받은 정답이 아니므로 자동 승인하지 않았다. **이번 작업은 필터 구현·112개 전수 차단 검사 완료, 전체 영역 정의는 일부 완료**다.

## 문서 OCR 86영역

두 원본을 다시 확인하여 상세페이지 제목, 문서 옆 효능 설명, WD 수치, 각주, 문서 위 별도 확대 인용문을 고정했다. 문서 본문 자체는 제외했다. [86개별 결과](document-86-audit.json)에는 원문·region ID·해당 고정 영역 ID가 있다. 원본을 기준으로 제목 및 오른쪽 인용 상자 경계를 보정한 후 86개 모두 포함/제외가 연결됐다. 초기 교차 5건은 문자열 분리가 아닌 원본 설명 영역 경계 오류였으며 OCR 문자열은 보존했다. 최종 개수는 validation.json을 따른다.

해당 영역은 정책과 원본을 근거로 작성한 재사용 후보다. 제품 버전이 바뀌어 bbox가 경계를 넘으면 다시 hold되므로 현재 반환값을 유리하게 잘라내지 않는다. GT 영역 앵커는 의미 위치 묶음이며 정밀 줄 bbox 또는 위치 정확도 평가는 아니다.

## Good all goodal과 남은 작업

기존 원본·반환 증거는 일반 문구와 로고를 한 문자열/영역으로 제공한다. 안전한 문자별 분리 근거가 없어 `mixed_string_no_split`으로 차단한다. 사용자가 결정한 일반 설명 포함·로고 제외 정책은 유지한다. 전체 포함/제외 예외를 요청하거나 적용하지 않는다. 해결하려면 문자열 구간과 원본 위치가 연결된 신뢰 가능한 근거가 필요하며 현재 출력은 부족하다. 근거 없이 섹션 일부만 정상 점수로 보고하지 않는다.

다음 작업은 109개 섹션의 원본 기반 포함 영역 작성과 GT 위치 연결, 얼굴/그림 등 비텍스트 영역의 경계 대조, 혼합 반환값의 위치 근거 확보다. 사용자에게는 작성된 고정 영역을 한 번 확인받아 버전 간 동일 범위로 사용할 필요가 있다. GT 텍스트 변경이나 재전사를 자동으로 요구하지 않는다. GT/범위 동결·실제 CER은 별도 단계다.
