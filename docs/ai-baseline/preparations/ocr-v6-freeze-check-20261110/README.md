## L045 원본 확인

GS-02_001/sec_1_03의 원본 픽셀 좌표 `[500,1380,730,1418]`을 6배로 확대한 [확인 이미지](L045-source-enlarged.png)다. 원본은 변경하지 않았다. 이는 사람 확인용 표시 자료이며 평가용 crop 입력이 아니고 OCR에 전달하지 않았다. OCR 출력은 기호 판독에 사용하지 않았다.

`상품앞` 뒤에 실제 작은 인쇄 기호가 존재한다. 다만 낮은 원본 해상도로 정확한 문자 종류는 확정할 수 없다. 기호가 없다고 결론 내리거나 유사한 문자를 추측해 넣지 않았다.

- 변경 전: `상품앞 표시품목 : 부가세 면세품목`
- 변경 후: 동일(판독 보류로 후보 GT 미수정)
- 사용자 확인 사항: 확대 이미지의 기호를 판독해 정확한 문자로 알려주거나, 더 선명한 동일 원본 근거가 있는지 확인. 판독 불가를 임의 빈 정답 수용으로 바꾸지 않는다.

## 최종 검증

- 고정 포함 105 / 정책상 전체 제외 4 / 고정 undetermined 3. 중복·누락 없이 112개 유지.
- 112개 원본 이미지·기존 출력 해시를 확인하고 공통 필터를 재실행했다. 저장된 GT/OCR 원문별 감사 기록·판정과 일치한다. 포함 105개 연결 완료, 전체 제외 4개와 고정 보류 3개 구분 유지.
- 기존 ID·텍스트·순서는 v2와 동일하고 좌표형 L005·L006에만 승인된 비활성화 이력이 추가됐다. 기존 v1/v2 동결본·실측·v4/v5 결과 및 이전 준비 패키지 보호 해시 356건 일치. 중복을 포함할 수 있으므로 독립 원시 파일 수로 해석하지 않는다.
- 기존 사용자 47개 / AI만 검수 53개와 v1 12개 검수 이력의 연결·해시를 유지했다. 포함 범위의 GT 완전성을 새 사람 전수검수 완료로 표시하지 않는다. 알려진 미해결 항목은 L045이며, 표본 검수 한계의 최종 수용 승인도 아직 받지 않았다.
- v4/v5/v6 및 공통 필터 합성·회귀 **147개 통과**. 고정 보류를 측정으로 바꾸는 경우, ID 누락·중복, 포함 대상의 추가 미측정, 전체 CER 오표기를 차단하는 테스트를 포함한다. 실제 CER 호출 없음.

## 승인 후 순서

1. L045의 정확한 판독 결과를 반영하거나 별도 사용자 결정 기록을 남기고 후보·GT 연결 해시를 갱신한다.
2. 입력/GT/범위/명세/코드 해시와 105/4/3 목록, 검수 이력·한계를 다시 확인한다.
3. 모든 필수 확인을 마친 구체적 후보에 대해 사용자 최종 동결 승인을 요청한다. 현재는 L045가 남아 있어 동결 준비 완료로 표시하지 않는다.
4. 승인 후 별도 영구 경로에 스냅샷·승인 근거·SHA-256 manifest를 만들고 v1/v2 및 기존 결과는 보존한다.
5. 실제 측정은 별도 승인 후 실행한다. 2·3차도 동일 고정 입력·GT·영역·알고리즘을 사용하며 전체 112개 CER 대신 고정 105개 부분 CER만 공개한다. 추가 미측정이 생기면 고정 부분값 확정도 차단한다.

이번 작업에서 GT 후보 수정·동결, 평가 범위 동결, OCR/API 호출·CER 측정, 제품 변경, 커밋·push·PR은 수행하지 않았다.
