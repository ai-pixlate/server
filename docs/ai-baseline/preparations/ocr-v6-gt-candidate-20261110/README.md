# OCR v6 GT·고정 부분 평가 후보

## 최신 상태 — 사용자 L045 확인 반영, 후보 revision 2

2026-11-10 사용자가 원본 기호를 `@`로 판독했다. L045를 `상품앞 @표시품목 : 부가세 면세품목`으로 교정하고 사용자 검수 이력·GT 연결 해시·범위 계획을 갱신했다. 기존 ID·순서와 두 줄 비활성화는 유지한다. 아래 L045 판독 대기 내용은 revision 1 당시 이력이며 해소됐다. 기존 47/53 검수 이력은 변경하지 않는다. 알려진 마지막 GT 확인은 해소됐고 **최종 동결 승인만 대기**한다. 최종 동결·CER 측정은 수행하지 않았다. 최신 해시는 `validation.json`과 `evaluation-plan.json`을 따른다.

2026-11-10 · 사용자 최종 검토 전 · 미동결 · 실제 CER 미산출

## 승인 반영

새 정답 후보 `ocr-text-v3-v6-candidate-20261110`은 [text_units.jsonl](text_units.jsonl)에 보존한다. v2의 112개·1,861줄을 복사하고 **GS-02_002/sec_1_01 L005·L006에만 비활성화·변경 이력 필드**를 추가했다. ID·원문·배열 순서·이미지는 그대로이며 활성 줄은 1,859개다. 이는 평가 분모가 아니라 후보 전체 행 수다. 두 줄의 원래 값과 승인 근거는 [changes.json](changes.json)에 있다.

기존 OCR Text v1/v2·기존 v3 재전사 초안·v4/v5 결과는 유지한다. [evaluation-plan.json](evaluation-plan.json)은 부모 GT 해시와 기존 approval.json 위치·해시를 기록한다. 신규 100개 중 사용자 검수 47개 / AI만 검수 53개, 기존 v1 12개의 이력을 승계하며 사람 전수 검수 완료로 표시하지 않는다.

고정 crop은 도입하지 않는다. `Good all goodal`·제형 숫자 `3`·배경 `b3+`의 3개 섹션은 사용자 결정으로 모든 버전에서 `undetermined`를 유지한다. 기술적으로 혼합 연결을 해소한 것으로 표시하지 않는다.

## 나머지 포함 GT

기존 16개 미전사 예외의 포장·라벨·문서 내부는 확정 제외 범위이며 추가 전사하지 않는다. 별도 손글씨·인용문·효능 설명·각주는 기존 원본 검토 근거와 GT를 승계한다. 전체 포함 영역을 새로 사람 전수검수한 것은 아니다. 53개 AI만 검수 이력과 표본 검수 한계는 최종 승인 문서에 계속 표시해야 한다.

원래 GT 0줄 사진 2개는 실제 무문자, 다른 전체 제외 2개는 정책 비대상이다. 고정 undetermined의 연결 미완료를 GT 0자로 해석하지 않는다. 포함 후보 105개에 대해 필터 연결 완료와 GT 완전성 승인은 분리한다.

## 부분 평가 구현·검증

[ocr_v6.py](../../../../tools/baseline/ocr_v6.py)의 `aggregate_fixed_partial(rows, plan)`은 고정 목록 112개를 모두 요구한다. 3개는 undetermined, 4개는 not_applicable여야 한다. 105개 모두 measured일 때만 `fixed_partial_cer_percent`를 제공하며 하나라도 추가 실패/보류이면 null이다. 전체 112개 CER은 항상 null이며 자동 공식 승인도 하지 않는다. 실제 입력에서는 이 집계를 호출하지 않았다.

분모는 고정 포함 105개에 속한 활성·포함 GT의 정규화 문자 수 합계다. 3개 기술적 보류와 4개 정책 비대상을 삭제 오류 0건처럼 넣지 않는다. 공개 명칭은 ‘고정 범위 105개 섹션 부분 CER’이며 전체 112개 결과라고 부르지 않는다. GT 후보·명세·정책·필터·채점기 버전과 해시를 고정하고 2·3차에도 동일 목록을 사용한다.

재현:

```powershell
python docs/ai-baseline/preparations/ocr-v6-gt-candidate-20261110/build.py
python -m pytest tests/test_ocr_v6_fixed_partial.py tests/test_ocr_v6.py tests/test_ocr_scope.py tests/test_ocr_scope_followup.py tests/test_ocr_scope_repair.py tests/test_ocr_scope_readiness.py tests/test_ocr_v5.py -q
```

합성·회귀 117개 통과. 승인 없는 비활성화 거부, OCR 삽입 유지, 고정 3개 상태 변경 거부, 추가 미측정 때 부분 확정 차단, 전체 CER 오표기 방지, ID·원문 불변성을 확인했다. [validation.json](validation.json)에 후보 파일 해시·109/3 상태·보호 증거 검증을 남겼다. v2 동결본·기존 실측·v4/v5 결과는 변경하지 않았다. 코드/명세 변경은 이번 사용자 승인 규칙만 반영했다.
