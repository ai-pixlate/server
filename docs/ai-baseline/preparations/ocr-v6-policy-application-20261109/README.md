# 사용자 제외 판정 적용 및 공통 필터 후속 검증

상태: 범위 후보 · GT 미수정 · 미동결 · CER 미실행. 기존 AI 분석과 사용자 검수 자료는 그대로 보존하고 이 폴더에 후속 결과를 기록했다.

## 결과

| 범위 상태 | 이전 | 현재 |
|---|---:|---:|
| 필터 검증 완료 | 78 | 82 |
| 사용자 확인 필요로 표시됐던 연결 미완료 | 33 | 0 |
| 기술적 연결 차단(기존 별도 차단 포함) | 1 | 30 |

이전 33개를 모두 해결했다는 뜻이 아니다. 4개를 보완했고 나머지는 사용자 정책 질문 대신 기술적 연결 차단으로 분류했다. 82개는 적용 대상 78개와 전체 제외 4개다. 이는 CER 계산 범위 승인 또는 독립 검증 정확도 100%가 아니다.

차단 30개는 GS-01 7개, GS-02 13개, GS-03 10개다. 전체 ID·차단 사유는 [section-status.json](section-status.json), 모든 GT/OCR의 포함·제외·보류와 원문은 [filter-audit.json](filter-audit.json)에 있다.

## 두 사용자 판정

근거: [채팅 검수 기록](../ocr-v6-review-ui-20261109/user-review-chat.json). 검수 데이터 해시와 두 ID·제외 판정을 대조했다.

| 섹션 | 적용 결과 | 남은 차단 |
|---|---|---|
| GS-03_005/sec_1_01 | 제형 숫자 3 제외 영역 추가, GT L007 범위 제외. 위 효능 설명과 하단 각주 포함 유지 | OCR reg_0021은 y=764~1816으로 각주 포함 영역까지 걸침. 원문 `3`만 보고 각주 없는 bbox로 바꾸거나 강제 제외하지 않음 |
| GS-03_014/sec_1_03 | 옅은 b3+ 제외 정책·배경 영역 추가. 전경 제목·영문·BRIGHTENING은 포함 영역으로 보존 | GT L008의 배경 글자는 전경 제목과 겹침. 제외 정책은 확정이나 범위 연결은 보류. GT만 제거하지 않음. 현재 대응 OCR이 없다는 사실도 이 차단을 해제하지 않음 |

필터에는 정책과 기하 분류가 충돌할 때 차단하는 조건을 추가했다. 배경 제외 영역 위에 별도 설명이 있는 경우 기존 명시적 override 규칙을 재사용한다. 큰 사각형으로 모든 전경을 삭제하지 않는다.

## 추가 보완

원본 5개를 직접 다시 열어 확인했다. 이미지 해시와 수정 근거는 [scope-changes.json](scope-changes.json)에 연결했다.

- GS-01_002/sec_1_11: 상단 설명 범위를 원본 기준으로 보정해 마지막 단어 `않는`을 포함. 아래 용기 인쇄는 제외 유지.
- GS-02_014/sec_1_02: 사진 위 `how to use` 의미 영역을 보정. 얼굴·용기 영역을 포함으로 바꾸지 않음.
- GS-03_008/sec_1_01: 기존 주석이 `VITAMIN C` 전체를 제외하고 `비타민C` 상단을 잘랐음. 같은 성분 콜아웃의 영문·한글을 모두 포함하도록 보정. GT와 OCR이 동일한 포함 영역을 사용함.
- GS-03_011/sec_1_01: 빈 OCR 반환이 영역 경계를 가로지르는 것만으로 차단하지 않도록 필터 보완. 기존 포함 GT를 모두 유지하며 정상 빈 반환과 실패/없는 출력을 구분.

이 밖의 연결을 이번에 원본까지 전수 재검수했다고 주장하지 않는다. 112개 모두 해시·ID·텍스트 보존·공통 필터 적용을 재검증했고, 나머지는 기존 근거와 차단을 재사용했다.

## 대칭 검증 및 한계

GT·OCR에 동일한 영역 분류 함수를 적용한다. GT 원문/배열 순서와 OCR 원문/ID는 변경하지 않았다. [decision-transitions.json](decision-transitions.json)에 필터 전후 변경을 모두 기록했다. 일부 GT의 기존 의미 영역 연결은 실제 줄 bbox가 아니며, 해당 사실을 유지한다.

현재 차단 로그: 미검증 GT 연결 593줄, 미검증/교차 영역 799건(GT·OCR 포함), 섹션 범위 미확정 15개, 혼합 문자열 1건, 두 신규 명시적 연결 차단 및 b3+ 정책 연결 보류. 이 값들은 중복 원인이 있는 검사 건수이며 독립 결함 수나 새 사용자 검수 항목 수가 아니다.

새 필터 회귀 검증은 원문 오류·중복·삽입을 보존하고, 정책 승인만으로 위치/겹침 차단을 통과시키지 않음을 확인한다. 빈 문자열 예외도 미검증 GT를 통과시키지 않는다.

## v6 채점 전 남은 작업

1. 30개 차단 섹션의 위치·의미 영역 연결 보완. 사용자에게 다시 일반적인 포함/제외 질문을 던질 문제가 아니다.
2. 제형 숫자와 각주처럼 큰 OCR bbox가 별도 포함 문구를 덮는 경우 원본 요소 연결의 객관적 증거가 필요하다. OCR 문자열을 잘라 해결하지 않는다.
3. b3+의 배경·전경 겹침과 Good all goodal의 단일 혼합 출력은 안전한 분리/연결 방법을 별도 검증해야 한다. 이번 결과를 좋게 만들기 위해 GT만 제외하지 않는다.
4. 나머지 GT 완전성·불확실한 텍스트, 기존 v5 분리·병합 대응 한계 검증, 버전 고정과 공식 v6 전환·채점 승인은 별도다. 범위 필터 통과는 이 조건을 대신하지 않는다.

GT 수정·동결, OCR 실행·외부 API·CER 채점, 커밋·push는 수행하지 않았다.
