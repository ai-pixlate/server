앞의 세 개는 원본 이미지·확대 영역을 대조하고 의미 영역을 연결했다. 새 GT bbox가 아니라 `source_semantic_area_not_line_bbox`로 기록한다. GT 텍스트·순서와 OCR 원문은 변경하지 않는다. 영역 밖 제외는 원본의 포장·사진·문서·QR 등 근거로 정하며 OCR 오류 여부로 선택하지 않는다. 포함 영역 안의 잘못된 문자·추가·중복 출력과 정상 빈 출력은 그대로 유지한다.

## 혼합 3개에 대한 결론과 대안

현재의 사각형+단일 문자열 증거만으로 세 사례를 모두 안전하게 자동 분리하는 것은 불가능하다. 문자열 일부를 추정해 삭제하거나 OCR 문자열을 GT에 맞춰 고치지 않는다.

| 대안 | 가능 범위/장점 | 제약·추가 실행·비교 영향 |
|---|---|---|
| 고정 crop 별도 평가 | Good all 일반 문구와 로고, 제형 숫자와 각주가 공간상 분리되는 부분에 적합. 모든 버전에 같은 입력 제공 가능 | 원본 기준 crop·해시·GT 연결을 먼저 확정하고 로컬 OCR 추가 실행 필요. 문맥·크기 변화가 있으므로 기존 전체 섹션 출력의 재사용 결과와 같은 조건이 아님. 별도 입력 버전/결과로 보존해야 함 |
| 원본 요소·문자 위치 기반 출력 연결 | 원래 입력을 유지할 가능성 | 기존 출력에 필요한 위치 근거가 없음. 새로운 출력 수집 또는 사람이 확인한 연결 근거와 버전 간 공통 규칙이 필요. 인식 문자열 자체로 포함/제외를 정하면 안 됨 |
| 전경/배경 마스크·레이어 분리 | 겹친 b3+와 제목을 분리할 가능성 | 사각 crop만으로 해결 불가. 이미지 변경이므로 별도 방법 승인·입력 버전·재실행과 품질 검증 필요. 현재 작업에서 수행하지 않음 |
| 현 상태 보류 | 기존 입력·증거와 공정성을 유지 | 전체 112개 공식 채점은 차단. 일부 결과를 전체 결과로 발표할 수 없음 |

추천: 기존 출력은 보류 상태로 보존한다. 공간상 분리 가능한 두 사례는 **별도 고정 crop 평가 설계**를 선택할지 결정하고, b3+는 crop으로 해결된다고 간주하지 않는다. 어떤 방법도 이번에 실행하지 않았다. 사용자에게 포함/제외 정책을 다시 묻는 것이 아니라 입력 조건·연결 방법 선택이 필요한 상태다.

## GT 완전성

- 기존 특허증·시험성적서 내부 미전사는 최신 확정 제외 정책상 추가 전사 대상이 아니다. 문서 밖 별도 설명은 유지한다. 예전 분석의 '내부 전사 필요' 문구는 당시 정책의 이력이며 현 요구로 재사용하지 않는다.
- 논문 위 인용문, 제품 콜아웃·각주는 기존 GT에 있다. 이번 범위 연결에서 이들을 삭제하거나 누락을 면제하지 않았다.
- 좌표형 GT 2줄은 알려진 내용 오류/비시각적 항목으로 남는다. 동결본을 수정하지 않았고 해당 섹션도 통과시키지 않았다.
- 빈 줄 검색만으로 완전성을 증명할 수 없다. 원래 16개 미전사 예외와 AI만 검수한 53개라는 이력은 유지한다. 이번 작업은 112개 전체의 신규 전사 전수검수가 아니며 `gt_completeness=not_certified`로 분리했다. 특히 영수증의 작은 글씨를 포함한 영역 연결 완료와 전사 무누락 인증은 다르다.
- 확인되지 않은 누락량·줄 수는 추정해 추가하지 않았다. 공식 전환 전 포함 범위의 GT 완전성 확인 및 필요한 새 버전 정리가 남는다.

## UI·기록 초기화

[현재 검수 화면](../ocr-v6-review-ui-20261109/review.html)을 로컬 브라우저로 연다. 이미 끝난 두 제외 결정을 다시 입력할 필요는 없다.

- Node 모의 DOM/저장소 테스트에서 이미지 해시·강조 좌표, 선택·저장·재조회, 항목 간 격리, 확대, 미검수 필터, 추천 자동 선택 방지를 확인했다.
- 이전 61항목 화면의 정확한 저장 키를 삭제하고 재조회하며, 삭제 실패는 미확인으로 표시한다. 이전 입력 이관은 하지 않는다.
- 실제 브라우저 localStorage의 삭제 완료와 시각·포인터 검증은 **미완료**다. 이전 Computer Use 안전 중단을 재시도하거나 브라우저 저장소 파일을 우회해 읽지 않았다.
- Downloads에 확인된 내보내기는 과거 9항목 공식 검수 증거 1개였다. 이를 초기화 대상인 새 61항목 화면 입력과 혼동해 삭제하지 않았다. 초기화 이후 채팅으로 받은 두 제외 판정도 별개 근거로 보존한다.
- 필요 시 사용자가 [이전 진입점](../ocr-v6-ai-scope-review-20261109/review.html)을 열어 초기화 안내를 확인한 뒤 새 화면에서 확대·저장·새로고침을 수동 확인한다. 테스트용 선택을 실제 승인으로 해석하지 않는다.

## v6 구현 착수 판단

**범위 필터와 v5 대응을 연결하는 채점기 구현·합성 테스트는 시작할 수 있다. 공식 채점·기준선 전환은 아직 불가하다.** 구현 시 준비 상태, GT 완전성, 범위/정답/입력 해시를 별도 검사하고 차단 섹션을 자동 제외하지 않아야 한다. 남은 5개 연결/방법 결정, 포함 GT 완전성 확인, 최종 명세·입력·정답 버전 승인 후에만 공식 측정으로 전환한다.

GT 수정·동결, OCR 추론·CER 계산·API 호출, 제품 코드 변경, 커밋·push·PR은 수행하지 않았다.
