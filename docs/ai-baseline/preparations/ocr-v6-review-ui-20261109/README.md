# OCR v6 문구 중심 사용자 검수

화면 생성 당시 상태: 사용자 미검수 · 미승인 · 미동결. 이후 두 정책 질문은 [사용자 채팅 회신](user-review-chat.json)에서 모두 제외로 확정됐다. 새 채팅 회신은 폐기 대상인 이전 61개 화면의 임시 의견이 아니다. 추가 사용자 선택은 필요하지 않으며, 이 기록 자체는 GT 동결·기술적 연결 승인·CER 승인을 뜻하지 않는다.

후속 연결·UI 재검증 결과는 [연결 보완 보고서](../ocr-v6-connection-repair-20261109/README.md)를 참조한다.

## 실행

[review.html](review.html)을 로컬 브라우저에서 연다. 서버나 모델 호출은 필요 없다.
원본 이미지는 기존 로컬 절대 경로를 참조하므로 이 폴더만 다른 컴퓨터로 복사하면 이미지가 열리지 않는다.
이전 61개 화면의 `review.html`도 새 화면으로 이동한다.

1. 주황색으로 표시한 문구만 확인한다. ‘대상에 맞춤’과 ‘원본 전체’를 전환할 수 있다.
2. 포함 / 제외 / 판단 보류 중 선택하고 필요한 경우 이유를 적는다. 추천은 자동 선택되지 않는다.
3. 항목을 저장하고 다음으로 이동한다. 미검수 필터와 저장 진행률을 제공한다.
4. 새 검수 결과를 JSON으로 내보낸다. 같은 화면의 데이터 해시가 일치하는 새 형식만 다시 불러올 수 있다.

이동은 드래그·방향키, 확대는 버튼·휠·+/−를 사용한다. 범위용 강조이며 bbox 정확도 검수가 아니다.

## 61개 항목 재분류

| 구분 | 수 | 처리 |
|---|---:|---|
| 사용자 정책 질문 | 2 | 제형으로 만든 숫자 3, 옅은 배경 b3+ |
| AI 정책 판정 | 1 | Reef Safe 일반 설명 포함 권고. 타원 배치만으로 인증 로고로 제외하지 않음 |
| 기술적 연결 대기 | 58 | OCR 경계 교차 45개, 섹션 단위 위치·GT 연결 13개 |

기존 33개 섹션·61개 ID는 `review-data.json`의 `triage`에서 모두 추적한다.
기술적 항목을 사용자 검수에서 뺐다는 이유로 검증 완료로 바꾸지 않았다.
이 58개는 각각 독립적인 품질 결함 개수를 뜻하지 않는다. 단순 OCR 줄 분리는 정책 질문이 아니다.
기존 AI 분석과 필터 감사 기록은 원래 경로에 보존한다.

### 남은 질문의 연결 한계

- `GS-03_005/sec_1_01`: GT L007 / OCR reg_0021의 `3`. 원본의 제형 숫자만 강조한다. OCR bbox는 각주에 걸쳐 있어 강조 사각형과 동일한 확정 연결로 표시하지 않는다.
- `GS-03_014/sec_1_03`: GT L008의 `b3+`. 옅은 배경 글자의 보이는 조각을 강조한다. GT 위치는 의미상 후보이며 대응 OCR 영역은 없다. 검정 제목·영문과 사진은 질문 대상이 아니다.
- Reef Safe의 정책 권고는 영역 마스크·GT 연결 완료 또는 사용자 승인을 뜻하지 않는다.
- Good all goodal은 기존 별도 채점 차단을 유지한다. 문자열을 임의 분리하지 않았다.

## 기존 입력 초기화 범위

기존 **61개 항목 화면**의 정확한 데이터 해시에 대응하는 localStorage 키 하나만 삭제한다:
`pixlate-v6-review:876d4702d4efb33e58e245126ba0f90c659d8332f48213d4911e1606ea5686d1`

이전 화면의 파일 URL에서 삭제하고 새 화면으로 이동하도록 구성했다. 새 화면에서도 해당 키를 삭제하며 이전 형식 입력을 읽거나 이관하지 않는다. 새 저장소는 `pixlate-v6-focused-2:<데이터 해시>`로 분리한다. 최초 선택은 모두 비어 있고, 이후 새 화면에서 작성한 선택만 저장·복원한다.

실제 브라우저 저장소 삭제는 화면을 열 때 수행된다. 이번 작업에서는 브라우저 접근을 하지 않아 삭제 완료를 직접 확인하지 못했다. 파일 URL별 저장소가 분리되는 브라우저에서는 이전 화면 링크를 한 번 열어야 그 URL의 기록을 삭제할 수 있다. 저장소 접근이 막히면 화면에 미확인 상태를 표시한다.

Downloads에서 새 61개 화면 해시의 내보내기 파일은 발견되지 않았다. 기존 `ocr-v6-review-notes-2026-11-09T06-28-44-236Z.json`은 **과거 9개 항목 검수 증거**로 확인돼 보존했다. 해당 키 및 공식 검수·GT·평가 증거는 초기화하지 않았다.
