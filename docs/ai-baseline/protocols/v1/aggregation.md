# 지표 집계 방식

공식 품질 집계는 원본 단위로 하고, 세부 오류는 섹션·블록·영역 단위로 기록한다.

원본 이미지 기술 처리 완료 비율·처리 시간·사용량 및 비용은 격리된 BE 처리 흐름의 실행 결과를 집계한다. 운영 서비스의 가용성·응답 시간·운영 비용으로 해석하지 않는다. 처리 시간은 실행 경로와 환경이 같은 회차끼리 비교한다.

| 항목 | 기준 |
|---|---|
| 품질 평가 단위 | 품질 지표 7개 각각에 대해 원본별 판정 1개를 기록한다. 섹션·블록·핵심 영역의 판정과 오류는 그 근거로 연결한다. |
| 원본별 단계 등급 | 해당 지표에서 확인된 결함의 영향으로 판정한다. C에 해당하는 결함이 있으면 C, C 없이 수정이 필요하면 B, 필요한 범위를 확인했고 수정이 필요 없으면 A로 한다. 서로 다른 단계의 등급을 자동 전파하지 않는다. |
| 확인 범위 부족 | 확인한 결함만으로 B/C가 명확하면 해당 등급과 확인 한계를 함께 기록한다. A를 판단할 만큼 확인하지 못했으면 판단 불가로 기록한다. |
| 품질 분포 | A/B/C 분포와 A 비율은 A+B+C 판정 건수를 분모로 계산한다. 판단 불가·해당 없음·산출물 없음은 별도 건수로 함께 표시한다. 분모가 0이면 비율은 산출 불가로 표시한다. |
| 평가 가능 범위 | 품질 비율 옆에 전체 34장 중 A/B/C로 판정한 원본 수를 지표별로 표시한다. 생성 실패가 많아도 성공한 일부의 품질만으로 전체가 좋아 보이지 않게 한다. |
| 상품별 결과 | GS-01·02·03별 결과와 전체 결과를 함께 표시한다. 서로 다른 품질 지표를 하나의 종합 점수로 합산하지 않는다. |
| 원본 이미지 기술 처리 완료 비율 | 원본 1장에 대한 전체 처리를 작업 1건으로 보고, 계획된 34건 중 기술적으로 처리를 종료한 건수의 비율을 계산한다. 산출물 생성 완료와 전체 제외 종료를 구분하며, 판정의 정답 여부를 원본 이미지 기술 처리 완료 비율에 섞지 않는다. 부분 실패·실행 실패는 완료에서 제외한다. |
| 실패·재시도 | 부분 실패는 완료로 계산하지 않는다. 재시도는 같은 작업에 연결하고 분모를 늘리지 않는다. 최초 시도 성공 건수와 재시도 후 완료 건수를 구분한다. 미실행·중단도 별도 표시한다. |
| 원본 이미지 처리 시간 | 작업 시작부터 최종 산출물 저장 또는 종료 판정까지를 측정한다. 재시도·대기 시간을 포함하고, 단계별 시간도 기록한다. 사람 검수 시간과 AI 평가 시간은 생성 시간에서 분리한다. |
| 시간 요약 | 완료 작업의 중앙값·P90·최댓값과 표본 수를 표시한다. P90은 정렬한 값의 ceil(0.9×건수)번째 값으로 계산한다. 실패 작업의 소요 시간은 별도 집계한다. |
| 개선 비교 | 같은 원본끼리 등급 변화와 실패·정상 제외·평가 가능 상태의 변화를 비교한다. 품질 비율 차이만으로 개선을 결론 내리지 않는다. |

전체 제외 종료는 포함할 섹션이 없어 후속 실행을 하지 않는 경우의 측정상 종료이며, 서비스의 N6 완료 상태와 구분한다. 제외 판단이 기대와 일치하면 정상 제외, 어긋나면 잘못된 제외, 근거가 부족하면 판단 불가로 따로 기록한다. 잘못된 제외라도 기술적으로 종료할 수 있으며 그 품질 오류는 지표 7에서 판정한다.

장애나 판정 호출 실패 때문에 제외된 경우는 단순한 판정 오답과 구분한다. 실행에 부분 실패·실패가 있으면 최종 이미지가 있거나 전체 제외됐더라도 원본 이미지 기술 처리 완료 비율에서 성공으로 세지 않는다.

정상 제외로 처리 대상이 없는 하류 지표는 해당 없음으로 기록한다. 잘못된 제외 때문에 필요한 최종·하류 산출물이 없으면 산출물 없음과 원인(잘못된 제외)을 기록하고, 지표 7의 판정과 연결한다. 최종 이미지가 생성됐지만 필요한 영역이 빠진 경우에는 그 누락을 최종 이미지에서도 직접 평가한다. 제외된 영역도 지표 7의 평가 대상에서 빼지 않는다.

시간 요약의 완료 작업에도 전체 제외 종료가 포함되므로 해당 건수를 함께 표시한다. 대상 건수가 0이면 시간 요약은 산출 불가로 표시한다.

사람이 일부 영역을 확인했다는 이유로 해당 원본의 모든 지표를 사람 검수 완료로 표시하지 않는다. 확인한 범위의 판정을 반영하고 원본별 집계와 검수 범위를 구분한다.

## 판정·제외의 세부 집계

혼동행렬은 고정 평가셋에서 사전·정책의 기대 처리와 실제 처리를 대조한 건수다. 이를 규제 검출 재현율로 보고하거나 NFR-14 충족 근거로 사용하지 않는다.

지표 7은 원본 좌표·문구에 연결한 기준 영역별로 기대 처리와 실제 처리를 대조한 뒤 원본별 등급으로 집계한다. 기대 처리에는 섹션 포함·제외와 포함 텍스트의 대체·완충 지시를 나누어 기록한다. 현재 실행의 섹션이 분할·병합돼도 같은 기준 영역에 연결하며, 같은 영역을 섹션 수만큼 중복 집계하지 않는다. 경계 변경으로 함께 사라진 내용도 기록한다.

- 제외 판단: '제외해야 함'을 양성으로 두고 정탐(TP), 미탐(FN), 오탐(FP), 정상 유지(TN)를 집계한다.
- 대체·완충 지시: '지시가 필요함'을 양성으로 별도 집계하고, 지시 내용이 기대와 일치하는지도 확인한다. 포함 여부가 같다는 이유로 대체 누락을 놓치지 않는다.
- 판단 불가와 산출물 없음은 혼동행렬에서 제외하고 별도 건수로 표시한다. 전체 기준 영역 수와 판정 가능한 영역 수를 함께 표시한다.

정책상 정당한 섹션 전체 제외와 함께 발생한 유용한 내용 손실은 정책 준수 판단과 구분해 기록한다. 현재 정책은 전체 제외를 요구하는데 평가 정답은 부분 보존을 요구하는 식으로 기준을 혼용하지 않는다.

## 공식 버전 비교

아래 결과는 각 품질 지표의 비교 결과이며 새로운 독립 품질 지표 번호를 부여하지 않는다.

| 비교 | 기준 |
|---|---|
| 원본 등급 전이 | 양쪽 모두 A/B/C 판정이 있는 원본으로 지표별 3×3 전이표를 만든다. 판단 불가·해당 없음·산출물 없음으로의 변화는 별도 상태 전이로 표시한다. |
| baseline 결함 추적 | baseline B/C 결함별로 해결·완화·유지·악화·평가 불가 건수를 기록한다. 완화는 결함이 남아 있지만 영향이 줄어든 경우로, 원본 등급이 C→C여도 기록할 수 있다. |
| 재발 | 이전 후속 회차에서 해결을 확인한 결함이 다시 나타난 경우 재발로 별도 표시한다. 재발 여부는 위 상태와 함께 기록하는 이력이며 중복 합산하지 않는다. baseline과 첫 후속 버전만으로는 재발로 판정하지 않는다. |
| 신규 결함 | baseline에 없었던 후속 버전의 B/C 결함을 기록한다. 뒤늦게 발견한 기존 결함은 신규 퇴행과 구분하고 baseline 기록 정정 이력을 남긴다. |

결함 대응은 같은 원본·같은 내용 또는 대상·같은 결함 유형을 기본으로 한다. 좌표 겹침은 보조 근거로 사용하며, '50% 이상 겹침 또는 같은 원문'만으로 자동 확정하지 않는다. 같은 문구의 반복 위치와 같은 위치의 다른 결함 유형을 구분한다.

결함별 ID를 유지한다. 한 결함을 여러 박스로 표현해도 여러 건으로 늘리지 않는다. 분할·병합된 결함은 기존 ID와 대응 관계를 보존하고, 애매한 연결은 사람 검수 대상으로 둔다. 결함 건수는 평가의 상세도에 영향을 받으므로 비교 버전의 평가 조건을 동일하게 유지한다.
