# AI 파이프라인 평가 지표 — OCR 기술 품질

상태: 2026-11-04 사용자 결정 반영 · 텍스트 기반 v4 명세·동결 방식 설계. 사용자 승인으로 [텍스트 전용 정답](../../references/ocr-text/ocr-text-v1-20261104/README.md)을 동결하고 [채점기](../../../../tools/baseline/ocr.md)를 합성 검증했다. 이후 사용자 승인으로 [최초 9개 및 보완 포함 12개 부분 평가](../../evaluations/ocr-v4-v1-0-1-20261105/README.md)를 수행했다. 전체 34장 결과는 아니다.

## 현재 적용 기준 — OCR v6 고정 부분 평가

2026-11-10 사용자 승인으로 [OCR v6 GT·평가 범위](../../references/ocr-text/ocr-text-v3-v6-20261110/README.md)를 동결하고 [v1.0.1 최초 측정](../../evaluations/ocr-v6-v1-0-1-20261110/README.md)을 완료했다. OCR01은 번역 대상 텍스트의 문자 오류율이다. 고정 입력 112개 중 포함 105개 / 정책상 제외 4개 / 고정 undetermined 3개를 유지하며 **고정 105개 부분 CER 3.49% (584/16,742자)**다. 전체 112개 CER이나 OCR 모델 성능 향상으로 해석하지 않는다.

v6의 범위·계산·승인 근거는 동결본을 따른다. 기존 v4 공식 결과·v5 후보는 별도 이력으로 유지한다. 변경 과정·로컬 재현 조건·검수 한계는 [최종 정리](../../ocr-baseline-summary.md)를 참조한다. OCR02는 계속 보류한다.

## 기존 v4 평가 범위 이력

2026-11-09 추가: [112개 고정 섹션 v4 결과](../../evaluations/ocr-v4-v2-v1-0-1-20261109/README.md)는 기존 기준 결과로 보존한다. 읽기 순서 및 GT 범위 문제를 개선하는 [v5 후보 명세](ocr-v5.md)와 [완전성 점검·후보 비교](../../analyses/ocr-v5-candidate-20261109/README.md)는 검토 중이며, v4 공식 기준을 대체하지 않는다. GT 보완은 별도 OCR Text v3 초안·사용자 승인 이후 동결 대상으로 남긴다.

- **OCR01 CER(문자 오류율)**: 대표 지표. 좌표 대응 없이 섹션별 텍스트를 비교한다. 계산·정규화·연결 순서·예외·동결 설계의 정본은 [텍스트 기반 CER 명세 v4](ocr-v4.md)다.
- **OCR02 텍스트 줄 재현율**: 필요성과 텍스트 기반 계산 방식 재검토 전까지 보류. 이번 평가에서 산출하지 않으며 0으로 기록하지 않는다.
- 영역 정밀도·분리·병합·중복·오검출 등 위치 기반 진단과 rotated 부분 CER은 이번 평가에서 제외한다. 출력의 반복 텍스트가 CER 편집거리에 반영되는 것과 위치 기반 중복 진단은 다르다.
- 사용자 보고: 정답 12개 섹션·369줄의 전사 정확성과 누락 여부 전수 검수 완료, 발견 오류 0건. bbox 위치·겹침 38건은 검수 생략이다. 기존 줄별 `verified`는 좌표·태그까지 포함한 v3 검수 상태이므로 자동 변경하지 않는다.
- H01~H05·OP01~OP07, OI-54·NFR-15 및 [공통 결함 분석](aggregation.md#공통-결함-분석)은 변경하지 않는다.

## 버전과 자료

[기존 v3](../../../ai-experiments/2026-09-25_02-ocr_scoring-spec-v3.md)는 과거 위치 기반 명세로 보존한다(마지막 변경 커밋 `3ca9c934e905986579235efb8f09569de58c859a`). v3 수치와 v4 수치를 같은 기준의 성능 변화로 비교하지 않는다. [v3 세부 제안](ocr-scoring-details.md)은 미적용 이력이다.

같은 고정 입력 12개 섹션의 이미지 해시·텍스트 동결본·명세 버전으로 v1.0.1과 2차·3차 통합을 비교한다. 12개 결과를 34장 전체 성능으로 일반화하지 않는다. 출력·시도·제품·설정 해시를 함께 보존하며 입력 또는 기준 변경 시 버전을 분리한다.

현재 증거의 재사용 한계는 [자료 사전 점검](../../ocr-preflight.md), 기존 검수 화면의 범위는 [검수 안내](../../ocr-review.md)를 참조한다. 추가 실행은 이번 작업에 포함되지 않는다.
