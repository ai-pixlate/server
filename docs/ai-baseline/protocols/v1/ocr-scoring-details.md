# OCR 채점 세부 규칙 결정안

현재 적용 제외: 텍스트 기반 [v4](ocr-v4.md)로 전환했다. 아래 내용은 위치 기반 v3 검토 이력으로만 보존하며 현재 채점 규칙이 아니다.

작성 당시 상태: 검토용 결정안 · 실제 채점 미적용. [OCR 지표](ocr.md)와 [기존 v3](../../../ai-experiments/2026-09-25_02-ocr_scoring-spec-v3.md)의 정의는 유지한다. 실제 OCR 출력·점수를 참조하지 않고 합성 문자열·좌표만으로 작성했다. 적용 전 아래 안을 승인하고 명세 버전을 고정해야 한다.

## 결정안과 영향

| 항목 | 제안 | 근거·영향 |
|---|---|---|
| 동일 위치 정렬 | 성분 안에서 `(bbox.y, bbox.x, bbox.h, bbox.w, 고정 ID)` 오름차순. ID는 문자열 코드포인트 순서. OCR ID가 없으면 보존된 출력 배열의 0부터 시작하는 인덱스를 정수로 사용. 정답과 출력은 각각 정렬 | v3의 위→아래, 왼쪽→오른쪽 우선 유지. 완전 동률에서만 결정성을 추가하며 텍스트나 정답 유사도를 정렬에 사용하지 않음. 배열 변경은 출력 버전 변경으로 취급 |
| 대표 CER 공백 | NFC 후 Unicode White_Space 속성에 속하는 문자 모두 제거. U+200B, U+FEFF는 공백으로 간주하지 않음 | 언어 런타임별 공백 판정 차이를 방지. Unicode 버전·문자 집합을 구현 시 고정. 기존 '모든 공백'의 해석 보완이므로 승인 필요 |
| 보조 CER 공백 | 각 줄을 NFC 처리 → Unicode White_Space 연속 구간을 ASCII 공백 1개로 → 양끝 공백 제거. 정렬된 비어 있지 않은 줄을 ASCII 공백 1개로 연결 | 분리·병합의 인위적 줄 경계에 일관된 구분자를 적용. 기존 v3가 정하지 않은 양끝·성분 연결 규칙을 보완하며 보조값은 달라질 수 있음. 대표 CER에 공백 삽입 없음 |
| 최소 편집거리 동률 | 역추적 시 동일 문자 일치 우선, 이후 동일 최저 비용인 치환→삭제→삽입 순. 인덱스는 문자열 끝에서 시작 | 최소 오류 총합은 동일하지만 S/D/I 내역만 달라질 수 있음. 채점기 구현 시 역추적 테스트 필요 |
| rotated 혼합 성분 | rotated 줄이 있는 성분 전체를 rotated CER 진단에 귀속. 비회전 글자도 포함하므로 'rotated 포함 성분 CER'로 표기하고 혼합 성분 수 공개. rotated 줄 재현율은 태그 줄만 분모 | 성분 문자열 오류를 줄별로 임의 배분하지 않음. 전체 CER에 중복 가산하지 않음. 별도 진단 의미의 보완이므로 승인 필요 |

White_Space 제안 집합: U+0009–000D, U+0020, U+0085, U+00A0, U+1680, U+2000–200A, U+2028–2029, U+202F, U+205F, U+3000. 대소문자·문장부호·전각 문자 변환과 NFKC는 적용하지 않는다.

## 합성 검증 사례

- 동일 좌표·크기 L002/L001은 입력 배열 순서와 무관하게 L001/L002. OCR 배열 인덱스 2/10은 숫자 순서 2/10.
- `  A\t B  `와 `A B`는 보조 정규화 결과 `A B`로 일치. `Ａ`와 `A`는 구별.
- 분리 줄 `A`, `B`의 보조 연결은 `A B`, 대표 연결은 `AB`.
- 분해형 한글은 NFC 합성, U+200B는 그대로 유지.
- `ab`→`ba`는 치환 두 번과 삭제·삽입 각각 한 번의 비용이 같음. 제안 우선순위는 치환 두 번. 실제 편집거리 구현·채점은 하지 않음.
- rotated 1줄+일반 1줄 성분은 진단 CER에 성분 전체 1회, rotated 재현율 분모에는 1줄. mixed_scope 제외는 v3 규칙이 먼저 적용됨.

좌표·문자열 사례는 테스트에서 검증한다. 편집거리·rotated 성분 집계는 채점기 구현 단계의 추가 검증 대상이다. 실제 정답·OCR 산출물을 사용한 CER 계산은 수행하지 않았다.
