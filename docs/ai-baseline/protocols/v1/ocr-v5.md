# OCR CER v5 후보 — 순서 독립 줄 대응

상태: 후보·진단용, 공식 전환 승인 전. [v4](ocr-v4.md), 기존 동결본과 결과는 유지한다. H01~H05·OP01~OP07 및 OCR02 보류 상태는 변경하지 않는다.

## 목적과 포함 범위

서비스 보정 후 `regions[].text`의 문자 인식을 비교한다. 입력 섹션 전체의 사람이 읽을 수 있는 문자(작은 인쇄·로고·회전·반복 포함)를 GT에 전사한다. 번역에 쓰이지 않는다는 이유로 빼지 않는다. OCR 출력이나 오류율을 보고 GT를 채우거나 제외하지 않는다.

읽을 수 있지만 미전사된 부분은 독립 전사·사용자 검수가 필요하다. 원본으로 판독할 수 없는 문자가 일부라도 있는데 해당 출력과 대칭적으로 범위를 제한할 근거가 없으면 섹션 전체를 `undetermined`로 둔다. 이는 높은 CER에 따른 제외가 아니라 GT 완전성 보류다. 빈 GT가 곧 텍스트 없는 이미지라는 뜻은 아니다. 완전한 무문자 이미지가 확인된 경우만 `not_applicable`; 잘못 검출한 출력 문자 수는 별도 공개한다. 범위 보류 섹션의 산술 진단값도 숨기지 않는다.

부분 범위 평가는 이번에 구현하지 않는다. 후속에는 OCR 결과를 보지 않고 입력 crop·GT 범위를 먼저 고정하고 모든 제품에 동일 적용해야 한다. bbox 정확성 평가·유사도에 따른 출력 제거·confidence 필터는 하지 않는다.

## 정규화와 대응 알고리즘 후보 A

NFC·공백 제거·코드포인트·대소문자/문장부호 보존은 v4와 같다. 줄 내부 문자 순서는 반드시 보존한다. 빈 문자열은 길이 0으로 유지하고 원래 줄 인덱스를 기록한다.

1. 정규화된 비어 있지 않은 GT 줄과 OCR 영역을 일대일 대응한다. 문자 Levenshtein 비용을 사용하고 더미 노드의 미대응 비용은 각각 전체 문자 삭제/삽입이다. Hungarian 알고리즘으로 이 **일대일 문제**의 전역 최소 비용을 구한다. 줄 사이의 순서 제한은 없다. 동률은 원본 인덱스의 오름차순으로 처리한다.
2. 분리·병합 진단을 위해 각 배열의 연속 1~3개 비어 있지 않은 줄을 연결한 그룹들을 생성한다. 그룹 내부 순서는 바꾸지 않는다. 모든 그룹 쌍의 거리/긴 쪽 문자 수가 작은 순, 삭제+삽입 대비 절감 문자 수가 큰 순, 소비 줄 수가 작은 순, GT/OCR 시작 인덱스 순으로 결정적으로 정렬한다. 이미 소비한 줄과 겹치지 않고 비용을 절감하는 쌍을 순서대로 선택한다. 나머지 문자는 모두 삭제·삽입이다.
3. 줄 경계만 달라진 동일 텍스트를 보장하기 위해 v4의 전체 순서 연결 경로도 계산한다. 세 경로 중 총 오류 수가 최소인 것을 선택한다. 동률 우선순위는 일대일→그룹→전체 연결이다. 선택 경로·줄 연결·미대응 줄·S/D/I를 저장한다. 결과별 임계값 조정은 금지한다. 최초 후보 A의 3줄 경계 제약이 동일 연결 텍스트에도 오류를 부과하여, 합성 불변조건을 추가하고 A2에서 전체 연결 경로를 보완했다. 최초 후보는 폐기 이력으로 별도 보존한다.

그룹 경로는 결정적인 휴리스틱이며 분리·병합을 포함한 전역 최적해를 보장하지 않는다. 4개 이상 또는 배열에서 떨어져 있는 조각의 병합, 다수 반복 줄의 모호한 대응은 남는 한계다. 따라서 이 구현을 검증된 공식 CER로 승격하지 않는다. 문자 정렬/빈도 비교는 사용하지 않고 한 문자는 한 번만 소비한다. 중복·추가·누락은 발생 횟수 그대로 남는다. 의미가 다른 비슷한 줄끼리 대응할 수 있으므로 매칭 근거를 사람이 확인해야 한다.

## 계산·상태·재현

각 선택 쌍에 v4 Levenshtein 역추적(일치→치환→삭제→삽입 동률 규칙)을 적용한다. 미대응 GT는 D, 출력은 I. `CER=(ΣS+ΣD+ΣI)/ΣN×100`, N은 GT 문자 수이며 100% 초과를 자르지 않는다. 섹션별 비율 평균을 쓰지 않는다. 대응 바뀜에 따라 S/D/I 분배도 바뀔 수 있다.

파일 없음/실행 실패는 `no_output`, 파싱·해시·형식 오류는 실패로 중단한다. 불완전 GT·승인 전 범위는 `undetermined`; 계산 가능한 진단값은 별도 필드에 둔다. 확인된 무문자 섹션은 N=0으로 CER 없음. 정상 빈 출력은 N자 삭제. 적용 대상 0과 정상 측정 0을 구분한다.

전체 112개 동일 GT의 v4/v5 비교는 알고리즘 효과 확인용이며 인식 품질 확정값이 아니다. 사용자 검수 근거가 있고 완전성 경고가 없는 범위, AI 검수만 된 범위, 보류 범위를 따로 집계한다. 기존 사용자 검수는 v5 승인으로 간주하지 않는다.

GT 보완은 OCR Text v3 초안으로 별도 관리하고 원본·부모 GT 해시·수정 근거·사용자 승인·입력 해시를 남긴다. 이번에는 보완 전사와 새 동결을 하지 않는다. 입력·정답·출력·명세·구현 해시와 Unicode 버전을 보존하고 2·3차에도 동일 승인 GT/입력/규칙을 사용한다.
