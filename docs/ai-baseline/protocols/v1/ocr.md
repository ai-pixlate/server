# AI 파이프라인 평가 지표 — OCR 기술 품질

상태: 지표 정의·자료 사전 점검 단계(2026-11-04). 정답 검수·동결, OCR 추론, 실제 채점은 미실시다. 기존 [OCR 채점 명세 v3](../../../ai-experiments/2026-09-25_02-ocr_scoring-spec-v3.md)를 재사용하며 원문은 수정하지 않는다. 해당 명세의 마지막 변경 커밋은 `3ca9c934e905986579235efb8f09569de58c859a`다.

이 문서는 [단계별 기술 품질 지표](aggregation.md#단계별-기술-품질-지표)의 OCR 계산·입력·집계 정의를 소유한다. H01~H05, OP01~OP07과 [공통 결함 분석](aggregation.md#공통-결함-분석)의 정의·계산식·측정 범위는 바꾸지 않는다. 현재 자료 상태와 실행 필요 여부는 [자료 사전 점검](../../ocr-preflight.md)을 따른다.

## 평가 대상과 반복 측정 조건

- 입력은 기존 OCR 고정 입력 v1의 품질 표본 12개 섹션이다. 정답 초안은 [ocr_truth/v1](../../../ai-experiments/ocr_truth/v1/)의 12개 JSON이며, 현재 369줄은 검수 전 개수다. 사람이 검수하면서 줄 수가 바뀔 수 있다.
- 섹션 이미지 바이트의 SHA-256, 크기, 원본 식별자·원본 내 위치와 정답 버전을 고정한다. `section_key`나 파일명만으로 동일 입력이라고 판단하지 않는다.
- 채점 출력은 블록 병합 이전의 `OcrResult.regions`다. 각 영역의 `bbox`와 `text`를 사용하며 제품 반환 영역을 임의의 confidence 임계값으로 추가 제거하지 않는다. 병합 블록·번역문·최종 렌더 이미지를 OCR 출력으로 대체하지 않는다.
- v1.0.1과 2차·3차 통합은 같은 이미지 해시·동결 정답·채점 명세·정규화·대응 규칙으로 비교한다. 제품 SHA, 모델/설정/환경, 출력 해시와 실행·재시도 식별자를 별도로 기록한다. 재분할로 입력이 달라졌다면 고정 입력 OCR 비교와 구분한다.
- 12개 표본 결과를 34장 전체나 모든 상품 OCR 성능으로 일반화하지 않는다. 정답·명세 변경 시 새 버전과 근거를 남기고 비교 대상 모두에 같은 기준을 적용한다. 과거 출력은 보존한다.
- 정답 동결 전 실행에 관한 기존 [baseline 예외 결정](../../decisions.md#ocr-품질-표본의-실행-제한)은 유지한다. 이번 정의 작업은 추가 실행 승인이 아니다. 정답 작성·검수 시 평가 출력 노출 이력을 기록하며 OCR 출력을 정답으로 사용하지 않는다.

## 대상 줄과 정규화

OCR01·OCR02의 대표 결과는 v3의 **OCR 전체 지표** 범위다. 후속 처리 대상 범위는 별도 하위 결과로 표시하며 두 범위를 섞지 않는다.

| 태그 | OCR 전체 지표 | 후속 처리 대상 | 별도 기록 |
|---|---|---|---|
| `illegible` | 제외 | 제외 | 판독 불가 줄 수 |
| `section_cut` | 제외 | 제외 | 섹션 분해 기인 잘림 줄 수 |
| `source_cut` | 제외 | 제외 | 원본 입력 기인 잘림 줄 수 |
| `logo`, `product_label` | 포함 | 제외 | 범위별 분모 구분 |
| `ink_overlap`, `rotated` | 포함 | 포함 | 태그별 줄 수; rotated 하위 결과 |

태그가 겹치면 해당 범위의 제외 조건을 적용한다. 정답의 글자 누락·bbox·태그는 사람 검수 대상이며 이번에는 수정하지 않는다.

- 대표 CER: 정답과 출력 모두 NFC 정규화 후 공백 전부 제거. 문장부호·대소문자·전각 문자는 유지한다.
- 보조 CER: NFC 후 연속 공백을 한 개로 축약하여 유지한다. 대표 CER과 분리해 보고한다.
- NFKC, 소문자 통일, 문장부호 제거, 맞춤법·단위 보정은 적용하지 않는다. 예를 들어 `㎖`를 `mL`로 바꾸지 않는다.
- 글자 수와 편집 비교는 정규화 후 문자열을 기준으로 한다. 한글 NFC 조합 결과를 사용하고 바이트 수로 나누지 않는다.

## 영역과 정답 줄의 대응

v3의 면적 기준을 그대로 사용한다. OCR 영역 r과 정답 줄 L 사이에 아래 조건 중 하나를 만족하면 간선을 만든다.

```text
area(r ∩ L) / area(r) ≥ 0.5 또는 area(r ∩ L) / area(L) ≥ 0.5
```

연결 성분의 표기는 **정답 줄 수:OCR 영역 수**다. 1:1, 1:n(분리), n:1(병합), n:m으로 구분한다. 빈 텍스트 영역도 대응·검출 대상으로 센다. 텍스트 유사도로 이 공간 대응을 대체하지 않는다.

| 대응 범위 | 처리 |
|---|---|
| 제외 줄에만 대응 | 그 지표에서 영역 제외; 삽입·오검출로 세지 않음 |
| 포함 줄에만 대응 | 정상 집계 |
| 포함 줄과 제외 줄이 연결된 `mixed_scope` 성분 | CER은 성분 전체 제외; 제외된 포함 줄·정규화 글자 수 공개. 영역 정밀도는 해당 영역을 분자·분모에서 제외. 줄 재현율은 포함 줄을 대응됨으로 집계하고 해당 줄 수 공개 |

성분 안 정답 줄과 OCR 영역 텍스트를 각각 위→아래, 왼→오른쪽으로 이어 비교한다. n:1·n:m 성분의 오류를 개별 정답 줄에 임의 배분하지 않는다. 위 대응은 모든 병합을 잡거나 텍스트 정확성을 보증하는 규칙이 아니다.

## OCR01 · CER(문자 오류율) — 대표 지표

| 항목 | 정의 |
|---|---|
| 평가 단위 | 고정 섹션 안의 대응 성분, 미대응 대상 줄, 미대응 영역 |
| 분자 | 정규화 문자열의 치환(S) + 삭제(D) + 삽입(I) 문자 수 |
| 분모 | 해당 범위의 정규화된 대상 정답 글자 수 N. 제외 태그 및 `mixed_scope` 성분의 대상 글자는 제외 |
| 계산식 | `CER = (S + D + I) / N`; 백분율 표시 시 `× 100` |
| 방향 | 낮을수록 좋음. 삽입이 많으면 100%를 넘을 수 있으며 상한으로 자르지 않음 |

편집 거리는 문자 단위 최소 치환·삭제·삽입 횟수(Levenshtein 거리)를 사용한다. 미대응 대상 줄은 정답 전 글자를 삭제로, 미대응 OCR 영역 텍스트는 삽입으로 집계한다. 제외 줄 전용 영역과 `mixed_scope` 영역은 삽입에 포함하지 않는다. 정상 반환된 빈 영역 목록은 검출 0건 결과이며 대상 글자의 삭제를 계산할 수 있다. 파일 자체가 없거나 실행이 실패한 경우와 구분한다.

S·D·I·N을 함께 보존한다. 검출 줄 CER은 **대응된 성분만**의 오류 합 / 해당 성분의 대상 정답 글자 수로 별도 표시한다. 성분별 CER 분포와 1:1·1:n·n:1·n:m 수를 함께 보고한다. 대표 전체 CER을 검출 줄 CER로 대체하지 않는다.

## OCR02 · 텍스트 줄 재현율 — 보조 지표

| 항목 | 정의 |
|---|---|
| 평가 단위 | 정답 줄 |
| 분자 | OCR 영역과 대응된 대상 정답 줄 수 M. 한 줄에 여러 영역이 대응해도 한 번만 셈 |
| 분모 | 해당 범위의 전체 대상 정답 줄 수 L |
| 계산식 | `M / L × 100` |
| 예외 | `mixed_scope` 안의 포함 줄도 분자·분모에 포함하고 그 수를 별도 공개 |

텍스트가 틀렸거나 빈 문자열이어도 공간 대응이 성립하면 대응된 줄이다. 따라서 이 비율을 문자 인식 정확도나 검출 품질 전체로 해석하지 않고 OCR01 및 아래 진단과 함께 본다.

## 진단 항목 — 별도 대표 지표 ID를 추가하지 않음

| 진단 | 분자·분모 또는 건수 정의 |
|---|---|
| 영역 정밀도 | 대상 줄에 대응된 OCR 영역 수 / (전체 OCR 영역 수 − 제외 줄에만 대응된 영역 수 − `mixed_scope` 영역 수) × 100. 조각·중복 영역도 분자에 들어가며 빈 텍스트 영역도 검출로 셈 |
| 분리 | 1:n 연결 성분 수 및 줄당 영역 수 분포 |
| 병합 | n:1·n:m 연결 성분 수. 모든 병합을 자동 검출했다는 뜻은 아님 |
| 병합 의심 | 미대응 OCR 영역 중 2개 이상 정답 줄과 교집합이 있는 영역 수 |
| 과대 대응 | 대응 줄 합집합과의 교집합 / 영역 면적이 0.5 미만이며 줄 면적 기준 조건만으로 대응된 영역 수 |
| 중복 의심 | 같은 정답 줄에 대응한 두 영역의 교집합이 작은 영역 면적의 0.5 이상인 순서 없는 쌍 수. 여러 줄에 함께 대응해도 한 번만 세며 실제 중복으로 확정하지 않음 |
| 오검출 | 미대응 OCR 영역 수. 제외 줄 전용 영역은 제외. 빈 텍스트 여부·이음매 중복 여부를 구분 |

건수 진단에는 임의 비율 분모를 만들지 않는다. `ocr_debug.json`이 없으면 타일 이음매 원인 여부는 판단 불가로 남긴다. `rotated` 줄은 대표 지표에 포함하면서 줄 재현율·검출 줄 CER·전체 CER과 해당 줄이 들어간 성분 수를 별도 보고한다(v3 4절). 이 진단으로 공통 결함 분석의 심각도·원인을 자동 확정하지 않는다.

## 예외 상태와 집계

[공통 집계 규칙](aggregation.md#공통-집계-규칙)의 상태와 0분모 구분을 재사용한다. 미검수 초안·입력 불일치·연결 근거 부족은 공식 채점 준비 미완료이며 정답을 추측해 채점하지 않는다.

| 상황 | 처리 |
|---|---|
| 입력·동결 정답·출력·계산 근거가 유효 | `measured` |
| 해당 지표의 적용 대상이 없음 | `not_applicable`; `— / 해당 대상 없음` |
| 대응·입력 동일성 등 필수 판단 근거 부족 | `undetermined`; 사유 공개 |
| 기대한 OCR 산출물이 없음 | `no_output`; OCR 결과가 정상적으로 빈 목록인 경우와 구분 |
| 채점 수행·기록 처리 실패 | `evaluation_failed`; 수치를 임의로 0으로 채우지 않음 |
| 적용 대상은 있으나 정상 측정 단위가 0 | `— / 정상 측정 0건`; 원인별 건수 표시 |

v3의 `N/A (분모 0)`은 수치를 만들지 않고 평균에서 제외한다는 의미를 유지한다. `mixed_scope` 제외 등으로 CER에 남는 글자가 0이면 비율을 미산정으로 두고 대상 줄·글자 수 및 제외 사유를 함께 표시한다. OCR01 분모가 0이어도 OCR02의 적용 줄 수는 양수일 수 있으므로 지표별로 판단한다.

- 섹션별·상품별·전체 표본별 **오류/대상 개수 합산**으로 집계한다. OCR01은 `Σ(S+D+I) / ΣN`, OCR02는 `ΣM / ΣL`, 영역 정밀도는 분자 합 / 분모 합이다. 섹션 비율의 단순 평균을 대표값으로 사용하지 않는다.
- 정상 측정이 가능한 범위만 수치에 넣고 계획 표본 12개 대비 정상 측정 섹션 수, 미측정·예외 상태·태그 제외·mixed_scope 건수를 함께 공개한다. 9개만 가능하면 12개 완료로 표시하지 않는다.
- 원본/섹션/정답 버전/체크 대상 출력 해시/명세 버전/실행 시도 식별자를 연결한다. 재시도 출력 중 좋은 결과를 선택하거나 다른 입력의 결과를 합치지 않는다.
- 서비스 성과 지표와 독립된 고정 섹션 평가다. 최종 서비스 결과가 전체 제외됐다는 이유로 OCR 표본을 제외하지 않는다. OCR의 태그별 범위를 따른다.

## 채점기 구현 전 남은 세부 합의

v3에 명시되지 않은 동일 좌표의 정렬 동률 처리, 동일 최소 편집거리에서 S·D·I 내역이 달라지는 경우의 우선순위, 보조 공백 유지 CER의 성분 연결 구분자·양끝 공백 처리, 비회전 줄과 혼합된 성분의 rotated 별도 CER 귀속 방식은 임의로 구현하지 않는다. 대표값의 기존 정의는 위와 같으며, 이 세부 사항은 결과를 보기 전에 문서로 고정할 후속 확인 사항이다. 이번에는 채점기를 구현하거나 실제 CER을 계산하지 않는다.
