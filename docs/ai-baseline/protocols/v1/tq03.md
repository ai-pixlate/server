## 기존 실험과 대조한 추출·집계 규칙

다음은 기존 `protocol.py`, `full_runner.py`, 결과 JSONL과 통계 파일에서 확인한 동작이다. 기존 수치 재현과 최종판 조건 고정의 기준으로 사용하되 아래 경계 사례를 임의로 수정하지 않는다.

1. 모델 출력은 `raw_output`으로 보존한다. 엄격 파서는 `Feedback: Reason: … Issues: … Direction: … [RESULT] N` 전체 형식을 요구한다. 완전 충족 `ok`는 0개, `format_error`는 487개, `output_limit`는 4개다. 형식 불일치를 생성 실패나 0점으로 바꾸지 않는다.
2. 별도 표지 추출은 Python `re.findall(r'\[RESULT\]\s*([1-5])(?!\d)', raw)`를 사용하고 **일치가 정확히 한 개**이면 `reported_score`로 보존했다. 엄격 파서의 `score`와 구분한다. 실제 491개 출력 재대조에서 집계용 점수 불일치는 0개였다.
3. 평균·분포는 `status in ('ok', 'format_error')`이면서 `reported_score`가 있는 항목만 사용한다. 출력 토큰 수가 384 이상이면 `output_limit`로 분류하고 표지가 있어도 평균에서 제외한다. `input_limit`(입력 2048 초과), 실행 오류도 점수 집계에서 제외하며 상태별 수를 남긴다. 토큰을 잘라 재평가하거나 한도를 자동 변경하지 않는다.
4. 기본 합계 970 / 점수 확보 449 = 평균 2.1603563474점(표시 2.16/5). 분포는 1점 28, 2점 345, 3점 61, 4점 6, 5점 9개다. 점수 없는 42개는 표지 미확보 38개와 출력 한도 4개로 분리한다. `score` 필드는 전부 null이며 `reported_score` 추출이 구조화 형식 충족을 의미하지 않는다.
5. 기존 GS-02-block-430의 본문 2점은 `body_only_score`로 보존된 보조값이다. 이것만 더한 기존 보조 통계는 450개 평균 2.16이다. 기본 449개 통계와 섞지 않으며 다른 본문 점수를 임의 복구하지 않는다. 최종판의 본문 점수 취급은 아래 고정 전 결정 대상으로 남긴다.
6. 완료된 `ok/format_error` 결과는 재실행 시 건너뛴다. 오류·한도 항목은 명시한 ID만 재시도할 수 있었고, 시도별 기록과 현재 선택 결과를 구분했다. 이번 대조는 저장된 최종 결과 491개를 읽었을 뿐 새 시도를 만들지 않았다.
7. 점수 확보율은 `점수 확보 수 / 전체 적용 대상 수`로 병기한다. 평균은 점수 확보 수로 나누고, 결측은 0으로 대체하지 않는다. 점수 확보 0이면 평균은 미산출, 전체 대상 0이면 대상 없음으로 구분한다. TQ03 원시 상태를 H 지표의 `measured/evaluation_failed`로 자동 매핑하지 않는다.

주의: 기존 표지 정규식은 소수·표지 뒤 부가 문장 등까지 엄격한 정수 전체 형식으로 검증하지 않는다. 예를 들어 `[RESULT] 2.5`의 앞자리도 매칭될 수 있다. 이번 원본에서는 소수 표지·복수의 유효 표지 사례가 없었다. 정규식을 강화하면 추출 정책 변경이므로 최종판 측정 전에 결정·버전 고정하고, 기존 원시 출력에 대한 재집계가 필요하면 원래 결과와 구분한 파생본으로 남긴다.

## 버전 비교와 표시

절대 평균을 독립적인 성능 주장이나 합격률로 발표하지 않는다. v1.0.1 Baseline과 최종판 변화 비교에 한정하며, 동일 모델의 편향이 상쇄된다고 단정하지 않는다. 특정 문체·라벨·성분·숫자에 대한 평가 편향은 버전별 문구 구성에 따라 다르게 작용할 수 있다. 모델의 지적은 확정 오류가 아닌 사람 검토 후보이며, 한국어 요약 번역·별도 분석·사람 수정 후보와 모델 원문을 구분한다.

## 최종판 측정 전 남은 결정

1. **추출 경계 정책:** 기존 정규식을 그대로 고정할지, 소수·복수/충돌 표지·부가 텍스트에 대한 엄격 규칙을 채택할지. 강화 시 Baseline 파생 재집계의 범위·명세 버전도 함께 결정한다.
2. **본문 점수·재시도:** 기존 body-only 보조값을 최종판에서도 수집할지, 기본 표지 통계만 비교할지. 오류·한도 재시도 허용 범위, 최대 시도 및 대표 시도 선택 규칙을 정한다. 좋은 점수만 고르는 선택을 정당화하지 않는다.
3. **대상 대응:** 최종판의 번역 성공 범위, 분할·병합 블록의 원본 내용 대응, 짝 비교와 전체 집계의 대상 선정 규칙을 고정한다. 결측 처리로 대상 구성이 바뀐 사실을 숨기지 않는다.
4. **자료 접근과 실행 잠금:** 원시 결과·입력·프롬프트·환경 파일의 팀 접근 가능한 보존 위치와 접근 범위, 최종판 실행에 사용할 동일 조건 묶음의 검증을 완료한다. 이 PR은 원시 파일을 공개 저장소로 복제하지 않는다.
5. **이용 조건:** 가중치 이용 조건 미확정과 향후 지속 사용 범위는 별도 확인 대상이다. 지표 등록이 라이선스 확인을 대신하지 않는다.

위 항목의 결정·기록 후, 최종판 측정 전에 규칙 버전과 파일 해시를 잠근다. 이번 PR에서 임의로 정책을 선택하거나 모델을 실행하지 않는다. 기존 H01~H04 준비 묶음·지침 사본·동결 정답·채점 도구·실측 증거는 수정하지 않는다.
