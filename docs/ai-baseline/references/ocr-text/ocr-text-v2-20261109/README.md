# OCR Text v2 텍스트 정답 동결본

2026-11-09 사용자 승인으로 112개 섹션·1,861줄을 동결했다. 기존 v1 12개·369줄과 신규 100개·1,492줄로 구성한다.

신규 100개는 Codex 채팅 AI 검수 67개 통과·33개 검토 필요로 기록됐다. 사용자는 전수 대상 33개와 GS별 통과 20% 올림 표본 14개, 총 47개를 육안 검수하여 전사 오류 발견 0건으로 회신했다. 나머지 53개는 사용자 미검수다. 0건 결과의 범위는 47개에 한정한다.

## 16개 판독 불가·미전사 부분의 수용 결정

사용자는 미세 문구·번역 미사용 문구를 세밀하게 확인하지 않았다고 설명하고, 이전 보고의 16개에서 판독 불가 부분을 빈 정답으로 수용했다. 해당 16개 목록과 원래 지적 내용, 원문 승인 및 리비전별 검수 근거는 approval.json에 있다. 이는 판독 가능성 재검증 결과가 아닌 기준상 수용 결정이다.

기존에 전사된 문자열과 lines[] 순서를 유지했다. 이미 빈 줄은 빈 문자열로 유지하고, 줄 자체가 없는 미전사 영역은 연결 문자열에 0자로 기여한다. 임의의 줄 수·ID를 생성하지 않는다. 이 예외는 명시한 16개에만 적용한다. OCR 출력은 삭제·필터링 없이 연결하므로 수용한 빈 정답 영역에서 인식한 문자도 전체 편집거리에 반영될 수 있다. 해당 한계를 후속 결과에 함께 표시한다.

spec-v4.txt는 기존 CER v4 스냅샷이다. 그 문서의 최초 12개 범위를 이번 사용자 승인으로 112개로 확대하며 L008 한정 예외에 위 16개 수용 결정을 추가한다. 계산식·NFC·공백·연결 순서·0분모 규칙을 승계한다. 텍스트 없는 사진 2개는 N=0 규칙을 적용한다. bbox·겹침 검증은 수행하지 않았다.

## 재현과 검증

text_units.jsonl은 기존 12개 단위 객체를 그대로 재사용하고 신규 단위에는 초안 경로·해시, 이미지 경로·SHA-256·크기, 줄 ID·인덱스·순서를 보존한다. approval.json은 표본 계획과 AI·사람 검수 스냅샷, 사용자 미검수 범위와 승인 근거를 보존한다. manifest.json은 파일별 해시와 동결 이력을 기록한다.

기존 도구의 verify 명령으로 동결본을 검증할 수 있다. 입력 이미지 112개는 로컬 고정 경로에 있으며 외부 공유·백업 완료는 미확인이다. 정확한 Codex 모델·설정 증빙도 미확보다. 추가 OCR 42개와 CER 측정은 별도 실행 승인 후 진행한다.
