# Baseline 격리 환경·소규모 실제 연결 점검

## 1. 질문

v1.0.1(`bfa3b700144467f4adf7d6802b7b2e93791fe6de`)의 OCR·LaMa·Gemini를 Windows 격리 환경에서 사용할 수 있는가? 공식 Baseline 실행과 별도로 사용자가 승인한 연결 점검이며 유료 API 상한은 $2다.

## 2. 표본

공식 GS-01~03 이미지를 사용하지 않았다. 직접 만든 512×256 단색 배경에 `TEST 123`, `연결 점검 50 ml`를 그린 이미지와 사각 마스크를 사용했다. Gemini에는 별도로 만든 연결 점검 안내문 1블록을 번역하도록 했다. 공식 평가 단위·정답 기준 자료로 사용하지 않는다.

## 3. 조건

- 제품 코드·설정·프롬프트는 v1.0.1 그대로다. 개발 환경과 이전 전용 venv는 보존하고 `.cache/bl-venv-locked-20261028`의 패키지만 정비했다.
- 운영 API 목록과 다른 13개 중 10개를 맞췄다. Pillow 12.3.0, google-genai 2.29.0 포함. PaddleX 제약 때문에 NumPy 2.3.5·PyYAML 6.0.2를 유지하고 Windows 미지원 uvloop는 제외했다.
- OCR은 릴리즈 PP-OCRv5 설정/CPU, LaMa는 같은 TorchScript 가중치/CUDA:0/FP32다. 자식 프로세스도 릴리즈 초기화 60초·추론 30초·종료 유예 5초로 확인했다.
- Gemini는 릴리즈 번역 호출자·프롬프트·JSON 스키마, gemini-3.8-flash/temperature=0/timeout=60초를 사용했다. SDK 자동 재시도 없음, HTTP 전송 재시도 0, redirect 금지, 도구/자동 함수 호출 없음, 유료 전송 최대 1회다.
- [공식 가격](https://ai.google.dev/gemini-api/docs/pricing)과 [모델 한도](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)를 2026-10-28 확인했다. 입력 $0.75/M·응답/사고 $3.75/M, 입력 최대 1,048,576·출력 최대 65,536토큰으로 요청 1회 최대 $1.032192다. $1.04를 사전 예약하고 영구 시작 기록으로 중복 호출을 차단했다.

## 4. 결과

성공 기준은 초기화·사용 가능한 출력·시간 제한 내 반환·기록 보존이다. 품질 점수나 공식 지표는 산출하지 않았다.

| 항목 | 결과 |
|---|---|
| OCR | 최초 Paddle→Torch 순서에서 shm.dll WinError 127. 새 프로세스에서 Torch 선로딩 후 성공: `TEST 123`, `연결 점검50ml`, 신뢰도 약 0.9805·0.9900 |
| OCR 시간 | 선로딩 재검증 초기화 12.016초, 추론 2.515초. 실행 도구 초기화 함수 연결 후 OCR 구간 7.703초 |
| LaMa | 직접 GPU 초기화 4.422초·추론 1.406초, 512×256 uint8 출력. 릴리즈 자식 프로세스 경로도 초기화+추론 약 5.750초로 성공 |
| Gemini | 실제 전송 1회, 6.000초, 번역 JSON 응답 검증 통과 |
| 토큰·비용 | 입력 608·응답 27·사고 250, 합계 885토큰. 추정 $0.00149475, 실제 청구서 금액은 미확인. 예약 정산 및 두 번째 호출 차단 확인 |
| 렌더 | Pillow 13.0.0/12.3.0의 별도 영문 합성 표본에서 픽셀 해시·2줄 배치 동일. 운영 Linux나 전체 입력 동등성의 증거는 아님 |
| 회귀 | Baseline 합성 106건, 제품 렌더·폰트·브로커 24건 통과(별도 DB 조건 1건 생략), 로컬 DB+가짜 AI 통합 6건 통과 |

실제 시간 초과는 없었다. 테스트 스크립트의 Gemini 인자 오류는 API 전송 전에 발생했고, LaMa factory 표기 오류는 자식 모델 로딩 전에 발생했다. 각각 릴리즈의 호출 서명·상수를 사용해 보정했다. 최초 실패 기록은 보존했다. 실제 유료 요청 원장은 `gemini-corrected-usage.jsonl`이다. 초기 인자 오류 후 로컬 금지 콜백을 검사한 `gemini-usage.jsonl`은 외부 전송 0회인 테스트 기록으로 API 지출에 합산하지 않는다. 유료 API 재시도는 없었다. OCR은 총 3회 실제 추론 성공(최초 초기화 실패 별도), LaMa는 직접/자식 경로 각 1회 성공했으며 모두 같은 합성 입력이다.

로컬 증거는 `.cache/baseline-connection-check-20261028/`의 environment.json, ocr*.json/log, lama.json, combined-local.json/log, gemini*.json/jsonl, render-*.json/png, 설치·시험 로그다. 입력/출력·설정·폰트 해시는 환경 보고서에 보존했다. 키·연결 문자열을 증거로 저장하지 않았으며 이 로컬 폴더를 공유 완료로 표시하지 않는다.

## 5. 판단

Windows 측정 도구에서 Torch 선로딩을 채택한다. 패키지 정비와 소규모 개별 연결은 통과했지만 공식 34장 종단 실행·큰 이미지 VRAM/시간 한도·이미지 VLM 요청은 검증하지 않았다. 운영 OS/Python/GPU 워커와의 동등성도 미확인이다. 기준 자료 동결과 공식 실행 승인은 계속 보류한다.

## 6. 반영

2026-10-28 `tools/baseline/be.py`의 승인 후 환경 초기화에 Torch 선로딩과 기록을 추가했다. Windows 패키지 해시 lock과 Baseline 실행·비용 문서에 결과를 연결했다. 제품 코드·기본 파라미터·평가 지표 변경은 없다. 이 기록으로 공식 Baseline 실행을 승인하지 않는다.
