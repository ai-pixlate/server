## 파일과 무결성

기존 원시 파일에는 CRLF와 LF가 섞여 있다. SHA-256을 유지하기 위해 Git 저장 시 줄바꿈 정규화 없이 원래 bytes를 보존한다. 원시 파일에 편집기 자동 저장이나 `git add --renormalize`를 적용하지 않는다. 다운로드/복원 후 색인의 SHA-256을 대조한다. 색인 자신의 해시는 자기 참조로 넣지 않으며 Git 커밋과 tree/blob 식별자로 검증한다.

확장자 없는 이미지·객체도 원래 이름을 유지한다. GitHub 미리보기 제한이 있으면 Raw/Download로 접근한다. HTML 검수 화면은 GitHub에서 실행되지 않으므로 내려받은 회차 폴더에서 열어야 한다. 기존 절대 로컬 경로는 당시 환경 증거이며 GitHub 공유 URL이 아니다. 원본과 결과의 실제 파일은 회차 내부에 보존돼 있다. 기준 초안의 이전 근거 경로 해석은 평가 준비 보고서를 따른다.
