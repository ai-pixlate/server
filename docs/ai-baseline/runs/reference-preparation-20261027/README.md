# GS-v1 기준 자료 초안 — 사람 검수 준비

> 상태: **PM 검토 전 초안 · 동결하지 않음 · 공식 실측 아님 · 사용자 비용·실행 승인 보류**

2026-10-27 GS-01~03 원본 **34/34장**을 Codex 채팅에서 직접 열람해 **324개 기준 단위 후보**를 작성했다. PM 확인·동결은 **0장**, PM 확인 대상은 **34장**이다. 이 중 **21장**에는 단순 미검토 외에 전사 미완료·원본 간 차이·정책 적용 불확실성도 있다. 그림만 있는 원본에는 없는 수치/문구를 만들지 않았다. 초안 작성 완료가 모든 작은 글씨의 전사 완료나 평가 정답의 완성을 뜻하지 않는다.

2026-10-28 범위 변경 안내: [이번 회차](../../plan.md#이번-회차-측정-범위--pm-승인-완료)는 AI 최초 선택·번역문을 유지하며 PM 승인이 완료됐다(2026-10-28 사용자 확인). 아래 2026-10-27 초안 내용·검증 기록·해시는 보존한다. 초안의 미국 판매 구성/사용자 선택 관련 질문은 정책 기대 검토와 후속 서비스 평가 질문으로 구분하며 이번 회차 편집을 요구하지 않는다. PM의 기준 자료·평가 결과 검수는 계속 필요하다.

## PM 검수 요청 준비

[PM 검수 시작 안내](pm-review.md)에서 우선 21장과 기본 확인 13장을 열고, 기존 [검토 목록](review-list.md)의 항목별 회신란을 사용한다. 원본·좌표·기대값·정책 근거를 연결했으며 기준 단위를 다시 작성하지 않았다. 요청 준비본은 로컬 전용이며 전달·PM 회신·승인·동결은 수행하지 않았다. A등급 결과 표본 검수는 실측 후의 별도 절차다.

원본은 [GS-v1 manifest](../../../../pipeline/samples/evaluation/gs-v1/manifest.json)의 SHA-256으로 고정했다. 과거 OCR·모델 응답·실측 결과는 정답으로 사용하지 않았다. 55개 확인용 타일로 모든 원본 픽셀을 열람했고 작은 각주 일부는 원본으로 다시 확인했다. 타일은 로컬 `.cache/`의 열람 보조 자료이며 원본을 대체하지 않는다. 새 외부 모델 API·OCR·LaMa·제품 실행은 하지 않았다.

정책 기대의 근거는 고정 사전과 [평가셋 정책 예외](../../protocols/v1/dataset.md)다. 표시된 효능·임상 결과가 사실임을 독립 검증하거나 미국 규제 적합성을 인증한 자료가 아니다. 미국 시험 요건 등 확인되지 않은 기대를 정상으로 채우지 않는다. 실제 Codex 모델 표시명·설정은 이번 작성에서 확인하지 못했으며 `GPT-6 Astra (light)` 등으로 추정 기록하지 않는다. 공식 평가 시에는 [평가 기록 요건](../../protocols/v1/evaluation.md#ai-평가-방식)을 별도로 충족해야 한다.

## 초안 해석과 도구 연결

- 필드/좌표 정의는 [회차 구조](../README.md#공통-필드와-연결-규칙)를 재사용한다. 좌표는 원본 픽셀이며 문맥을 포함한 넓은 확인 영역이다. 정밀 OCR 박스·제품의 실제 분할 경계를 정답으로 고정한 것이 아니다. K01~09는 기존 좌표 그대로다.
- 모든 행의 `verified_by`, `verified_at`, `verification_ref`는 null이다. `expected_value.human_confirmation_required=true`는 **PM 확인 필요**, `expected_value.uncertainty`의 구체적인 이유는 **별도 판단 불확실/전사 미완료**를 뜻한다. 둘은 별개다. 모든 원본의 전체 적용 여부도 PM 확인 전 null로 둔다.
- `critical_fact`는 확인된 사실의 중요도·단위 후보이며 H04 분모에 아직 넣지 않는다. 표/그림의 시험 조건을 잃지 않도록 인접 문맥 단위를 함께 확인한다. `applicability.H04`는 두 체크포인트 모두 미정(null)이다. PM은 채택할 단위의 중요도·중복·적용 여부를 검토한다. `semantic_block`, `protected_visual`, `layout_region`은 H04 사실 분모에 합산하지 않는다.
- 정책의 일부 영역 기대와 원본 전체 적용 여부를 구분한다. 초안의 `applicability.H01` 및 `expected_value.all_sections_excluded`는 null이다. 동결 시 H01 적용 여부는 원본 전체 검토 단위에서만 확정하고 영역별 정책 단위의 H01 키는 제거한다. 적용 대상이 하나라도 있으면 true, **정답 기준 모든 섹션 제외가 맞을 때만** false와 `all_sections_excluded=true`로 확정한다. 시스템이 전부 제외했다는 사실만으로 false를 정하지 않는다.
- 이 폴더는 공식 회차가 아닌 검토 묶음이라 실행용 manifest를 두지 않았다. `basis_refs`의 `artifacts/<원본 해시>.jpg`와 `artifacts/protocol-dataset.md`는 기존 `protocol.prepare`가 준비 회차에 보존하는 경로다. 초안의 작성 당시 정책 근거는 [보존 사본](artifacts/protocol-dataset.txt)으로 별도 유지했다. 이는 현재 실행 규칙이 아닌 2026-10-27 근거 스냅샷이다. 과거 초안의 해시 검증 시 이 사본을 검증용 준비 폴더의 artifacts/protocol-dataset.md에 배치한다. 실제 회차 준비 시 최신 정책 스냅샷으로 참조를 몰래 바꾸지 말고 검토·동결한 기준 버전과 경로·해시를 명시적으로 연결한다. 원본 21MB를 이 폴더에 중복 저장하지 않는다. 저장소 원본 경로/해시는 draft-index에서 연결한다.
- 비과금 검증용으로만 `.cache/`에 `protocol.prepare`를 사용한 빈 준비 회차를 만들고, 같은 이름의 사전 색인 사본을 배치해 파일·해시 참조를 검사한다. 이후 `check_row(reference_units)`가 PM 미확인 324행 전부를 거부하는지 확인한다. **초안을 record/동결/집계하지 않는다.** 도구 코드 수정은 없다.
- 추후 PM 수정·확인 이력을 artifacts에 보존한 뒤 별도 동결본을 만든다. 실제 회차 ID·기준 버전, 두 체크포인트 적용 여부, 검증자·시간·근거 파일을 확정하고 기존 `record` 검증을 통과시킨다. 정책 근거도 해당 회차로 보존하고 경로·해시를 재결합한다. 초안 파일의 이름만 바꾸거나 null을 자동 채워 정답으로 승격하지 않는다. 원본에서 추가 핵심 사실을 찾으면 새 단위로 보완한다.

## PM 우선 확인 사항

구조 검증에서 원본 34장 해시·324개 ID/필수 필드/좌표 범위·K01~09 좌표 일치를 확인했다. 기존 도구의 정답 등록 검증은 324행 모두 `사람 확인·동결 근거 필요`로 거부했다. 검증용 준비 회차의 정답 파일은 비어 있고 reference_freeze·사용자 실행 승인은 null이다. 내부 Markdown 링크/앵커 152개와 `git diff --check`도 통과했다. 이 검증은 내용의 사람 검증이나 제품 실측을 대신하지 않는다.

1. **GS-01:** SPF 50+/PA++++ 및 시험값·±·각주, 미국 시험 조건 불명, Reef Safe/비건 근거 범위, 18 Free 작은 성분 목록. GS-01_001 리뉴얼/교환·환불 문구와 1+1 구성의 섹션 처리.
2. **GS-02:** 15ml+3ml 국내 증정 구성, GS-02_001 국내 이벤트 전체 제외 적합성 및 재발송 날짜 차이, GS-02_005의 표시값 **0.00%**와 이웃 원본의 892.35%를 혼동하지 않기. GS-02_007의 가로모공 **-13.13%**와 GS-02_009의 **-13.33%**, 리프팅 증감 부호 차이. 원본을 임의 정정하지 않는다.
3. **GS-02 사용법:** 2mm(0.2g)/4mm(0.4g), 2주/3주 안내와 초기 한 달 숙련도별 표의 적용 관계, 다음 날 자외선차단제, 임산부·수유부·동시 사용 주의. 병용/단독·레티놀/레티날·원료가격/효과 배수 구분.
4. **GS-03:** 커버 톤업/미백/밝아짐의 문맥 구분, 118.9%와 2배의 서로 다른 비교 조건, 300mL·개봉 후 12개월·주문일 기준 36개월 이내 제조, 주의사항과 전성분 작은 글씨. 설문 각주의 25~29세와 다른 시험의 25~59세 차이를 그대로 확인한다. 보이지 않는 그래프 수치는 만들지 않는다.
5. **정책 기대:** 명확한 미백 RG-024 대체와 각질층 착색의 기존 RG-025 적용 예외를 혼동하지 않는다. `밝아진다`만으로 미백을 확정하지 않는다. 허용 표현은 결함이 아니며, 조건부 표현은 필요한 N5 경고를 확인한다. 국내 연락처·환불 문구를 포함한 **실제 섹션** 제외와 함께 잃은 상품 정보는 구분한다. 셀러가 결정할 미국 판매 구성/N3 선택을 PM 평가 검수로 대신 확정하지 않는다.

## 사람 검수와 동결 전 남은 일

담당자·시간·종료 조건 및 A등급 표본 추천안은 [7단계 사람 검수](../../protocols/v1/evaluation.md#7단계-사람-검수-프로토콜)가 소유한다. 이번 회차의 N3/N5 필수 확인 담당자는 아직 지정되지 않았고 PM의 평가 검수 역할과 구분한다. N5 박스 수정은 [v1.0.1 기능 확인](../../protocols/v1/evaluation.md#n5-박스-수정-기능-확인)에 따라 기능 미지원이다.

PM은 34장의 핵심 단위·좌표·문맥·정책 기대 및 중요도를 확인하고, 작은 글씨 미전사/불확실 항목을 보완하거나 근거 부족을 유지해야 한다. 원본 간 차이를 수정할 필요가 있으면 원문 값과 PM의 별도 근거를 함께 남긴다. 확실하지 않은 정책/사실을 자동 정상 처리하지 않는다. 동결 범위·버전·검증 이력, N3/N5 필수 확인 담당자·최초 선택 유지 기록, A표본 추천안 채택이 남아 있다. **사람 검수·동결·공식 실행·제품 모델 호출을 이번 작업에서 수행하지 않았다. 사용자 최종 비용·실행 승인은 계속 보류다.**
