## 웹 열람과 근거의 범위

원본은 이미 공개 저장소에 있는 34장의 JPEG를 사용한다. 검토표는 develop 기준 커밋 `dc038bdfa937b3d9762e2af0a8a97929e62f5ff9`의 GitHub 이미지 페이지와 원본 크기 링크를 가리킨다. 새 이미지·타일·모델 출력·개인 환경 파일은 추가하지 않는다. 공개 페이지는 로그인/clone 없이 읽고, 코멘트 작성은 GitHub 로그인 후 한다. PM 계정으로 실제 열람/회신한 것으로 대신 기록하지 않는다.

draft-index의 `.cache/` 사전 경로는 작성 당시 출처 기록이지 웹 링크가 아니다. 사전 원본 XLSX는 이 PR에 포함하지 않으며 PM은 제공된 원천 행 색인과 정책 근거 사본을 검토한다. 추가 원천 증빙이 필요하면 해당 ID를 판단 보류로 회신한다. 개인 PC 경로나 .cache 파일의 공유를 완료했다고 표시하지 않는다.

## 초안 해석과 도구 연결

원본 좌표는 좌상단 기준 `[x_min,y_min,x_max,y_max]`, 끝 좌표 제외다. 원본 전체·주변 문맥을 포함한 영역이며 제품의 실제 섹션 경계를 고정하지 않는다. GS-01의 원본별 H01/H04 기대는 실제 AI 분할과 독립적인 11/3 PM 회신을 반영했다. JSONL의 basis_refs는 후속 준비 회차 내 상대 경로다. 원본은 검토표의 웹 링크 및 draft-index의 해시로, 정책 근거는 위 보존 사본으로 확인한다. 이 검수 전용 폴더에서 실행·집계하거나 파일 이름만 바꿔 동결하지 않는다.

PM 회신 원문·코멘트 URL·대상 ID·초안 버전을 보존하고 수정 전후를 연결한다. 수정 후 PM 재확인, 적용 여부·중요도·좌표·해시 확인 및 동결 범위/버전 확인이 끝나야 별도 동결본을 만들 수 있다. 불확실한 값을 정상/0건으로 채우지 않는다. 세부 절차는 [검수 안내](pm-review.md#회신-반영과-동결-절차)를 따른다. 이 PR 생성·리뷰 요청·병합은 기준 자료의 자동 동결이나 유료 실행 승인이 아니다.

## PR #94 리뷰 후 관리 결정

#93은 PM 검수 의견을 받은 뒤 **병합하지 않고 닫는다**. 지금 닫거나 자료를 동결하지 않는다. 이 폴더의 기존 7개는 #94에서 검수 전 초안으로 보존됐으며, 이번 GS-01 반영분도 미동결이다. PM 검수 완료 후 동결본은 `docs/ai-baseline/references/gs-v1/`의 별도 파일과 새 PR로 관리한다. 공식 회차는 승인된 동결본을 참조·복사하고 해시를 기록한다. [현재 비용·생성/채점 결정](../../cost-estimate.md#pr-제출-시-승인-상태)을 따르며 동결 전 이미지 생성은 허용하고 H01~H04 공식 채점은 동결 후 진행한다. 기존 초안의 미확인 값이나 검수란은 승인으로 채우지 않는다.
