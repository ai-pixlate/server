## 회신 및 완료 관리

실제 PR 코멘트의 항목 ID와 PM 이름·날짜·URL로 회신을 연결한다. 반영본에 오류가 있으면 `ID / 수정 필요 / 올바른 값·근거`, 추가 판단이 필요하면 `ID / 판단 보류 / 사유`로 기록한다. 이번 후보는 PM 최종 의견을 반영한 것이며 수정 반영본을 PM이 재검토했다고 표시하지 않는다.

PM은 검수 담당자이며 원본당 제한 시간은 없다. 필요한 확인·수정이 완료됐을 때 종료한다. 실측 후 A등급 표본 검수와 N3·N5 실제 확인 역할은 기준 자료 검수와 별개다.

## 회신 반영과 동결 절차

1. PM 코멘트 원문·ID·날짜와 적용 우선순위를 보존한다. 초기 AI 초안과 과거 동결본·실측 증거·사전을 덮어쓰지 않는다.
2. 반영본의 기대값·중요도·H01/H04·좌표·신규 단위·누락/중복 및 근거 해시를 확인한다. 이번 후보의 모든 verified_*와 reference_freeze는 null이며 동결 승인이 아니다.
3. PM의 반영 확인과 사용자의 동결 범위·버전 승인을 받은 뒤 별도 동결본을 만든다. GS-01 기존 동결은 유지하고 GS-02·03 후보는 미동결로 남긴다. 복수 번역을 허용하는 정책 기대값은 내용 미확정과 구분한다.
4. 동결 시 실제 승인 근거·원본/기준 단위 해시·버전·변경 이력 및 회차 연결을 보존한다. 현재 변경만으로 공식 채점·새 실측을 시작하지 않는다.
5. #93은 병합하지 않는다. 검수 의견 반영 뒤 별도 지시에 따라 닫고, 동결본은 별도 PR로 관리한다.

이번 작업에는 PM 대신 승인·동결하거나 사전·제품 코드·기존 실측 결과를 바꾸는 작업이 포함되지 않는다.
