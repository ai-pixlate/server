# ② OCR 채점 명세 v1

> 상태: **동결** (2026-09-23 사용자 결정). **v2로 대체됨** — 보존용. 보관: `docs/ai-experiments/`(2026-09-23 규칙 #35로 PoC 레포 대신). 동결 기준은 이 파일을 추가한 커밋이다.
> 이 파일은 실험 1건이 아니라 ② OCR 품질 실험들이 공유하는 채점 기준이다(정답과 짝, `dev.md` 5절).
> 범위: ② OCR 초기 품질 표본(10~12개 섹션)의 채점. 제품 파라미터가 아니라 채점 규칙이다. 결과를 보고 바꾸지 않는다.
> 결과 표현: "이 표본 N개 섹션 · 이 규칙 기준"으로만 서술한다. 표본 밖 일반 보장으로 쓰지 않는다.

## 0. 표본과 동결 순서

- 품질 표본과 프로브 표본은 분리한다. 품질 표본 후보를 먼저 정하고, 프로브는 그 밖의 섹션에서만 한다.
- 품질 표본 섹션은 정답 v1과 이 명세 v1을 동결(해시 기록)하기 전까지 어떤 OCR에도 넣지 않는다.
- 입력은 OCR 고정 입력 v1의 섹션 이미지다. 정답은 섹션 이미지 SHA-256에 묶는다(입력이 바뀌면 정답 무효).
- 정답·명세 수정은 사유와 이미지 근거를 남겨 v2로 올리고, 비교하는 모든 실행을 다시 채점한다.

## 1. 정답 작성

### 1.1 줄 텍스트

- 채점 단위 = **정답 줄**: 같은 기준선 위에 이어진 한 줄의 글자.
- 초안은 Gemini 전사, 사람이 이미지 기준으로 줄마다 전수 대조한다. OCR 결과를 보고 정답을 고치지 않는다.
- 표는 **셀마다 따로 줄**. 한 정답 줄은 셀 경계를 넘지 않는다.

### 1.2 줄 bbox (품질 표본 전 섹션, B군 없음)

- 한 줄의 모든 글자 잉크 외곽(받침 · 하강부 · 부호 · 문장부호 포함)에 맞춘다.
- 여백은 상하좌우 각각 **최대** 잉크 외곽 높이(여백 제외)의 10%. 모든 bbox에 10%를 더하는 규칙이 아니다.
- 정답 bbox끼리 겹치지 않는다. 잉크가 실제로 겹쳐 불가피하면 `ink_overlap` 태그로만 허용.

### 1.3 태그

| 태그 | 뜻 |
|---|---|
| `illegible` | 판독 불가 |
| `section_cut` | 섹션 경계에서 잘린 줄(① 기인) |
| `logo` | 로고 글자 |
| `product_label` | 제품 라벨 글자 |
| `ink_overlap` | 잉크가 다른 줄과 실제로 겹침 |

### 1.4 검수

- 자동: 좌표 유효성 · 섹션 범위 이탈 · 정답 bbox 겹침(`ink_overlap` 외 불허).
- 사람: 글자 누락 · 여백 10% 이하 · 셀 경계 준수 (잉크 마스크가 없으므로 여백은 자동 검사하지 않는다).
- 정답 v1은 **1인 검수**로 기록하고 결과 보고에도 밝힌다. 검수 수정 내역은 기록한다.

## 2. 지표 대상 줄

| 태그 | OCR 전체 지표 | 후속 처리 대상 지표 | 별도 보고 |
|---|---|---|---|
| `illegible` | 제외 | 제외 | 줄 수 |
| `section_cut` | 제외 | 제외 | ① 기인 줄 수 |
| `logo` | **포함** | 제외 | — |
| `product_label` | **포함** | 제외 | — |
| `ink_overlap` | 포함 | 포함 | 줄 수 |

아래 모든 규칙은 지표마다 위 표의 제외 목록으로 따로 적용한다.

## 3. 대응

- 간선(영역 r, 정답 줄 L): `area(r ∩ L) / area(r) ≥ 0.5` **또는** `area(r ∩ L) / area(L) ≥ 0.5`. 영역 bbox는 OCR `bbox`.
- 간선의 연결 성분을 1:1 / 1:n(분리) / n:1(병합) / n:m으로 분류한다.
- 해석 제한: 줄 재현율·영역 정밀도는 "대응 기준을 만족한 비율"이며 검출 품질을 뜻하지 않는다. CER · 병합 · 중복 · 과대 대응 지표와 함께 판단한다.
- 이 규칙으로 잡히지 않는 병합이 있으므로 "모든 병합을 자동 분류한다"고 쓰지 않는다.

### 3.1 혼합 대응 (`mixed_scope`)

| 영역이 대응한 줄 | 처리 |
|---|---|
| 제외 줄에만 | 그 지표에서 영역 제외(삽입·오검출 아님) |
| 포함 줄에만 | 정상 집계 |
| 포함 줄 + 제외 줄 | `mixed_scope` 별도 집계 |

`mixed_scope` 성분: CER 계산에서 성분 전체 제외(제외한 포함 줄 수·글자 수 공개) · 영역 정밀도 분자·분모에서 제외(영역 수 공개) · 줄 재현율에서는 성분 안 포함 줄을 "대응됨"으로 집계(`mixed_scope` 줄 수 공개).

## 4. 지표

| 지표 | 정의 |
|---|---|
| 줄 재현율 | 대응된 대상 줄 / 대상 줄 |
| 영역 정밀도 | 대상 줄에 대응된 영역 / (전체 영역 − 제외 줄에만 대응된 영역 − `mixed_scope` 영역). 조각·중복 영역도 분자에 들어가는 영역 단위 지표. 빈 텍스트 영역도 검출로 센다 |
| 전체 CER | (치환 + 삭제 + 삽입) / 대상 줄 글자 수. 성분 CER = 성분 안 영역 텍스트를 위→아래 · 왼→오른쪽으로 이은 것 vs 성분 정답 줄을 같은 순서로 이은 것. 미대응 대상 줄 = 전 글자 삭제. 미대응 영역(제외·`mixed_scope` 제외)의 텍스트 = 삽입. 치환·삭제·삽입 각각 보고 |
| 검출 줄 CER (보조) | 대응된 성분만의 CER |
| CER 분포 | 성분별. 1:1 · 1:n은 줄별 값과 같다. n:1 · n:m은 개수와 성분 CER만 보고하고 줄별로 배분하지 않는다 |
| 분리 | 1:n 성분 수 · 줄당 영역 수 분포 |
| 병합 | n:1 · n:m 성분 수(대응 규칙으로 검출된 것) |
| 병합 의심 | 미대응 영역 중 두 개 이상 정답 줄과 교집합이 있는 것의 수 |
| 과대 대응 영역 | `area(r ∩ 대응된 줄들의 합집합) / area(r) < 0.5`인데 둘째 조건으로만 대응된 영역 수 |
| 중복 의심 쌍 | 같은 정답 줄에 대응한 두 영역의 교집합 ≥ 작은 쪽 면적의 0.5. 순서 없는 영역 쌍은 여러 줄에 함께 대응해도 한 번만 센다. 겹침만으로 실제 중복을 확정하지 않는다 |
| 오검출 | 미대응 영역 수 — 빈 텍스트 여부 · 이음매 중복(`ocr_debug.json`) 여부로 나눠 보고 |

- 분모가 0이면 `N/A (분모 0)`로 표시하고 평균에서 뺀다.
- 원인 구분: ① 기인(`section_cut`) / ② 기인 / ② 임시 분할 기인(`ocr_debug.json`으로 이음매 판별)을 나눠 보고한다.

## 5. 정규화

- 기본 CER: NFC · 공백 전부 제거 · 문장부호 · 대소문자 · 전각 유지.
- 보조 CER: NFC · 연속 공백 1개로 축약해 유지.
- NFKC는 쓰지 않는다(`㎖`→`mL`, `①`→`1`처럼 정답 자체를 바꾼다).
