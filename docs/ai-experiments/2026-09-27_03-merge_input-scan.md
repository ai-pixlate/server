# 2026-09-27 ③ 병합 입력 사실 확인 — `merge-input-v1` 영역 스캔

## 1. 질문

③ 휴리스틱 잠정 설계(`open-questions.md` #38)를 정하기 전에, 설계가 가정하는 입력 특성을 확인한다.

- 빈 텍스트 영역의 형태와 score — 빈 블록의 `ocr_confidence`를 일반화할 수 있는가
- 폭·높이 0 영역이 실제로 나오는가
- 정렬 동률이 실제로 생기는가
- PoC 역할 규칙(가격 정규식 · 주의문구 키워드)이 이 입력에서 무엇에 걸리는가

## 2. 표본

`pipeline/samples/local/merge-input-v1/`의 OCR JSON 100개(섹션 100개 · 영역 1,815개). 품질 표본 12개는 입력본에서 이미 빠져 있다.

## 3. 조건

- 읽기 전용 스캔. 병합·역할 코드는 없다(미구현).
- **영역 단위** 관찰이다. 병합된 블록 단위 결과가 아니며, 가격의 40자 조건은 적용하지 않았다.
- 주의문구는 PoC 키워드 17개의 부분 문자열 포함으로 셌다(PoC 자료가 키워드 목록으로 전달돼 단순 대안 정규식으로 가정).
