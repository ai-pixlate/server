# 2026-09-29 ④ 제품 라벨 판정 검수 명세 v1

④ 단독 실측(`open-questions.md` #66, `docs/ai/pipeline.md` 7.4절)의 결과를 섹션 이미지와 대조할 때 쓰는 분류 기준이다. AI 검토와 사용자 검수가 같은 분류를 쓴다. 정답 데이터 작성 명세가 아니며, 이 명세로 낸 집계는 정확도가 아니라 **검토한 범위의 관찰값**이다.

## 1. 판정 정의(정본)

- `is_product_label = true`: 블록 글자가 **사진 속 실물 제품의 용기 · 패키지(병 · 튜브 · 캡 · 단상자 · 제품에 붙은 스티커 등)에 인쇄 · 부착된 것**. [계약 2.2]
- 제품명 · 브랜드명이라도 페이지 배경 · 여백에 얹은 디자인 글자는 false. 논문 · 인증서 · 화면 캡처 · 표 안의 글자도 패키지 인쇄가 아니면 false(별도 제외 정책은 `open-questions.md` #39 후속).
- 애매하면 라벨(true) 편향은 정본 규칙이다. 따라서 "패키지 위인지 페이지 위인지 이미지로 가릴 수 없는" 블록의 true는 과보호로 세지 않고 `unsure`로 둔다.

## 2. 블록 분류

블록마다 하나. 공백 블록(④ `basis=blank_text`, VLM 미전송)은 분류하지 않는다(규칙 동작이라 별도 집계).

| 분류 | 조건 |
|---|---|
| `ok` | 판정이 1절 정의에 맞다 |
| `miss` | **라벨 미탐** — 블록 글자가 전부 또는 일부 패키지 인쇄인데 false |
| `overprotect` | **일반 문구 과보호** — 블록 글자가 전부 페이지 디자인 글자(패키지 인쇄 없음)인데 true |
| `mixed` | **상류 과병합 영향** — 한 블록에 패키지 인쇄 글자와 페이지 글자가 섞여 있다(③ 과병합). true면 방침(블록 전체 보호)대로이므로 `mixed`, false면 `miss`로 적고 메모에 "혼합" |
| `unsure` | 이미지로 패키지 인쇄 여부를 가릴 수 없다(너무 작음 · 흐림 · 가려짐), 또는 OCR 블록이 글자가 아닌 곳(사진 · 도형)을 가리킨다 |

- 메모(`note`)에 근거를 짧게 적는다. 긴 섹션에서 이미지가 작아 판단이 어려웠으면 "긴 섹션"이라고 적는다.
- 실행 실패 섹션(`status=failed`)은 블록을 분류하지 않고 섹션 단위로 실패 원인만 적는다.

## 3. 집계 원칙

- 라벨 미탐 · 일반 문구 과보호 · 상류 과병합 영향 · 실행 실패를 **따로** 센다. 혼합 블록의 true는 과보호에 넣지 않는다.
- 자동 검사(실행 상태 · 응답 검증 · 불변식), AI 검토(에이전트, 사람 판단 아님), 사용자 검수를 구분해 적는다.
- 정답 전수 검수 전에는 정확도 · 재현율 같은 비율을 성능으로 주장하지 않고, 합격 기준 수치를 만들지 않는다.
- 입력(`blocks-input-v1`)은 정답이 아니다. OCR 누락 · 병합 오류와 ④ 판정 오류를 구분한다(OCR이 놓친 패키지 글자는 ④ 미탐이 아니다).
