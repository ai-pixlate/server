# 2026-11-26 A+ 압축 뒤 규칙 검사 시험

> 압축 뒤 규칙 검사(`pipeline/aplus/recheck.py`)를 실제 압축 결과에 처음 돌린 기록이다. 수치는 도구 출력이며 모델 호출과 사람 판단이 없다. 사전은 로컬에 있던 이전 판이고 용어 목록이 없어 강제 용어는 검사하지 않았다. 결론은 아래 세 상품 범위에 한정한다.

## 1. 질문

압축이 바꾼 문구에 원본 규격 유지 경로의 번역문 규칙 검사를 돌리면 무엇이 검출되는가(`docs/ai/aplus.md` 4.8, `docs/ai/open-questions.md` #96).

## 2. 표본

- 2026-11-26 압축 실행 결과 3개(`aplus-compress-trial_2026-11-26_GS-01` · `_GS-02` · `_GS-03_r2`의 `aplus_compress.json`). 읽기만 했다.
- 압축이 문구를 바꾼 칸 12개다(GS-01 5 · GS-02 4 · GS-03 3). 모두 출처 블록이 1개다.
- 한국어 원문은 7칸 구성 시험 입력(`aplus-trial6_2026-11-24_<상품>/block_sources.json`)에서 읽었다.

## 3. 조건

- 방식은 `docs/ai/aplus.md` 4.8(사용자 결정 2026-11-26)이다. 비교 대상은 없다 — 한 가지 설정으로 한 번 돌렸다.
- 검사 규칙은 `pipeline/stages/text_check.py` 그대로다(`match@2026-10-08.1` · `term-check@2026-11-08.1` · `glossary-select@2026-11-08.1`).
- 사전은 로컬 정규화본 `regulation@2026-09-28.1`(원본 표기 v9 · 16행)이다. `docs/ai/contract.md` 5.1.1은 규제사전 v12로의 교체를 따로 적고 있다 — 이 실행의 사전은 그 이전 판이다.
- 규제 분류는 실행 인자로 줬다 — GS-01 `otc`(적용 분류 `otc` · `common`, 규제 행 10개), GS-02 · GS-03 `cosmetic`(적용 분류 `cosmetic` · `common`, 규제 행 6개). 에이전트가 상품 종류를 보고 준 값이며 셀러 선택값이 아니다.
- 용어 목록은 주지 않았다(용어집을 받지 않았다). 강제 용어는 검사하지 않았다.
- 실행 도구는 `docs/ai-experiments/tools/aplus_recheck_run.py`다.

## 4. 결과

판정 기준: 규칙 검사의 규제 매칭(사전 영어 표현의 글자 일치)이 있으면 「매칭 있음」이다. 매칭은 위반 확정이 아니고, 매칭이 없다는 것이 문제없음을 뜻하지도 않는다.

| 상품 | 바뀐 칸 | 규제 행 | 매칭 있는 칸 | 영어 표현이 없어 검사하지 못한 항목 | 강제 용어 검사 |
|---|---|---|---|---|---|
| GS-01 | 5 | 10 | 0 | 0 | 안 함 |
| GS-02 | 4 | 6 | 0 | 0 | 안 함 |
| GS-03 | 3 | 6 | 0 | 0 | 안 함 |
| 합계 | 12 | | 0 | | |

- 세 상품 모두 검사는 끝까지 돌았다(`status=ok`). 용어 목록이 없어 12칸 모두 검사 범위가 다 차지 않은 것으로 남았다(`complete=false`).
- 도구 밖 일회 확인: 같은 사전을 분류 구분 없이(16행) 세 상품의 글 칸 54개 전부에 압축 전 · 후 문구로 돌렸을 때 매칭은 1건이다 — GS-02 칸 7 본문(RG-030). 압축 대상이 아닌 칸이고 1차 번역에 있던 문구다. 바뀐 12칸은 이 조건에서도 0건이다.

에이전트가 결과를 읽고 적은 관찰이다. 사람 검수가 아니다.

- 압축 시험 기록(`2026-11-26_aplus_compress-trial.md` 4절)에서 뜻이 줄거나 달라져 보인다고 적은 칸은 규칙 검사에 걸리지 않았다. 규칙 검사는 사전 표현의 글자 일치만 본다.

## 5. 판단

- **보류** — 압축 뒤 규칙 검사의 방식(자리 · 대상 · 기록만)은 시험 전에 사용자 결정(2026-11-26)으로 정해졌고, 이 기록은 그 방식의 첫 실행이다.
- 이 세 상품 · 이 사전에서는 압축이 바꾼 12칸에서 규제 매칭이 없었다. 현재 사전으로 돌린 결과가 아니다.
- 강제 용어 검사(압축이 강제 용어를 뺐는지)는 돌리지 못했다. 용어 목록을 받은 뒤에 확인한다.
- 1차 번역에 원래 있던 규제 표현이 칸에 들어간 것은 이 단계가 보지 않는다. 표시할지는 정하지 않았다(#96).
