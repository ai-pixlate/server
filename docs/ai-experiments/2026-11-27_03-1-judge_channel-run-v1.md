## 5. 확인 범위와 관찰 — 에이전트 선별 확인(전수 아님 · 사람 검수 전)

에이전트 1명이 **present 5건, 신호가 떴는데 absent인 4건, 국가 축 실측과 엇갈린 2섹션**(겹치는 섹션을 빼면 9섹션)의 블록 원문과 모델 사유만 읽었다. 나머지 absent는 보지 않았고, 섹션 이미지는 직접 보지 않았다. 사람이 볼 수 있게 `review.html`(읽기 전용)을 만들어 전달했다.

- **신호가 떴는데 absent 4건**: 「리뷰 작성은 필요 없어요」(`리뷰`), 「추천 사용법」 2건(`추천사`가 「추천 사용법」 앞부분에 걸림), 시험 보고서 하단의 `www.` 주소. 모델은 넷 다 맥락을 들어 absent로 답했다.
- **시험 보고서 하단 URL(GS-03_014/sec_1_01)**: 모델 사유는 "고객 대상 문의처 안내가 아니다"다. 전달 파일의 CH-01 맥락 열은 문의처 · 주소 안내 섹션을 예로 들 뿐 이런 경우를 말하지 않는다. 이 판정이 채널 규칙에 맞는지는 이 기록에서 판단하지 않는다.
- **국가 축 실측과 엇갈린 섹션(GS-02_001 sec_1_01 · sec_1_02, 증정 이벤트)**: 국가 축(2026-09-29, 개발용 판정)은 둘 다 LC-03 · LC-05 · LC-06 present였다. 채널은 CH-02를 둘 다 absent로 답했고(사유: 판매가가 아니라 증정 금액), CH-06은 sec_1_01만 present, sec_1_02는 absent였다(사유: 기간 · 수량 조건이 없는 전원 증정). 즉 sec_1_02는 채널 4항목 어디에도 present가 없다.
  - 전달 파일의 CH-06 `판단 근거` 열에는 프로모션 자료 금지 조항 때문에 이벤트 안내가 걸린다는 설명이 있으나, 모델에 주는 `제외하는 맥락` 열은 기간 · 수량이 걸린 안내만 말한다. 판단 근거 열은 모델에 보내지 않는다(3절). 모델 답이 맥락 열의 글자 그대로와 어긋난다고 볼 근거는 이 표본에서 찾지 못했다 — 맥락 열이 이벤트 안내 전반을 담을지는 데이터 담당 확인 사항이다.
  - 국가 축 판정이 함께 도는 실제 작업에서는 이 두 섹션이 국가 축으로 제외된다. 채널만 본 이 실행의 결과와 구분한다.
- **CH-01 · CH-02 present 0건**: 2절의 한계 때문에 "잘 걸러 냈다"와 "판정할 대상이 없었다"를 이 표본으로 구분할 수 없다.
- **uncertain 0건**: 이 실행에서는 불확실 경로(정책의 제외 처리)가 실제 응답으로 한 번도 지나가지 않았다. 단위 테스트로만 확인된 상태다.
