## 4. 결과

### 실패 응답과 비교

section 27 / block 232의 `HOW\nTOSF`에 대해 task 163은 “판독 불가능하거나 의미를 알 수 없는 오탈자('TOSF')”, 자동 재시도 task 227은 “판독 불가능한 문자열”이라는 모델 명시 실패를 반환했다. 두 요청의 payload·prompt SHA는 같고, 응답 SHA는 다르다. 약 21.125초 / 18.938초 소요했으며 504가 아니다.

보존된 것은 **파싱된 모델 실패 사유·출력·사용량·응답 해시**다. 제공자 HTTP/응답 본문 전체는 이 수집기에 저장되지 않아 원시 응답 전문을 복원했다고 주장하지 않는다. 응답 SHA는 각각 `968df6116c2940638cfa70eb0008b9183e74f6c575a67baa60fad30190d3aa85`, `1c30a78b42a72c025182bfb7481d9a2e3e7de770bc7b3a817077213c076303a6`이다.

같은 실행의 정상 채택 사례:

| 블록 / task | 원문 | 실제 결과 |
|---|---|---|
| 128 / 139 | BODY BRIGHTENING | 동일 문구 유지 |
| 235 / 166 | All over the body / Apply it like a light massage. | Apply all over the body, / massaging gently. |

| 129 / 139 | It contains glutathione and vitamin C / It adds brightening energy to dull skin tones. | Formulated with glutathione and vitamin C, / it infuses dull skin tones with radiant brightening energy. |

따라서 영어 입력 자체를 실패 원인으로 단정할 수 없다. 확인된 직접 원인은 이 입력에 대한 모델의 명시적 실패와, 섹션 번역 성공 0건일 때 N4를 차단하는 제품 규칙이다. 두 차례 실패가 다음 시도의 실패를 증명하지 않으며, 다음 성공 확률도 추정하지 않는다.

### 비용과 권장 범위

누적 **163회·$9.21462925 예산 점유**(토큰 추정 $0.89462925 + 미확인 예약 $8.32)를 승계한다. 실제 청구액은 미확인이다. r2는 합산하지 않는다.

가장 비용 효율적인 안은 **task 227의 block 232만 JOB-06으로 1회 재시도**하는 것이다. 해당 입력은 1블록 요청이며 새 retry_count=2로 기존 한도에 도달해 추가 자동 재시도 여지가 없다. 예상 추가 Gemini 호출 1회, 기존 요청당 예약 상한 $1.04 적용 시 누적 최대 **164회·$10.25462925 점유**다. 누적 500회·$25 상한도 유지한다. 성공하면 다른 부분 실패는 기존 경고·빈 칸을 보존하고 N5 무수정 자동 확인 → N6 → H02~H04 별도 평가로 진행한다. N6 렌더는 모델 재호출이 아닌 기존 로컬 경로다.

부분 실패 6개 task까지 함께 재시도하는 선택도 가능하지만 이미지 확보의 선행 조건은 아니므로 이번 최소 실행안에 포함하지 않는다. 추가 품질 개선 범위로 별도 승인할 수 있다.

## 5. 판단

**JOB-06 최소 재시도 경로 채택 제안, 실제 실행 승인 대기.** 이전 보고서가 원문 수정·차단 규칙 변경만 대안처럼 제시한 부분을 보완한다. 기존 제품 로직의 사용자 재시도 경로를 이용할 수 있다.

실제 실행 전 승인할 범위는 새 복제본의 task 227 → block 232 한 번, 기존 예산 승계, 성공 시 N5 경고 무수정 자동 확인·N6·별도 품질 채점이다. 같은 블록이 다시 실패하면 기록을 보존하고 멈춘다. 원문·결과 수정이나 한도 초기화는 하지 않는다. 실행 도구는 별도 승인 근거와 새 복제본을 확인한 뒤 기존 JOB-06을 호출하도록 연결해야 하며, 기존 N3 전용 실행기를 그대로 재실행하면 안 된다.

한도 소진 또는 복제 자료 불일치로 이 경로가 불가능하면 새로운 격리 DB에서 전체 회차를 실행하는 대안이 남는다. 기존 코드·입력·정책 그대로라 동일 OCR/번역 실패가 반복될 수 있다. 이번 경로에서 누적 163회가 필요했던 관측값을 참고할 수 있으나 신규 회차의 호출·비용을 보장하지 않는다. 별도 범위·상한 승인 후 진행하며 기존 기록은 보존한다.

## 6. 반영

후보 검사·비과금 endpoint 검증 helper와 회귀 테스트를 PR #161에 추가한다. 앞선 수집기 자동 확인 이벤트 수정도 회귀 테스트와 함께 보존한다. 제품 코드·정답지·실측 증거·공식 명세는 변경하지 않는다. 병합·추가 모델 호출·CI 대기는 하지 않았다.
