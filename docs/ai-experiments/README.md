# ai-experiments — 개발 중 실험 기록

- 실험 1건 = 파일 1개. 파일명 `YYYY-MM-DD_<주제>.md`. 주제는 자유롭게, 단계가 있으면 앞에 붙인다(예: `2026-09-25_06-inpaint_score-min.md`).
- 이미지·CSV·로그 등 산출물은 `runs/`에 두고 git에 올리지 않는다. 기록 파일에는 요약 표만 남긴다.

## 기록 항목 — 이 순서로, 없는 항목은 "없음"

1. 질문 — 무엇을 알려고 했나. 관련 정본 절 또는 open-questions 번호
2. 표본 — 무엇으로 돌렸나(골든 섹션 번호, 장수 등)
3. 조건 — 비교한 것과 고정한 것
4. 결과 — 표 또는 수치. 판정 기준을 먼저 적는다
5. 판단 — 채택 · 기각 · 보류 중 하나와 이유
6. 반영 — 채택이면 어느 정본의 어느 절 또는 어느 open-questions 항목을 어떻게 바꿨는지와 날짜. 보류·기각이면 "없음"

## 이 폴더의 위치

- 구현 근거가 아니다. 에이전트는 이 폴더를 읽고 docs/ai 정본을 재해석하지 않는다.
- 정본과 어긋나면 정본이 맞고, 이 폴더의 기록은 그 시점의 실험이었을 뿐이다.
