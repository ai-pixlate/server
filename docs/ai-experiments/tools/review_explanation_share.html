규제 판정 설명 사례

번역문을 AI가 미국 화장품 · 선크림 광고 규제 관점에서 검사한 결과입니다. 문제가 될 수 있다고 본 문장마다 원문, 번역문, AI가 쓴 설명, 그리고 판단에 쓴 사전 사유와 근거를 함께 모았습니다.

판정 읽는 법

  • 문제 가능 규제 문제가 될 수 있는 표현
  • 조건 확인 필요 시험 결과 같은 상품 정보가 있어야 쓸 수 있는 표현
  • 문제 없음 관련 표현은 있지만 해당하지 않는다고 본 경우

설명 두 가지

  • 현재 설명 지금 서비스 코드의 프롬프트
  • 개선안 설명 판매자가 읽기 쉽게 설명 쓰는 법만 바꾼 실험 프롬프트. 판정 기준은 같습니다
  • 같은 문장을 프롬프트마다 2번씩 검사했습니다. 판정이 갈리면 판정 흔들림으로 표시합니다

주의

  • AI 1차 결과이고 정답 판정이 아닙니다
  • 사전 사유 · 근거는 서비스 규제사전(로컬 사본)에서 온 원문입니다. AI가 쓴 글은 설명뿐입니다
  • 합성 문장은 일부러 만든 시험용 문구입니다

실험 조건
  • 모델 gemini-3.8-flash, 온도 0, 호출 시간 제한 180초. 프롬프트마다 같은 문장을 2번씩 검사했습니다
  • 실제 상세페이지 문장은 골든셋 원문을 서비스 번역 함수로 번역한 것입니다. 표현 순화 지시는 현재 운영에서 꺼져 있어 넣지 않았습니다
  • 규제사전은 v9 계열 로컬 사본이고, 상품 분류(화장품 · 선크림)는 실험용 가정입니다
  • 경고로 보지 않은 문장은 싣지 않았습니다. 섹션의 전체 문장은 각 섹션의 "섹션 전체 문장 보기"에서 볼 수 있습니다
