## 4. 12월 범위 — MVP 밖

MVP 완성 후 다룬다. 상세는 여기 두지 않는다.

- 규격 변경 경로 전체 — 후속 번역 파생(`trans_2`) · 템플릿 할당·매핑 · 템플릿 렌더링 · 규격 자동 검증 · 아마존 A+ 산출 [개발계획 2.3, 4.1] [계약 10.1]
- 레이어 분해 · 정밀 누끼 — `birefnet-general` + `vlm_pick` 잠정, 그래픽 잔존·대상 누락·VLM 번호 착오 재검증 · 제품컷 누끼를 기능에 남길지 [PoC 0장 #3, 4장, 13장] [개발계획 4.1]
- 썸네일 입력 · 입력 유형 축(상세페이지/썸네일 선택) [개발계획 2.1, 3.1]
- 로고 인식 고도화 — 등록 로고 파일 · 이미지 매칭 · 심볼형 로고 · 매칭 실패 신호 [개발계획 2.1, 4.1] [계약 2.3, 10.1]
- 인페인팅 품질 고도화 — 잔존율 측정 · 재시도 기준 [개발계획 4.1] [계약 5.2, 10.1]
- 품질 신호 집계·분석 — 검수 수정 전후 기록 집계 [개발계획 4.1]
- 출력 분할 용량 한도 — 규격 검증에 용량 항목 도입 시 [개발계획 3.1]
