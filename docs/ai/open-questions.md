#### #56 상세 — BE 정정 안내와 남은 계약

**출처와 확인 범위**: 사용자 경유 BE 메시지(2026-09-30, 「RG-021·RG-022 대체 표현의 자리표시자 — 9월 MVP 데이터 정정 안내」). 아래 전달본 · 적재 상황은 BE의 보고이며, AI가 새 파일을 수령 · 대조하거나 RDS를 직접 확인했다는 뜻이 아니다.

- **BE 전달 사실**: 9/28 첫 전달본은 근거 날짜 누락으로 BE 적재 불가, 9/30 전달본은 근거 날짜만 보완했고 두 항목의 대체 표현은 그대로라고 안내했다. 메시지 시점 RDS에는 규제사전이 없으며 PR #44 머지 후 9/30 전달본 적재, 다음 정정본 수령 후 두 행 갱신 예정이라고 했다. 적재 완료로 기록하지 않는다.
- **정정 예정**: 두 행의 대체 표현에서 한국어 설명이 있는 자리표시자를 `[value]`로 바꾸며, 판정 · 사유 · 근거 · 검출 표현은 변경하지 않는다고 안내했다. 두 항목은 `conditional`이며, 완성 번역문이나 실행 지시가 아닌 **값 치환용 템플릿**으로 취급한다. 실제 정정본 수령 · 반영 여부는 별도 확인한다.
- **MVP 범위**: BE는 설명서 §4에 따라 대체 표현이 9월 번역 프롬프트(F-TRN-02)에 주입되는 값이라고 안내했다. 12월 대체 표현 자동 제안 UI(F-TRN-03b)와 별개다. 이 기능 식별자는 BE 전달상의 구분이며 현재 코드 구현 완료를 뜻하지 않는다.
- **BE가 전달한 사용 제약**: 값의 임의 생성 · 자리표시자의 최종 출력은 허용하지 않는다. RG-021은 검증된 상품별 수치가 필요하고, RG-022는 수치 외에 원본 `reason`의 적용 조건 충족 확인도 필요하다. OCR이나 한국 표시값을 얻었다는 사실만으로 검증값으로 간주하지 않는다. BE 로더의 한국어 감지 경고가 사라져도 번역 준비 완료는 아니다.
