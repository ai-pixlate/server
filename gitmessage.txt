# ── 제목: 유형: 내용 (영문 기준 50자 이내, 끝에 마침표 금지) ──────────

# ── 빈 행 (지우지 마세요) ─────────────────────────────────────────

# ── 본문: 무엇을, 왜 바꿨는지 (어떻게는 코드가 설명함) ─────────────
# - 변경 내용 1
# - 변경 내용 2

# ─────────────────────────────────────────────────────────────────
# 커밋 유형
#   feat            새로운 기능 추가
#   fix             버그 수정
#   docs            문서 수정
#   refactor        코드 리팩토링
#   chore           패키지 매니저 수정, 그 외 기타 수정 (예: .gitignore)
#
# 규칙
#   - 한 커밋에는 한 가지 문제만 담을 것
#   - 유형은 영어 소문자로 시작, 제목과 본문은 한글로 작성
#   - 제목과 본문 사이는 빈 행으로 분리
#   - 항목이 여러 개면 글머리 기호(-)로 나열
#
# 예시
#   feat: S0 프로세스 바 컴포넌트 추가
#
#   - 완료·현재·미도달 3가지 상태를 시각적으로 구분
#   - 전 단계에서 공통으로 쓰기 위해 components/ 하위에 배치
# ─────────────────────────────────────────────────────────────────
